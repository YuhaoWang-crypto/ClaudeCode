# 单细胞衰老分型深挖:衰老特征"擂台" × 跨诱导迁移 × 亚型可分性

这是对第一行(单细胞身份/干性/衰老)里**衰老分型**的深挖——第一轮只测了 SenCID 一个模型(排序能用、阈值未校准),
留下的真正问题是:**不同的"衰老特征集"彼此一致吗?能跨诱导方式/细胞语境迁移吗?衰老亚型能用基因集分开吗?**
这决定了任何衰老评分流程选哪个特征、能不能信。

结论先行:**"衰老分数"不是一回事——同一份数据上不同公开特征集 AUROC 从 0.51(Reactome 通路集,≈抛硬币)到 0.91(SenMayo);
SenMayo + 简单停滞/SASP 标记 + 增殖缺失这三类稳健且可跨诱导迁移,而通路级/部分文献集不可用也不迁移;衰老亚型用现成"亚型基因集"分不开**。

## 数据与特征(全部公开)

| 类型 | 数据 |
|---|---|
| 单细胞(RAS 诱导衰老) | GSE115301,IMR90 纤维母细胞,增殖 207 / RAS 衰老 240 细胞 |
| bulk(多诱导) | Casella 2019 GSE130727,同一纤维母细胞:复制性 / 阿霉素(DNA损伤) / 辐射 衰老 + 各自对照 |
| 衰老特征集 | SenMayo(124)、Fridman_up(77)、Reactome 细胞衰老(197)、CellAge 诱导衰老(370)、SenCID 基因集(1290)、核心标记(停滞+SASP)、增殖缺失 |

评分:单细胞用 scanpy 模块评分(score_genes),bulk 用样本间 z-score 均值;增殖缺失取负向。

## 结果

### 1. 衰老特征"擂台":选哪个特征决定一切

单细胞 RAS 衰老 vs 增殖,各特征 AUROC:

| 特征 | AUROC |
|---|---|
| SenMayo | **0.91** |
| 核心标记(CDKN1A/CDKN2A/SASP 等) | 0.86 |
| 增殖缺失(MKI67/LMNB1↓) | 0.85 |
| CellAge 诱导衰老 | 0.81 |
| Fridman_up | 0.72 |
| **Reactome 细胞衰老(通路集)** | **0.51(≈抛硬币)** |
| SenCID 训练模型(第一轮单独跑) | 0.89 |

同一份数据,AUROC 从 0.51 到 0.91。**Reactome"细胞衰老"通路集几乎检不出衰老**——因为它装的是通路机器基因,不是衰老状态标记。用对特征(SenMayo / 紧凑的停滞+SASP+增殖缺失面板)才可靠。
(注:SenCID 基因集 0.24 是误用——它是训练模型的输入特征表、不是方向性 up-signature;SenCID 作为模型本身 AUROC 0.89。)

### 2. 跨诱导迁移:好特征能迁,通路集不能

bulk 上各特征"衰老−对照"z 分差(复制性/阿霉素/辐射):

| 特征 | 复制性 | 阿霉素 | 辐射 |
|---|---|---|---|
| 核心标记 | +0.81 | +0.88 | +0.95 |
| SenMayo | +0.57 | +0.82 | +0.77 |
| 增殖缺失 | +0.94 | +0.44 | +2.13 |
| Fridman_up | +0.30 | +0.24 | +0.38 |
| CellAge 诱导 | +0.13 | +0.14 | **−0.23** |
| Reactome | +0.01 | −0.00 | **−0.49** |

核心标记、SenMayo、增殖缺失在三种诱导上都升高(可迁移);Reactome、CellAge 在辐射衰老里反而下降(不可迁移)。

### 3. 特征间一致性低

同一批细胞的 per-cell 分数,特征两两 Spearman 相关 0.1–0.7:好特征之间 0.6–0.7,Reactome 与其余近 0(0.1)。"做衰老评分"换个特征集结论可能完全不同。

### 4. 衰老亚型:现成"亚型基因集"分不开

用 CellAge 按衰老类型拆分的基因集(复制性/癌基因/应激)去打分 Casella 各诱导,**矩阵不对角**——复制性基因集在复制性衰老里甚至为负,最高值出现在阿霉素。即现成的文献"亚型基因集"不能干净区分衰老亚型。这正是 SenCID 要用机器学习(而非简单基因集)去定义 6 个 SID 的原因——亚型可分性是真问题。

## 可交付的建议(落地)

1. 衰老检测:默认用 **SenMayo**,或一个紧凑的"停滞(CDKN1A/CDKN2A)+SASP(IL6/CXCL8/MMP)+增殖缺失(MKI67/LMNB1↓)"面板;这几类 AUROC 0.85–0.91 且跨诱导稳健。
2. 不要用通路级集合(Reactome 细胞衰老)做衰老打分——它检不出衰老。
3. 分"衰老亚型"不要靠现成亚型基因集(分不开);要用训练模型(SenCID)并在目标语境重新校准阈值(第一轮已证 SenCID 阈值未校准)。
4. 交付前务必在客户自己的诱导方式/细胞类型上验证——衰老评分有语境依赖。

## 限制

- bulk 每条件仅 2 个重复(Casella),跨诱导用分数差而非 AUROC;单细胞只有一种诱导(RAS)、一种细胞(纤维母细胞)。
- SenCID 作为模型未在本次重跑(用第一轮的 AUROC 0.89);其基因集均值评分是刻意展示"模型≠方向性特征"。
- Casella 没有 bulk 的 RAS/癌基因诱导样本,"癌基因诱导"亚型集无法在此匹配验证。
- 评分用模块均值/z-score,未用 AUCell/ssGSEA 等更复杂方法(方向结论稳健,绝对值会变)。
- 未纳入 SA-β-gal、形态等非转录证据;衰老金标准本身有争议。
