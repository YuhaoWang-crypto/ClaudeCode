什么交给 UMA，什么交给 DFT

这是整条产品线的诚实核心。机器学习势（UMA）算能量、力、几何——快且省；电子结构（轨道、电荷、态密度、氧化电位）必须路由到 DFT（PySCF/QE）。产品从不假装 UMA 能算它算不了的东西。

适用域的一句话

  • UMA task-head 近似不同 DFT 泛函：oc20 ≈ RPBE，omol ≈ ωB97M-V——跨 head 的绝对能量不可直接相减。
  • 相对趋势 / 排序（谁吸附更强、谁氧化更早、p 型 vs n 型）稳健；绝对数值作为估计交付并标注。
  • 所有交付都带收敛判据、参考态定义与「与报告 / 文献的差值」——不藏丑。

ECH-RDX-001 / ECH-INT-001

电化学传感筛选：DA / AA / UA 氧化电位指纹

✅ 已复现

多巴胺（DA）、抗坏血酸（AA）、尿酸（UA）是电化学传感的经典共洗脱三元组——在裸电极上氧化峰重叠。为每个分析物算一套描述符指纹，并用 PCET（1H⁺/1e⁻，含 −0.059·pH 校正） 把朴素单电子电位拉回实验窗、恢复选择性次序。

这套产品线诚实的边界

能承诺的

  • 把「几百上千个候选」在几小时内收敛到「3–10 个值得进实验的组合」，并给出每个的机制解释与排除理由。
  • 吸附 / 结合 / 构象 / 能垒的相对排序，与文献 / 服务报告对齐；差分电荷与前线轨道走 DFT。
  • 可复现、可版本化：脚本 + 结构文件 + 结果 JSON + 与报告的差值，全部随交付。

不承诺的

  • 不替代最终实验验证——交付的是「下一炉该做什么」，不是结论。
  • 不给化学精度的绝对反应焓 / 绝对电位；跨 UMA head 的能量不可直接相减。
  • 周期性电子结构（DOS / 能带 / 功函）需 QE 等 DFT，UMA 只出能量与力。
