# 分子胶 / 三元复合物设计 Playbook —— 从 RevMed RAS(ON) 平台学到的研发思路，及对设计新分子的启发

> 来源：「制药漫谈」B 站《小分子抓不住 RAS，为什么借个蛋白就能做到？》逐帧梳理 + 其引用的原始文献
> （Schulze et al., *Science* 2023；Weller et al., *Science* 2025, doi:10.1126/science.ads0239；
> 专利 US20160199506A1 / Warp Drive Bio；Ostrem et al., *Nature* 2013；经典免疫亲和素文献）。
> 本文把这套"招募伴侣蛋白造界面"的研发逻辑抽象成**可迁移的设计准则**，并对接我们已验证的 Boltz + 界面分析框架（见 `../demo/tricomplex/`）。

## 0. 一句话抓住这套思路

**当靶点"没有口袋"时，不要再找口袋——招募一个胞内高丰度的"伴侣蛋白（presenter）"，设计一个小分子让伴侣蛋白与靶点"共建一个原本不存在的识别界面（neomorphic interface）"，用这个新界面把靶点钉住。** 小分子不是把两个蛋白"粘"在一起那么简单，它还会**诱导伴侣蛋白表面重排**，与之共同构成识别面。

| **工具分子 → 候选药（4 杠杆）** | ①**骨架大环化**（含取代吲哚的连接段，限制构象自由度，回到天然产物形态）；②**共价/非共价并行**（Cmpd‑2 乙酰胺可逆、仍成三元 vs Cmpd‑3 丙烯酰胺共价 Cys12）；③**更换弹头**（丙烯酰胺→**炔酰胺 ynamide**，三元形成 IC50 **52→28 nM**，最大靶标结合速率 **×26**）；④**优化连接段构象**（RMC‑4998，调整弹头**位置与朝向**，结合速率**再×14**） | Schulze 2023, Fig.1B–D |

## 2. 提炼：可迁移的设计准则（The Playbook）

把上面的故事抽象成**遇到一个"无口袋/难成药"靶点时可照着走的决策链**：

### 准则 A — 范式选择：造界面而非找口袋
靶点若是平坦 PPI 面 / 持续活化开关（无深口袋、内源配体亲和力极高），放弃正构抑制，走**伴侣蛋白招募型分子胶**：目标是制造 **neomorphic interface**。

### 准则 B — presenter（伴侣蛋白）的三条选择标准
1. **药理可及**：胞内**高丰度、广泛表达**（否则胶被稀释/占不满）。
2. **有化学起点**：存在**已知高亲和的天然配体/配体骨架**可作为 presenter 结合端（CypA↔sanglifehrin A/环孢素；FKBP12↔FK506/雷帕霉素）。
3. **界面可诱导**：presenter 表面与靶点目标面有**形状/静电互补的潜力**（CypA 对 KRAS 效应面互补、FKBP12 不互补）。⚠️ 互补 ≠ 自发结合，胶负责"促成"。

### 准则 C — 先做"工具分子"拿结构，再打磨成药
- 工具分子 = **双功能最小体**：presenter 结合端 + 靶点栓系端（常用**共价栓系**先把弱三元"锁住"）。
- 目的不是成药，而是**拿到可解析的初始三元晶体**（如 8G9Q）作为 SAR 起点。
- 血缘启示：**tethering（二硫键/共价栓系）既能钓隐匿口袋（2013 G12C），也能建初始三元（2023）**——同一工具，两种用法。

### 准则 D — 工具分子→候选药的四个优化杠杆（可独立调）
| 杠杆 | 物理意义 | 可观测读出 |
|---|---|---|
| **大环化/预组织** | 限制构象自由度，预付结合熵 | 结合速率/亲和力↑；构象采样更集中 |
| **弹头工程** | 共价 vs 非共价；反应性调谐以匹配靶残基 | 三元形成 IC50、kobs（结合速率）|
| **连接段构象** | 调整弹头"接近靶点的姿势"（位置+朝向） | kobs 可数量级提升（文中 ×14）|
| **界面优化** | 诱导 presenter 表面重排，共建识别面 | 界面 BSA、界面残基、静电互补 |

### 准则 E — 弹头-残基匹配：选择性来自界面几何，不只来自弹头反应性
- 可及 **Cys**（G12C）：丙烯酰胺 / 炔酰胺（ynamide）。
- 弱亲核 **Asp/Glu**（G12D）：**温和弹头（aziridine）**，本征反应性低、靠界面把弹头摆到 Asp12 旁的合适距离/朝向 → **选择性共价**。
- 推论：**用"温和弹头 + 界面几何"实现对一般认为难共价的残基的选择性**，是可推广的新杠杆。

### 准则 F — 平台化
一旦 presenter 招募原理跑通，**同一 presenter + 同一原理**可派生多靶点/多突变分支（共价选择性 vs 非共价泛选择性各取所需）。

## 3. 对"设计新分子"的具体启发（Actionable）

> 下面每条都给出：设计动作 + 用我们现有 Boltz/界面框架如何先做计算验证（`../demo/tricomplex/` 已跑通）。⚠️ 均为假设生成层面。

### 3.1 把 presenter 选择变成"可计算的决策"
- **动作**：对候选 presenter（CypA、FKBP12、14‑3‑3、其他高丰度免疫亲和素/伴侣）逐一评估与目标靶面的**形状+静电互补**。
- **计算**：① 对 presenter:target 做**无胶二元**预测（protein_protein_binding）看 apo 不自发结合（应低置信，符合"需要胶"）；② 关键用**界面静电互补 + 可诱导性**打分（可在我们 `tri_analyze.py` 基础上加一个静电互补度量）。
- **✅ 已验证（Pilot 1，见 [`pilot1/RESULTS.md`](pilot1/RESULTS.md)）**：量化真实 9BFX 的 CypA–KRAS 界面 = **CypA 碱性(+5) ↔ KRAS 酸性(−5)、8 盐桥、0 冲突、EC+1.15**，复现"局部电荷互补"；同口径下 **FKBP12–KRAS** 找不到干净互补界面（EC+0.11、首现 2 个同电荷冲突、binding_confidence 最低 0.171）——方向上支持"选 CypA 不选 FKBP12"。即 **presenter 选择可被量化成筛选器**。

### 3.2 弹头-残基匹配矩阵（温和弹头库）
- **动作**：建立"可及亲核残基 → 温和弹头"对照库（Cys→acrylamide/ynamide；Asp/Glu→aziridine/温和亲电；Lys→活化酯/醛亚胺；Ser/Thr/Tyr→探索）。选择性由**界面把弹头摆到目标残基旁**决定。
- **计算**：用我们已验证的**显式共价键建模**（Boltz `bonds`，见 demo：声明 Cys12 SG↔弹头后，距离 4.66→1.96 Å、界面回收率升到 82–90%），对不同候选残基/弹头组合逐个建键预测，看**弹头原子到目标残基的距离与朝向是否被界面几何支持**。

### 3.3 大环化/连接段的构象预组织，做计算排序
- **动作**：同一药效团，比较**大环 vs 开链**、不同连接段（吲哚/吡啶取代）。
- **计算**：逐个三元预测，比较 **protein_iptm、三元界面 BSA、样本间一致性**（预组织好的应更高且更稳）——我们 demo 已证明"约束越贴合真实化学，预测越贴近晶体"。

### 3.4 共价（选择性）vs 非共价（泛选择性）两条路线并行
- **动作**：像 RevMed 一样对同一骨架做**共价版（单突变选择性）**与**非共价版（覆盖多突变+WT）**。
- **计算**：共价版用 `bonds` 建键；非共价版靠界面协同拿亲和力——用 **binding_confidence + 界面回收率**排序，并对 WT/多突变做**选择性对照**（我们 demo 已做 G12D vs WT 选择性的雏形）。

### 3.5 迁移到新靶点（平台外推）
- **动作**：把"CypA 招募"外推到其他**无口袋 PPI 靶点 / small GTPase**（如其他 RAS 超家族 RHO/RAC/RAL，或平坦的转录因子界面——呼应 TTI‑101/STAT3 失败的教训：STAT3 正是因无口袋而失败，正适合换成分子胶范式）。
- **计算**：先做 **presenter:新靶点** 的界面互补预筛（3.1），互补性好的再设计胶做三元预测。

## 3B. 能否推广到其他不可成药靶点？presenter 是靠"柔"吗？

> 回应一个常见直觉："presenter 是不是比较柔，所以能适应别的光滑表面，再靠小分子做动态矫正？"
> 结论：**方向对，但分工要修正**——presenter 不是靠"整体柔"，而是靠"刚性 scaffold + 局部诱导契合 + 本来就带的潜在互补面"；真正"编程新界面/做矫正"的是**小分子**。

### 证据：CypA 其实很"刚"（Pilot‑flex 实测）
取 apo 人源 CypA 晶体（PDB 2CPL）vs 结合态 CypA（9BFX 链 D），Kabsch 叠合：
- **全局 Cα RMSD = 0.41 Å** → 基本是晶体噪声级，CypA **整体几乎不动**（是个刚性 β‑桶，不是柔性适配器）。
- **界面 rim 偏差均值 0.58 Å**，但**个别残基在动**：**Asn71 = 2.15 Å、Arg69 = 1.39 Å**，其余 <0.7 Å。
- → 适配是**局部的诱导契合（几个 rim 残基的小幅重排）**，不是整体变形。对应视频"改变的不只是那只手套"，但幅度**局部且小**。

### 正确的分工（修正后的心智模型）
| 角色 | 谁来做 | 性质 |
|---|---|---|
| **大块亲和力锚 + 立体盾牌** | presenter（CypA） | **刚性** scaffold，可靠、可预测 |
| **潜在互补面**（如碱性 rim 对 KRAS 酸性效应面）| presenter **本来就带** | Pilot 1：apo 态 rim 已是 Arg55/69/Lys125/148/151 |
| **局部微调**（rim 诱导契合）| presenter 的少数 rim 残基 | **小幅**（~1–2 Å） |
| **编程新界面 + 做"矫正"** | **小分子（胶）** | 创造新化学面 + 选择/锁定 presenter 的生产性构象 |

**所以**：换一个新靶点时，"适应新界面"主要靠**重新设计胶**，而不是靠 presenter 自己变柔——presenter 被反复复用，恰恰因为它是个**行为可预测的刚性锚**。

### ⚠️ "越柔越好" 是错的
柔性是双刃：局部诱导契合有利，但**整体柔 → 三元形成的构象熵罚大、协同弱、界面难预测**。所以 RevMed 的真实做法是**反其道而行——把胶"刚化"**（大环化、锁连接段构象）来**预付熵**（见准则 D）。设计甜点是：**刚性 presenter（带潜在互补面 + 少量 rim 可塑）+ 预组织好的刚性胶（负责编程新界面并诱导那点局部重排）**。

### 推广到其他不可成药靶点：可以，但是"选对 presenter + 靶面"的问题
这套"诱导邻近/招募 presenter"范式本身是通用的，领域里已大量在做：
- **E3 连接酶做 presenter 的分子胶降解剂**：IMiDs（沙利度胺类）→CRBN→新底物（IKZF1/3 等）；indisulam→DCAF15→RBM39。
- **14‑3‑3 做 presenter 枢纽**：fusicoccin 类稳定 14‑3‑3 : 客户蛋白复合物——一个很贴切的"刚性 scaffold + 小分子编程界面"的例子。
- **免疫亲和素**：rapamycin→FKBP12→mTOR；FK506→FKBP12→钙调磷酸酶；sanglifehrin→CypA→RAS（本案例）。

**适合的靶点画像**：平坦 PPI 面 / 持续活化开关 / 无深口袋的"光滑球" / 高丰度难成药癌蛋白 / 其他小 G 蛋白（RHO/RAC/RAL/RAB）/ 转录因子。
> ⚠️ 但"适合换范式"≠"适合每一条分支"。**Pilot 2（STAT3）实测**：STAT3 的功能面是 **pTyr705↔SH2‑Arg609 磷酸锁孔热点（近中性宽面）**，CypA/FKBP12 式刚性遮盖 presenter **抓不住**（预筛 binding_conf ~0）；STAT3 应走**降解分支（E3）或口袋直给**。→ 范式内还要先判"**哪条分支适配该靶**"，预筛正是干这个的。见 [`pilot2/RESULTS.md`](pilot2/RESULTS.md)。
> ✅ **Pilot 3 证实了"换分支就成"**：给 STAT3 一个真实双功能 PROTAC（**SD‑36**）招募 **CRBN**，Boltz 形成**高置信三元（binding_conf 0.87**，遮盖分支才 ~0），PROTAC 两端分别锚定 CRBN tri‑Trp 口袋与 STAT3 SH2，并把 STAT3 的 **K707/K709 递到 CRBN 面前（6.1 Å）**——降解分支的"诱导邻近 + 赖氨酸递呈"判据全部满足。见 [`pilot3/RESULTS.md`](pilot3/RESULTS.md)。

**成功的硬条件（缺一不可）**：
1. 靶面存在一块**功能相关**的表面（不必是口袋，但要能被"presenter+胶"的复合面互补并且阻断它有治疗意义，如遮住效应器面/招募降解）。
2. 存在一个 presenter 与该靶面有**潜在互补**（我们 Pilot 1 证明这可计算筛选，也证明**不是随便哪个 presenter 都行**——FKBP12 对 KRAS 面就不互补）。
3. presenter 有**化学起点**（已知高亲和配体/骨架）作结合端。
4. 胶可被设计成**双功能桥**（presenter 端 + 靶点端，最好带共价/高驻留锚）。

→ 即：**范式可推广，但它是"逐靶点配对 presenter + 设计新胶"的工程问题，不是"找个柔蛋白通吃"**。我们的 `pilot1/electro_complementarity.py` + 界面分析正好能把"presenter×靶面"的潜在互补做成**批量预筛器**（准则 B 的计算化）。

## 4. 我们已经验证了这套设计循环的哪几步（证据）

我们在 `../demo/tricomplex/` 用 Boltz‑2 对 **CYPA : RMC‑6291 : KRAS G12C** 做过完整对照，证明**本框架能执行上面设计循环的关键读出**：

- **三元界面可复现**：含胶预测复现 9BFX 天然界面，KRAS 侧界面残基 precision 100%、CYPA 侧 recall 55%。
- **无胶对照界面崩塌**：binding_confidence 0.90→0.32、样本剧烈波动——对应"需要胶"。
- **显式共价键改善排布**：声明 Cys12 SG↔弹头 β‑碳后，胶↔Cys12 距离 4.66→**1.96 Å**、BSA 337→**417 Å²（≈实验425）**、CYPA 界面回收率 55%→**82%**。

→ 即：**presenter 招募（3.1）、共价锚定（3.2）、界面优化读出（3.3/3.4）** 这几个设计杠杆，我们都已有可跑的计算读出。缺口是**协同自由能 ΔΔG_coop 的 FEP 金标准**（准则 D 的定量化）。
