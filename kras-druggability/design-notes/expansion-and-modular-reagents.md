# 拓展与模块化试剂：这套「诱导邻近 / 招募 presenter」范式还能做什么

> 承接 playbook 与 4 个 pilot（KRAS 遮盖/共价 + STAT3 降解）。本文做三件事：
> ① 把范式**再概括**到它真正的边界；② 系统列**可拓展的识别靶点 / 不可成药靶点**并按可行性排序；③ 评估两个**模块化试剂**构想（无抗体胞内检测、模块化先导发现骨架）。
> 📏 诚实标注：✅=已有实验/上市验证；🟡=有概念验证、工程化中；⚠️=前瞻假设，需实验证。本文是**战略性 ideation + 文献 grounding + 我们计算框架的对接**，非逐条实验结论。

---

## 0. 关键再概括：范式的真正边界

**本质 = 用一个（通常双功能的）小分子，在"难成药靶点"与"某个效应器/presenter"之间诱导邻近（induced proximity）。** 一旦能诱导邻近，"拿它干什么"就变成一个**可组合的效应器菜单**：

| 效应模态 | 招募谁 | 已验证载体 | 对靶点的要求 |
|---|---|---|---|
| **抑制/遮盖** | 伴侣蛋白(CypA/FKBP12) 盖住功能面 | RMC‑6291/6236(RAS) | 需**潜在表面互补**（最苛刻）|
| **降解(TPD)** | E3 连接酶(CRBN/VHL/DCAF15/…) | 众多 PROTAC/分子胶（AR/BTK/RBM39…）| 只要**三元 + 一个可及 Lys**（最宽容）|
| **去磷酸(PhosTAC)** | 磷酸酶(PP1/PP2A) | 概念验证 | 有磷酸位点 |
| **稳定 PPI** | 14‑3‑3 等枢纽 | fusicoccin 稳定 14‑3‑3:client | 已有待稳定的 PPI |
| **重定位** | 把 TF 赶出核/锚到膜/招 14‑3‑3 扣留 | 概念验证 | 有可劫持的定位信号 |
| **检测(本文 §3.1)** | 报告子/点亮荧光团 | CID 生物传感器 | 状态/构象标记物 |

> 推论：**靶点宇宙 ≈ 几乎所有"无口袋"的 PPI / 转录因子 / scaffold / 开关蛋白**。能不能做，取决于(a) 靶面有没有一个**化学起点**（去做"靶端"弹头/结合子），(b) 选哪条**效应分支**（遮盖最难、降解最宽容）。
> 这也是我们 Pilot 2→3 的核心教训：**同一个 STAT3，遮盖分支 binding_conf ~0，降解分支 0.87——先判分支再建模。**

## 1. 可拓展的识别靶点（按可行性排序）

> 每条给：**适配分支 · 为什么难 · 验证状态 · 我们的预筛读出**。预筛读出 = 遮盖分支用 [`pilot1/electro_complementarity.py`](pilot1/electro_complementarity.py)（EC+盐桥/冲突+binding_conf）；降解分支用 [`pilot3/proximity_analyze.py`](pilot3/proximity_analyze.py)（三元+赖氨酸递呈）。

### 1.1 高可行性 ✅🟡（同平台或已有验证）

| 靶点 | 适配分支 | 说明 / 验证 | 预筛读出 |
|---|---|---|---|
| **NRAS / HRAS** | 遮盖(CypA) | 与 KRAS 同家族同面，RMC‑6236 已泛 RAS(ON) ✅ | 直接复用我们的 CypA–RAS 管线 |
| **RHOA / RAC1 / CDC42 / RALA·B / ARF / RAB** | 遮盖(专用 presenter)或共价 | 同为 GTP 锁定的平坦开关；RAL/RHO 是热点🟡 | presenter×靶 互补预筛 |
| **SOS1（RAS‑GEF）** | 口袋/遮盖 | 已有小分子胶与抑制剂 ✅ | — |
| **AR / ER（核受体）** | 降解(E3) | 降解剂 **vepdegestrant/ARV‑471、bavdegalutamide 临床/上市** ✅ | 三元+Lys 递呈 |
| **BTK / BRAF / BCL6 / IRAK4** | 降解(E3) | 多个 PROTAC 临床 ✅ | 三元+Lys 递呈 |
| **RBM39 / CK1α / GSPT1 / IKZF1·3 / SALL4** | 降解(分子胶) | indisulam/IMiD **已证分子胶可降这些"无口袋"蛋白** ✅ | 降解分支判据成熟 |
| **STAT3**（本工作） | 降解(CRBN) | Pilot 3：SD‑36 三元 binding_conf 0.87 ✅ | 已做 |

### 1.2 中等可行性 🟡⚠️（经典"不可成药"，走降解/稳定更现实）

| 靶点 | 为什么难 | 最适分支 | 备注 |
|---|---|---|---|
| **MYC** | 无口袋、内在无序、必需 | 降解 / 干扰 MYC‑MAX | 终极难靶；Omomyc 肽 + 降解尝试中 ⚠️ |
| **β‑catenin（WNT）** | 平坦 PPI、支架 | 降解 / 口袋处 PPI | 降解剂在研 🟡 |
| **NF‑κB (RelA) / FOXP3 / MYB / STAT5** | 转录因子、无口袋 | 降解 | FOXP3(Treg) 诱人但必需性高 ⚠️ |
| **mutant p53（R175H 等）** | 失稳/错折叠 | 稳定(复活)或降解突变体 | 复活剂(eprenetapopt)思路不同；降解突变体可计算 🟡 |
| **SHP2 / PTP1B / PTEN / CDC25（磷酸酶）** | 活性位带电浅、同源性高 | 变构/降解/PhosTAC | SHP2 变构已上市(如 TNO155 类) ✅，其余难 |
| **KEAP1‑NRF2 / MCL1 / MDM2‑p53 / menin‑MLL** | PPI（部分有浅沟/口袋） | 口袋/PPI/降解 | menin‑MLL(revumenib)、MDM2 有口袋 ✅；可做降解增强 |
| **HIF‑2α** | TF，但有**真实疏水腔**（例外）| 口袋(belzutifan) ✅ | 不必走胶 |

### 1.3 较低可行性 / 需换模态 ⚠️

| 靶点类 | 问题 | 替代模态（仍是"诱导邻近"家族）|
|---|---|---|
| **Tau / α‑synuclein 聚集体** | 非折叠/聚集，无稳定界面 | **AUTAC / ATTEC**：诱导邻近到**自噬**机器（LC3/p62），非 presenter 遮盖 |
| **胞外 / 膜蛋白（细胞因子、受体）** | 胞内 E3 够不到 | **LYTAC**：招募 **CI‑M6PR / ASGPR** 走溶酶体降解 |
| **DNA/RNA 元件、必需管家** | 无蛋白界面 / 毒性窗口窄 | 一般不建议本范式 |

## 2. "不可成药"靶点 → 推荐分支 速查

```
靶面性质                         首选分支                 我们的预筛判据
─────────────────────────────────────────────────────────────────────
宽阔带电/疏水平面(效应面)   →   遮盖(presenter)          EC+盐桥/冲突+binding_conf
磷酸/pTyr"锁孔"热点          →   口袋直给 or 降解          (口袋:对接) / 三元+Lys
支架/PPI 中心               →   降解 or PPI 稳定          三元+Lys / 界面BSA
错折叠/失稳(mut p53)         →   稳定复活 or 降解突变体     构象预测 + 三元
聚集体(Tau/α-syn)            →   自噬诱导(AUTAC/ATTEC)     邻近到 LC3
胞外/膜                      →   溶酶体靶向(LYTAC)         邻近到 M6PR
```

**最通用的结论**：**降解分支（E3 招募）是"不可成药"靶点的最大公约数**——因为它对靶面要求最低（只要形成三元 + 露出一个 Lys）。遮盖分支虽优雅，但苛求表面互补（Pilot 2 已证 STAT3 不满足）。

## 3. 模块化试剂构想（你的两个想法 + 诚实评估）

### 3.1 胞内低丰度蛋白检测，不用抗体 —— 想法对，但"带荧光蛋白过去"要修正

**⚠️ 需要修正的点**：单个小分子胶**带不动一个完整荧光蛋白**（GFP ~27 kDa、~238 aa，是个蛋白，不是小分子货物）。"把荧光蛋白带过去"在化学上不成立。

**✅ 但"无抗体、靠诱导邻近做胞内检测"是成立的，有几条真实可行路线：**

| 方案 | 原理 | 需不需要基因工程 | 成熟度 |
|---|---|---|---|
| **a) 分裂报告子互补(CID)** | 双功能分子一端结合靶、一端招募报告子半体 → 分裂荧光素酶/分裂 FP 重构发光 | 需表达分裂报告子半体 | 🟡 CID 生物传感器成熟 |
| **b) 点亮型诱导邻近探针** | 胶自带**环境敏感/荧光原("turn‑on")荧光团**，只有在靶上形成三元时去淬灭/变亮 | **不需蛋白货物** | ⚠️ 新，但化学可行 |
| **c) 招募基因编码报告酶放大** | 把 HaloTag/HiBiT/β‑gal 等招到靶旁，酶促放大信号 | 需表达小标签 | 🟡 |
| **d) 邻近标记(化学诱导 BioID)** | 双功能分子把生物素连接酶/反应探针带到靶旁，标记邻域再检测 | 部分需酶 | 🟡 |

**真正的差异化 niche（这才是胶的独门优势）**：**状态/构象选择性检测**——只在靶处于**特定构象或 PTM 态**时点亮。正如 RAS(ON) 选择性分子胶只认 GTP 态，可以做一个"**只点亮活化态/磷酸化态靶蛋白**"的探针，这是抗体/常规标签很难做到的（它们认序列不认瞬时构象）。这是"检测试剂"里最值得做的方向。

**⚠️ 灵敏度诚实边界**：诱导邻近给的信号∝靶丰度；**低丰度要靠催化放大**（酶报告子、分裂荧光素酶的酶促转化），纯化学计量的"点亮"难测极低拷贝数。所以：**检测低丰度 → 必须配酶促/催化放大**；若只求"有没有/在哪个构象"，点亮探针就够。另：无抗体胞内检测已有 nanobody/intrabody、aptamer、split‑FP、HiBiT 等成熟方案，胶探针的卖点是**状态选择性**而非单纯灵敏度。

### 3.2 模块化骨架分子用于先导发现（你的"带巯基骨架"想法）—— 这个方向很对

**✅ 核心判断**：这正是 Shokat/Wells 的**栓系(tethering)** + RevMed 的**模块化分子胶库**的工业化形态，高度可行。只做一处**诚实修正**：别用"裸露自由巯基"（‑SH 易氧化、乱反应、难控），业界用的是**二硫键栓系**（可逆共价）或**调谐过的温和亲电弹头**。

三类模块化试剂（可组合、可计算排序）：

| 试剂 | 模块化维度 | 怎么用 | 成熟度 |
|---|---|---|---|
| **① 二硫键栓系片段库** | 片段 × Cys 扫描位点 | 在候选面做 Cys 扫描突变，弱还原剂下孵育含二硫键片段，完整蛋白 MS 读分子量增加 → 找出能稳定**隐匿口袋**的片段先导（跨靶点通用）| ✅ 成熟(2013 G12C 即此法) |
| **② "presenter 锚 × 弹头/linker" 双功能库** | **presenter 模块** × **弹头+linker 模块** | 固定 presenter 端（CypA/CRBN/FKBP12/VHL 锚），变靶端弹头与连接段，在**饱和 presenter** 存在下筛三元 → 找分子胶先导。两条正交模块轴 | 🟡（RevMed 实践的工业化） |
| **③ 共价弹头工具箱(按残基匹配)** | 弹头 × 可及残基(Cys/Lys/Ser/Tyr/Asp) | 丙烯酰胺/炔酰胺(Cys)、活化酯/醛(Lys)、aziridine(弱亲核 Asp，见 playbook 准则E)… 配 ABPP 化学蛋白质组学**全基因组找可配体位点** | ✅ (scout fragments, ABPP) |

**映射到我们已有的计算管线**（让这些库"可计算优先级排序"）：
- **哪个 presenter 锚配哪个靶**：`electro_complementarity.py` 预筛 presenter×靶面互补（Pilot 1）。
- **哪个弹头/残基组合能成键**：`bonds` 显式共价建模 + 弹头原子↔目标残基距离/朝向（Pilot 3 的做法）。
- **Cys 扫描排序**：对候选面每个位点建 Cys、预测片段三元、按 binding_conf + 弹头‑SG 距离排序 → 优先做哪些突变体。
- **三元可行性**：`proximity_analyze.py` / tri 分析（界面 + 递呈/桥接）。

> 即：你设想的"模块化骨架 + 不同靶点/不同 presenter"——**可以做成一个 (presenter 模块) × (弹头/linker 模块) × (靶点/位点) 的组合库，并用我们这套 Boltz+分析器做虚拟预排序，再上实验栓系/ABPP 验证。**

## 5. 诚实边界 + 建议的可计算下一步

**诚实边界**
- 本文是**战略判断 + 文献 grounding**，具体可行性需逐靶实验；上市/临床标注用于佐证"该分支整体可行"，不等于某个新靶一定成。
- **降解分支对靶面最宽容但非万能**：仍需(a) 靶端有结合子/弹头的化学起点，(b) 三元几何能把 Lys 递到 E2~Ub（全 CRL4 语境，我们只建了受体域 = 几何代理），(c) 细胞渗透/三元体内稳定/hook effect 等 PK 现实。
- **检测试剂**：低丰度必须配催化放大；胶探针的独特价值在**状态/构象选择性**，不是通用灵敏度。
- **模块库**：虚拟预排序会有假阳性，必须下实验栓系/ABPP/生物物理闭环。

**建议的可计算 pilot（挑 1–2 个我就能直接跑，各约 $0.1–0.3）**
1. **高可行性外推**：RHOA 或 RALA + CypA 的遮盖互补预筛（看小 GTPase 平台能否一键迁移）。
2. **降解分支外推**：给一个经典 TF（如 β‑catenin 或 AR）配一个已知 E3+PROTAC，跑诱导邻近 + Lys 递呈。
3. **模块库虚拟排序雏形**：固定 CRBN 锚，对 2–3 个靶端弹头/linker 变体排三元 binding_conf（演示"presenter×弹头"双模块可计算打分）。
