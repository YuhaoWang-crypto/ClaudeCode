数学 · 系统生物学 · 从头到尾的总结

能不能把纯数学搬到生物网络里，找到可检测的 biomarker？

从一个概念问题出发——群论、对称、不可约、分岔理论能否作用于哺乳动物调控网络（~2 万蛋白、~1600 个转录因子）——最后落成一套 22 个模块、可真跑的分析流水线。每个数字都是计算出来的，每条结论都带严格性标注。

22 模块 ~25 条通路 3 类分岔覆盖 12 张实算数据表 真实数据 KRAS G12C / ERK 2026-07
起点最初的问题

如果调控网络也有"素因子"和"对称性"，它们能不能变成 biomarker？

最初的直觉有三层：对称（不同上游通路坍缩到同一节点，像群作用的轨道）、不可约（网络里存在无法再分的最小功能模块，像素数 / 不可约多项式）、临界（细胞命运翻转是一次动力学分岔，而某个小分子结合把系统的李雅普诺夫指数从负推向正，这个参数本身就是高度抽象的 biomarker）。

问题是：这些是漂亮的类比，还是能在具体网络上真正算出数字的东西？下面这条流水线就是逐一把类比变成计算——并在每一步诚实地标出哪里是严格结果、哪里是待验证的假设。

第一部分 · 五步核心工具M1 – M4

四把抽象数学工具，在教学级小网络上逐一落地

先在能验证每一步的小网络上把方法跑通，保证每个数字可复核，再去接真实大网络。

M1

图自同构 → 商网络：把"对称冗余"变成群论计算

RTK→RAS→RAF→MEK→ERK 级联里，三个 RAS 旁系（HRAS/KRAS/NRAS）接线完全相同 → 自同构群 |Aut(G)| = 6 = S₃；商掉这个轨道，网络 9 → 7 节点，三个冗余节点坍缩成单个有效节点 RAS*。"不同上游通路坍缩到一个节点"由此成为严格的图论事实。

M2

CRNT 亏格 δ：一个整数决定网络"有没有资格"当开关

Feinberg 亏格零定理：δ=0 且弱可逆 ⇒ 任意速率常数下唯一稳态 ⇒ 不可能双稳。实测：A⇌B⇌C 环 δ=0（单稳），经典 Schlögl δ=1（双稳，X≈3.45 / 0.43 两个吸引子）。一个凌驾于所有浓度之上的拓扑不变量，从根上决定能否成为开关。

M3

初等通量模式（EFM）：代谢网络的"素因子 / 生成基"

稳态通量锥的极射线 = EFM，是支撑最小、不可再分的通路。4 代谢物网络算出 3 个 EFM；随机可行通量用非负最小二乘从 EFM 重构，残差 3.4e-16 ⇒ 任何稳态通量都是它们的非负组合。这是最接近"不可约分"的严格对象。

M4

DNB / 临界慢化 / 李雅普诺夫指数：直接回答那个核心问题

先在 Rössler 吸引子上验证 Benettin 算法：LLE = +0.0737（文献 ≈+0.071），证明"能算出正的李雅普诺夫指数并对应混沌"是真的。再把互激活基因对推过鞍结分岔：越靠近临界点，主特征值 → 0，方差 / 自相关 / DNB 指数同步升 ~30 倍。

✅ 对那个李雅普诺夫假设的正面回答

"小分子结合把核心网络的最大李雅普诺夫指数从负推向正，这个参数就是抽象 biomarker"——方向完全正确，而且做出来了：λ 穿过 0 的那一刻就是失稳分岔点，是一个单一、抽象、可测量的稳定性参数。

⚠️ 诚实的边界

在这个 fold 系统里 λ 是从负趋近 0（失稳 = ON 态崩溃 = 命运翻转）；要严格为正（真正混沌）需 ≥3 维系统——这正是先在 Rössler 上验证的原因。分子动力学纳秒尺度的构象李雅普诺夫，与这里的网络 / 细胞尺度是两个不同尺度；"λ 变号 ⇒ 凋亡 / 毒性"是可检验的假设，不是已证定理。可严格交付的是：λ 在分岔点变号，作为模型内可计算的稳定性 biomarker。

01 · 结构

不可约核心节点身份

自同构 / 纤维化商网络给出的 pan-assay 代表读出（pERK1/2、pSTAT、pSMAD2/3…），先验可定。

02 · 拓扑

亏格 δ = 距双稳有多远

整数不变量，纯由网络拓扑计算，决定通路"有没有资格"当开关。

03 · 通量

EFM 使用率 / 限速生成元

代谢网络的不可约生成基，¹³C 通量组学可测。

04 · 动力学

λ / DNB / 方差·自相关

模型无关：只要有足够采样率的时序即可算，最适合临界跃迁 / 毒性预警。

✅ 三条支柱都做实了

一、一套统一的临界慢化 biomarker 框架，覆盖 ~25 条通路 + 三类分岔（开关 / 时钟 / 可兴奋周期），且模型无关信号可直接落到时序数据上。二、逐位复现的精确文献模型（Markevich 到小数点），并找到通用的策展模型下载法（biomodels 镜像 + libRoadRunner），M15 得到官方 SBML 独立验证（Km5=78）。三、真实数据端到端跑通，正对照证明方法灵敏，并给出决定性实验的判据。

下一步 · 唯一的决定性实验

做一次 MEK 抑制剂滴定梯度（如 PD0325901 / Trametinib）的单细胞 ERK-KTR/EKAR live imaging，剂量跨越 ERK 关断阈值，让一部分细胞的稳态落进双稳 / 鞍结区间。预测：去趋势残差的方差与 lag-1 自相关在近阈剂量出现 ~5× 尖峰，深 ON / 深 OFF 处回落。M16→M18 流水线已就绪，拿到这种数据即可直接判定那个李雅普诺夫 biomarker 假设。

⚠️ 全程守住的诚实边界

严格的（✅）：自同构 / 纤维化压缩、CRNT δ、EFM、λ 算法（Rössler 验证）、Markevich 逐位复现、10/10 迁移、三类分岔几何、官方模型下载与验证、真实数据统计量。待验证的假设（⚠️）："λ 变号 ⇒ 凋亡 / 毒性"需实验标定；E→μ 是单调示意耦合；PK 用近似标签值；跨阈单细胞数据尚未拿到，故临界慢化 biomarker 仍未被决定性证实——这是当前真实状态。
