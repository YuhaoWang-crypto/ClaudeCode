# 方法学与设计思路（why it's built this way）

## 为什么从基因出发（gene-first）
Biomarker 本质是"通路活动的**可测代理**"，而通路 = 基因/蛋白节点组成的网络。从基因出发能把 **靶点 → 通路 → 可测标志物** 串成一条**机制因果链**，而不是从蛋白组/代谢组关联里拍脑袋挑（那是数据驱动但缺因果）。基因层还能直接挂客观证据源（Open Targets 遗传学、STRING 网络、AlphaGenome/Evo2 序列基座模型），让归因有据可依。

## 种子（seeds）怎么选
种子必须是**已验证的机制锚点**（本项目 = 5 个靶点拆成分子实体后的去重集，配体-受体对齐全）。STRING/富集都是"从种子扩展一阶邻居"——种子选错，扩展出的邻居就是噪声。种子数不是越多越好，而是"机制上必须先站稳的已知点"。

## 为什么进 STRING
把离散种子补全成**通路邻域网络**，从而能算每个节点的**拓扑中心性**（betweenness/degree）——枢纽被扰动会带动全通路，决定它作 PD 标志物的价值。`required_score=700` 只留高置信边，避免低质量互作把中心性算歪。

## 权重为什么这么配
归因 = **可测性 ×（0.65·关联 + 0.35·中心性）**：
- **关联 0.65（主导）**：与疾病有无因果/遗传关系是 biomarker **有没有意义**的第一性问题。
- **中心性 0.35（次要）**：决定能否代表整条通路做 PD；但与疾病无关的 hub 不是好 marker。0.65:0.35 让"相关性"压过"拓扑位置"，又保留拓扑信息（不漏 ACVR2B 这种低关联高枢纽的 PD 节点）。
- **可测性（乘法门，1.0/0.8/0.7/0.3）**："测不了就不是 biomarker"是硬约束 → 乘法而非加法，纯胞内被强力压低，分泌/基因型不打折。
这些是**可解释的先验超参**，不是学出来的；建议做敏感性分析（阈值 0.7/0.9、关联:中心性 0.5:0.5）看面板稳健性。

## 最小单元认证（minimal essential unit）
贪心最小覆盖：按归因累加，取累计 ≥80% 的最小节点子集 = "用最少可测标志物覆盖大部分通路证据贡献"。临床上少测省成本、降复杂度，又不漏主要机制（80% = 帕累托阈值）。

## 为什么要三方法交叉（而非一个）
三个方法用**正交信息**回答**不同问题**，各有盲区：
- **方法一（归因）** 看"疾病证据 + 可测性"——但依赖数据库收录（新靶点如 INHBE 可能关联=0，需别的证据救回）。
- **方法二（RWR 拓扑）** 看"网络中心性"——但**孤儿节点（如 GPR75，STRING 零互作）完全看不见**。
- **方法三（network-biomarker skill，动力系统）** 看"动力学不可约核心 + 临界转变早期预警"——这是前两种静态排序法**结构上给不了**的（开关能力 CRNT δ + DNB/临界慢化可测量）。
**三者收敛处 = 最可辩护的核心**；分歧处是方法签名，也有信息量。本项目肥胖网络上三法都收敛到 `ACVR2B → SMAD2/3`。

## 方法三挂接（run the network-biomarker skill）
在同一 pathway 上跑用户的 `network-biomarker` skill（`grn_pipeline`）：按其 `reference/adding-a-pathway.md` 新增 pathway 模块，复用引擎 `m1_symmetry`/`m11_fibration`（不可约核心）、`m2_crnt`/`m12_dualphos`（CRNT δ 判双稳）、`m4_dnb_lyapunov`/`m19`（DNB/临界慢化早期预警）。读**正确的分岔签名**：鞍结 → 方差+AR1；Hopf → 功率谱；SNIC → 周期/ISI。严格 ✅严谨 / ⚠️假设 标注。

## 临床落地（三类用途）
- **入组**：基因型/eQTL + 基线可测（循环配体、影像）分层。
- **进程/PD**：中心节点动态量——配体敲低↓、磷酸化节点(pSMAD2/3)、受体占位；复测/再给药周期依抑制动力学。
- **效果确认**：下游表型——影像/体成分/疾病实验室指标。
