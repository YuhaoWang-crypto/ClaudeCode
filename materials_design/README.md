# 三个独立的材料设计项目：量子点 / 上转换 / 超导

> 说明：这是**三个各自独立**的设计任务，**不是**要在同一块材料里同时实现三种效应
> （那样在物理上互相冲突——金属性超导会猝灭量子点分立态和 4f 上转换发光）。
> 每个项目给出：候选材料组合、晶体结构、为什么这样排列能实现目标效应、以及计算验证。

验证工具：**FairChem UMA**（Meta 通用机器学习势，`uma-s-1p1`，在 Modal A10G GPU 上）做几何弛豫 +
Γ 点最大声子频率；量子点带隙用 **Brus 方程**解析计算。所有脚本与数据见本目录。

## 项目一：量子点（Quantum Dots）

### 材料组合与晶体结构
| 材料 | 晶体结构 | 空间群 | 发光区 |
|---|---|---|---|
| **CsPbBr₃**（卤化物钙钛矿） | 立方钙钛矿 | Pm-3m | 可见（绿） |
| **CdSe**（II–VI） | 纤锌矿 | P6₃mc | 可见 |
| **PbS**（IV–VI） | 岩盐 | Fm-3m | 近红外 |
| **Si** | 金刚石 | Fd-3m | 红/近红外 |

### 为什么能实现量子点效应
当晶粒尺寸 < 激子玻尔半径时，电子/空穴被**三维限域**，连续能带变成**分立、尺寸可调**的能级，
带隙 Eg(R) 随半径 R 减小而增大（∝ 1/R²）。这就是“量子限域”。

### 验证
**(a) Brus 方程**（`brus_qd.py`）——带隙/发射波长随直径变化（3–8 nm 区间，<3 nm Brus 会高估）：

| 材料 | d=3 nm | d=4 nm | d=6 nm | d=8 nm |
|---|---|---|---|---|
| CdSe | 384 nm | 487 nm | 599 nm | 649 nm |
| PbS | 292 nm | 487 nm | 924 nm | 1341 nm |
| CsPbBr₃ | 280 nm | 356 nm | 440 nm | 478 nm |
| Si | 607 nm | 769 nm | 944 nm | 1020 nm |

→ 尺寸减小→带隙增大→发射蓝移，覆盖可见–近红外，**尺寸可调性成立**。

**(b) FairChem UMA 结构弛豫**——确认四个母体都是稳定能量极小点，弛豫晶格常数接近文献
（Si a=5.45 vs 5.431 Å；PbS a=6.01 vs 5.94 Å），Si Γ 声子 510 cm⁻¹ 对文献拉曼 520 cm⁻¹。

## 项目二：上转换粒子（Upconversion）

### 材料组合与晶体结构
| 角色 | 材料 | 结构 / 空间群 |
|---|---|---|
| 基质（低声子） | **β-NaYF₄**（首选） / LiYF₄ / CaF₂ | 六方 P6₃/m / 白钨矿 I4₁/a / 萤石 Fm-3m |
| 敏化剂 | **Yb³⁺**（~980 nm 吸收） | 掺入基质 A 位 |
| 激活剂 | **Er³⁺**（绿/红）、**Tm³⁺**（蓝）、Ho³⁺ | 共掺 |

典型配方：**β-NaYF₄:Yb³⁺(18–20%),Er³⁺(2%)** —— 近红外 980 nm → 可见绿/红。

### 为什么这样排列能实现上转换
1. **敏化/激活共掺**：Yb³⁺ 吸收截面大、只有一条 980 nm 跃迁，把能量**接力式转移**（ETU）给 Er³⁺；
   Er³⁺ 有近乎等间距的**真实中间态 4f 阶梯能级**（⁴I₁₁/₂→⁴F₇/₂…），两个及以上光子接力填到高能级后发出一个高能光子。
2. **低声子基质是关键**：中间态靠**多声子弛豫**损耗，速率 ∝ exp(−α·ΔE/ℏω_max)。基质最大声子能量 ℏω_max 越低，
   跨越能隙需要的声子数越多、猝灭越弱。氟化物（NaYF₄ ~350 cm⁻¹）远低于氧化物，因此效率高；金属完全不行（自由载流子瞬间猝灭）。

### 验证（FairChem UMA Γ 点最大声子频率）
| 基质 | 类型 | 声子 max (cm⁻¹) |
|---|---|---|
| **CaF₂** | 氟化物 | **378** |
| MgO | 氧化物（对照） | 529 |

→ 氟化物声子显著更软 → 多声子猝灭更弱，**定量验证了“上转换必须用低声子氟化物基质”的机理**。
（⚠️ LiYF₄ 因初始坐标过于粗糙，弛豫时体积塌缩 −39%，结果不可用；干净的氟化物结论以 CaF₂ 为准，
后续应改用文献 CIF 复算 NaYF₄/LiYF₄。）

## 项目三：超导材料（Superconductors）

### 材料组合与晶体结构
| 材料 | 结构 / 空间群 | Tc | 机制 |
|---|---|---|---|
| **MgB₂** | 六方 P6/mmm | 39 K | 声子介导、双能隙（σ 带空穴 + B 的 E₂g 声子） |
| **Nb₃Sn** | A15 立方 Pm-3n | 18 K | 常规 BCS，技术超导（强场磁体） |
| **Nb** | bcc Im-3m | 9 K | 元素 BCS 基线 |
| （高 Tc 备选）YBa₂Cu₃O₇ | 正交 Pmmm | 92 K | 铜氧面 d 波 |

### 为什么这样排列能实现超导
BCS 图像下，需要**离域巡游电子**在费米面附近通过**电声耦合**配成库珀对。MgB₂ 之所以 Tc 高：
硼的**面内 E₂g 伸缩声子频率极高**且与 σ 能带空穴强耦合 → 大的电声耦合 λ → 高 Tc。

### 验证（FairChem UMA）
| 材料 | 弛豫 a (Å) / 文献 | 声子 max (cm⁻¹) |
|---|---|---|
| **MgB₂** | 3.068 (c 3.51) / 3.086 (c 3.52) | **686** ← 即 E₂g 硼声子 |
| Nb₃Sn | 5.34 / 5.289 | 178 |
| Nb | 3.32 / 3.301 | 213 |

→ MgB₂ 的 686 cm⁻¹ 高频声子**正是驱动其 39 K 超导的 E₂g 模**（实验 ~600–670 cm⁻¹），
晶格常数与文献吻合，**结构与关键声子都得到验证**。

## Demo A · 同族金属替换（isovalent substitution）Ca²⁺→Sr²⁺→Ba²⁺
萤石 MF₂ 中把第 II 族金属逐级替换，UMA 算性质变化并与实验对比（`demoA_substitution.png`）：

| | UMA a(Å) | 实验 a | UMA 声子(cm⁻¹) | 实验 | UMA B(GPa) | 实验 | UMA M–F(Å) | 实验 |
|---|---|---|---|---|---|---|---|---|
| CaF₂ | 5.515 | 5.463 | 378 | 463 | 79.5 | 82 | 2.388 | 2.365 |
| SrF₂ | 5.863 | 5.800 | 341 | 380 | 66.1 | 70 | 2.539 | 2.511 |
| BaF₂ | 6.284 | 6.200 | 306 | 335 | 54.7 | 57 | 2.721 | 2.685 |

**规律（模拟与实验一致）**：同族向下（离子半径 Ca 1.12→Sr 1.26→Ba 1.42 Å）→ 晶格膨胀、M–F 键变长、
声子变软、体模量下降。**物理意义**：更重更软 → 上转换基质多声子猝灭更弱（BaF₂ 是更好的低声子基质）。
体模量 UMA vs 实验吻合极好（79.5/66.1/54.7 vs 82/70/57 GPa）。

## Demo B · 掺杂（doping）Nb⁵⁺ → Ti⁴⁺ 位（Nb:SrTiO₃，n 型）
在 SrTiO₃ 2×2×2 超胞里把 Ti 逐个换成 Nb（x=0,1/8,1/4,3/8），UMA 弛豫看晶格随掺杂变化（`demoB_doping.png`）：

| Nb 分数 x | UMA 赝立方 a(Å) | 膨胀 Δa(Å) |
|---|---|---|
| 0.000 | 3.947 | 0 |
| 0.125 | 3.962 | +0.015 |
| 0.250 | 3.987 | +0.040 |
| 0.375 | 4.004 | +0.057 |

**规律（Vegard 定律）**：晶格随 Nb 增加**线性膨胀**，UMA 斜率 +0.157 Å/x。
**验证**：方向与机理与实验一致——Nb⁵⁺(0.64 Å) > Ti⁴⁺(0.605 Å) 使晶格膨胀（实验 XRD 证实，见 Sci. Rep. 12, 2764, 2022）。
**电子学后果**：每个 Nb⁵⁺ 替代 Ti⁴⁺ 多带一个电子 → n 型载流子，这正是 SrTiO₃ 导电/稀释超导的来源。
（UMA 绝对晶格系统性偏大 ~1%，故用膨胀量 Δa 直接对比，去除绝对偏移。）

### 方法
两个 demo 都用 `subst_dope_modal.py`（FairChem UMA `uma-s-1p1`，Modal A10G）：变胞弛豫→晶格/能量/键长，
小胞再加 Γ 最大声子与 Birch-Murnaghan 体模量（EOS）。绘图 `plot_demos.py`。

# 进阶：替换/掺杂的性质模拟验证（① 同族替换 ② Er掺杂局域结构 ③ 真实DFT）

## ① 同族金属替换 → 性质变化（`step2_substitution.png`）
UMA 计算两组同族替换的性质变化：
- **量子点 CsPbBr₃ → CsSnBr₃（Pb→Sn，第14族）**：晶格 6.00→5.90 Å（Sn 小→收缩，实验 5.87→5.80），
  最大声子 77→50 cm⁻¹（软化），体模量 ~19 GPa（卤化物钙钛矿都很软）。实验带隙 2.3→1.75 eV（Sn 更窄，UMA 不直接给）。
- **超导 Nb₃Sn → V₃Si（A15，Nb→V, Sn→Si）**：晶格 5.34→4.69 Å（收缩，实验 5.29→4.72），
  声子 178→322 cm⁻¹（更轻原子→更硬），体模量 153→186 GPa（更刚）。两者均 A15 超导（Tc 18.3/17.1 K）。

## ② Er³⁺ 掺杂 CaF₂ 局域结构（`er_local_structure.txt`）
Er³⁺→Ca²⁺ 替换 + 近邻间隙 F⁻ 电荷补偿，2×2×2 超胞（Ca₃₁ErF₆₅，97 原子）UMA 弛豫：
- Er 变成 **9 配位**（Ca²⁺ 为 8 配位）——多出的 1 个来自补偿间隙 F⁻
- **Er–F 键收缩到 2.27–2.40 Å**（Ca–F 为 2.40 Å），最近 4 个 Er–F 被间隙 F⁻ 拉到 2.274 Å
- 这正是经典的 **CaF₂:RE³⁺ 电荷补偿中心**（上转换激活剂掺杂的真实局域结构）。
  注：NaYF₄:Er 是 Er³⁺→Y³⁺ **等价**替换（无需电荷补偿），所以是更理想的上转换基质。

## ③ 真实 DFT 能带/态密度看 n 型能级（`step3_dft_dos.png`）
用 **GPAW/PBE**（平面波，Modal 16 核）算 SrTiO₃ 掺杂前后 DOS：
- **纯 SrTiO₃**：绝缘体，**带隙 1.68 eV**（PBE 值，实验 3.2 eV，PBE 低估是已知系统误差），E_F 落在带隙中，
  价带顶=O 2p，导带底=Ti 3d。
- **Nb:SrTiO₃ (x=0.25)**：E_F 上移，**导带底（Ti 3d/Nb 4d）被 Nb 供的电子部分填充**（E_F 处 DOS≠0），
  即**简并 n 型**——这正是 SrTiO₃ 从绝缘体变导体/稀释超导体的电子结构本质。UMA 只能给出结构/能量/声子，
  这一步用真正的 DFT 补上了电子结构（能级/DOS）。

### 方法
- ① ② 用 `subst_dope_modal.py`（FairChem UMA `uma-s-1p1`）；③ 用 `gpaw_dos_modal.py`（GPAW/PBE，nbands=200% 以覆盖导带）。
- 绘图：`plot_step2_subst.py`、`plot_dos.py`。数据：`step_subdope_results.json`、`er_results.json`、`dft_results.json`。

# 高通量筛选：不断替换元素把性质推向更好（`screening.png`）
枚举元素替换 → UMA 算描述符 → 过滤稳定性 → 排序。两个真实筛选族：

## (A) 上转换基质筛选 —— 描述符有效 ✓
描述符 = 最大声子能量（越低→多声子猝灭越弱→量子效率越高）。10 个卤化物/氧化物排序：
`RbF(162) < KF(192) < NaF(277) < BaF₂(306) < SrF₂(341) < CaF₂(378) < CaO(383) < LiF(451) < MgO(525) < TiO₂(769)` cm⁻¹。
→ **氟化物全部低于氧化物**，重阳离子氟化物最低，与真实最佳基质（NaYF₄ ~350，NaLuF₄ 等低声子氟化物）一致。
描述符对上转换效率**有预测力**（但真实选基质还需 RE 溶解度、低对称晶场等）。

## (B) 超导硼化物筛选 —— 描述符失效 ✗（重要教训）
描述符 = 特征声子频率（BCS 里高声子利于高 Tc）。12 个 AlB₂ 型 MB₂ 按声子排序：
`BeB₂(979) > AlB₂(944) > CrB₂(937) > VB₂(927) > TiB₂(899) > ... > MgB₂(688) > CaB₂ > YB₂`。
**但 MgB₂ 是其中唯一的高 Tc 超导体（39 K），声子却排倒数第 3！** 声子更高的 BeB₂/AlB₂/TiB₂ 都不超导。
→ 声子频率 vs 实测 Tc **无相关**（图 C）。**单一声子描述符无法预测 Tc**，因为 MgB₂ 的关键是
**硼 σ 带被 Mg 掏成空穴、强耦合到 E₂g 声子**——这是**电子结构**特征，声子频率捕捉不到。

## 结论：能不能靠筛选把性质推更好？
**能，但要选对描述符。** 
- 上转换（低声子→高效率）这类"性质↔单一结构量"强相关的，简单描述符筛选就很有效。
- 超导 Tc 这类依赖电子结构（λ、N(E_F)、σ带填充）的，必须用**多描述符**或直接算电子-声子耦合（DFPT+Allen-Dynes），
  或用**生成式逆向设计**（MatterGen 按目标性质条件生成）+ 高通量数据库（Materials Project）。
- 严谨的现代流程：生成/枚举 → 廉价代理粗筛 → DFT 精算 → 实验验证，逐级收敛。
