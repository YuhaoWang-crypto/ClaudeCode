# SV2A 可溶化重设计：Stage 0/1 小规模预研

目标：UniProt Q7L0J3（人 SV2A）。结构来源 8JLC（2.88 Å，SV2A + LEV + BoNT/A2 Hc）、8K77（BRV）。
复现：`python stage1_analysis.py <cif> <配体残基名> <前缀>`（LEV=UKX，BRV=VLX）。

## 3. 方法局限（必须在 proposal 里注明）
1. **膜位置是近似的。** OPM 没有 8JLC 条目，PPM 未运行。这里用 UniProt TM 注释拟合膜法线，以 TM Cα 质心为中心、取 ±15 Å 的疏水厚度。**正式交付前要用 PPM 3.0 重做并比较**。
2. **只有一个构象（外开）。** 内开构象中的埋藏位点未纳入，需要 AF2/Boltz 生成内开模型后取并集，作为"不动集合"。
3. **脂质面判据是静态 rSASA（仅链 A）。** 没有跑膜内 MD，所以环形脂质和胆固醇位点尚未识别。
4. **"保守 MFS 氢键网络"尚未确定。** 需要 MSA 保守度加结构氢键分析。
5. **二聚体（8JLH）没有分析。**
6. 以上数据是纯几何分类，没有经过实验验证。

## 4. Stage 0：ChEMBL 校准集
**重要发现：ChEMBL 里人 SV2A（CHEMBL1998）只有 2 条记录**，而且都是无活性的类似物（Ki >250 µM）。可用数据都在**大鼠 SV2A（CHEMBL4381）**上，由 MCP 取回 200/211 条（上限 200，剩余 11 条未取到，**需要补取**）。

| 数据集 | 文献 | 化合物数 | 活性范围 | 备注 |
|---|---|---|---|---|
| CHEMBL857182（pIC50） | CHEMBL1148391（2004） | 44 | 3.0–7.1（跨 4 个对数单位） | 同一实验内含 LEV pIC50 6.1 与 BRV 7.0，**最适合作排序校准** |
| CHEMBL5738746（Ki/IC50） | CHEMBL5729459 | 8 个有 Ki；9 个有 IC50 | pKi 6.94–9.57 | 吡咯烷酮类，范围 2.6 个对数单位，最高 pKi 9.57 |

**数据清洗说明**：2004 年那组记录的 `standard_value` 是被错误换算的数值（高达 1e16 nM），实际 `value` 是 pIC50（单位字段为空）。已用 `value` 恢复，原始记录没有被修改。

**局限**：
- 校准集是**大鼠脑匀浆**数据，不是人 SV2A。人/鼠口袋是否完全一致需要对比序列后确认。
- 2004 文献的 pIC50 与 2025 文献的 Ki 不是同一实验，**不能混合排序**。
- 化合物数量有限，适合检验"docking / MM-GBSA / Boltz-2 能否复现排序"，不足以训练任何模型。

## 5. 对 proposal 的影响
- 口袋和 LD4 界面的锁定集可以直接写入，**Stage 1 的主要风险降为"膜位置与构象"**，工作量估计 1–2 周（含 PPM、内开模型、MSA）。
- 设计空间量化：脂质面 70 + 边界 43 = 113 个位点，占已解析 TM 残基（252）的 45%。所以"25–40% 全长突变"这个指标应改为"113 个膜内位点中 60–100% 被重设计"，全长突变率大约在 15–20%。
- 校准集已就绪，下一步是在 8JLC 上对 LEV/BRV 与 44 个化合物跑 docking 与 Boltz-2，检验排序相关性，作为 Stage 0 的 go/no-go 门槛。

## 6. Stage 0 对接校准结果（AutoDock Vina 1.2.5，8JLC 刚性受体）
脚本与结果在 `docking/`。协议：链 A 蛋白、obabel 加氢 pH 7.4；盒子以 8JLC 里 LEV 质心为中心，边长 22 Å；exhaustiveness 32，9 个构象，单个种子；54 个化合物（校准集 53 个加 BRV 作为参照）。

| 检验 | 结果 | 判断 |
|---|---|---|
| LEV 重对接（8JLC 晶体构象） | top-1 RMSD **1.17 Å** | 通过（<2 Å） |
| BRV 交叉对接（对比 8K77 构象，两结构 TM Cα RMSD 0.27 Å） | top-1 **3.1 Å**，第 7 个构象 1.0 Å | **未通过**，正确构象没有排在第一 |
| 排序：2004 年 44 个化合物（pIC50，跨 4.1 个对数单位） | Spearman **0.27**（p=0.07） | **未通过**，没有显著相关 |
| 排序：2025 年 9 / 8 个化合物 | 0.35 / 0.26（p>0.35） | 样本太小，无结论 |
| 对照：仅用重原子数预测 44 个化合物 | Spearman **0.37**（p=0.014） | 比 Vina 得分更好 |

- LEV 的 Vina 得分 -6.17，BRV 为 -7.30，方向与实验一致（pIC50 6.1 对 7.0），但这只是两个点，不能当作排序能力的证据。
- 去掉唯一的 pAct=3.0 化合物后结论不变：Vina ρ=0.26（p=0.097），重原子数 ρ=0.34（p=0.024）。
- **结论：Vina 得分在这个体系里没有超出分子大小的信息，不能用作"结合保留"的判据。** Stage 0 的 go/no-go 门槛对 Vina 是 no-go。

**局限**
- 单个种子、刚性受体、没有做重复。LEV 晶体配体的 B 因子约 130，晶体位姿本身不确定。
- 受体是 LEV 结合态，对更大的配体可能偏向。
- 活性数据来自大鼠，且 2004 年的数据在 3.0–7.1 之间分布稀疏，高活性端只有少数化合物。
- 立体化学直接用 ChEMBL SMILES，没有枚举质子化态。

**建议的下一步（按成本由低到高）**
1. 用 GNINA 或 Boltz-2 亲和力头在同一校准集上做同样检验，并与 Vina 一起作共识打分。
2. 用口袋残基约束 docking（锁定集作为约束），并多种子重复，选 top-N 构象再做 MM-GBSA 重打分。
3. 只有第 1、2 步能显著超过"重原子数"基线（ρ>0.5 且 p<0.05），才把它作为设计体的功能过滤器；否则设计体的功能验证应回到口袋几何（RMSD、氢键保持）加实验。
