模型 4

琼脂免疫扩散：沉淀线从哪来

两种构型不能混为一谈

双向免疫扩散不会出现前带/后带。两孔是恒浓度储库，凝胶内浓度比从 ∞ 连续扫到 0，等价带总能找到位置——线只会移动，不会消失（抗原越浓，线越靠近抗体孔）。真正的钟形前带/后带是试管沉淀这种封闭体系的现象：抗原大幅过量时抗体被迅速消耗进不沉淀的可溶复合物，沉淀量因此塌陷。这条钟形曲线就是模型唯一真正省钱的用途——预测出清晰沉淀线的浓度窗口，省掉棋盘滴定。

模型 5

平板凝集：前带效应是推论，不是假设

Smoluchowski 聚集方程。交联需要一端已结合抗体、另一端仍是空表位，所以桥联效率正比于 θ(1−θ)，在半饱和处最大。抗体过量时表位全被占满、无处搭桥——前带效应就这么出来的。

最优抗体浓度就是 Kd（θ=0.5 时桥联效率取到 1）。滴定曲线两端都塌陷，所以定量凝集试验必须做系列稀释——单一浓度出阴性，可能是抗体太少，也可能是抗体太多，两者无法区分。

接口

怎么接自己的药物和数据

两层接口。序列层进 FASTA，剂量层进浓度；药物通过作用机制而不是一个笼统的抑制率进入模型。

from assaysim.viral_dynamics import CellVirusParams, Drug, Antibody, apparent_ec50
from assaysim.neutralization import Virion, nt50_from_kd

# 1) 标定：用自家生长曲线拟合 病毒×细胞系 参数（不可跨组合迁移）
par = CellVirusParams(name="ASFV/PAM", beta=3e-7, k_eclipse=1/6,
                      delta=1/12, p=5.0, c=1/6, T0=1e5)

# 2) 小分子：按作用机制进入，potency 来自非细胞测定
drug = Drug("候选物-A", moa="replication", ec50_mol=100.0, hill=1.0)
res  = apparent_ec50(par, drug, moi=0.01, readout_h=72)
res["ec50_apparent"]      # 孔水平会测到的 EC50
res["shift_log10"]        # 相对分子层的系统性位移

# 3) 抗体：Kd 经占据模型进入同一个 ODE
ab = Antibody("mAb-7", kd_nM=10.0, virion=Virion("ASFV", n_spikes=100, k_hits=1))
apparent_ec50(par, ab, moi=0.01, readout_h=72)["ec50_apparent"]

# 4) 纯分子层的快速估计，不跑 ODE
nt50_from_kd(10.0, Virion("flu", 340, 1))
诚实的边界

ODE 的结构可迁移，参数不可迁移——上面的迁移检验把这句话量化成了 +0.84 log 的系统性偏差。所以每个新的 病毒×细胞系 组合都必须先用自家的生长曲线重新标定，标定之后才谈得上预测新药。
