# 顺式调控与非编码变异效应:公开数据实测

检验矩阵这一行的承诺与边界。
这一行里 SpliceAI/Pangolin 负责"剪接变异效应"预测,Enformer/Borzoi/AlphaGenome/ChromBPNet 负责序列→调控活性。
第 05 栏承诺"零样本直接预测变异效应方向";第 06 栏边界:**"预训练分数不证明该细胞内真实调控因果;质粒 MPRA 标签与内源染色质环境存在偏差"**。

本机只有 CPU,Enformer/Borzoi/AlphaGenome 这类大序列模型需要 GPU,未测。
SpliceAI(五模型集成)可在 CPU 运行,且剪接变异有大量 ClinVar 真值,是最干净的"已知答案"检验。

结论先行:**SpliceAI 在典型剪接位点近乎完美(AUROC 0.998),但信号随离剪接位点的距离迅速衰减,非典型/深内含子致病变异 85% 漏检**。
"零样本预测变异效应"只在模型擅长的变异类别(典型剪接位点破坏)成立;离开这个语法就基本失明。

## 数据(全部公开)

| 项目 | 数据 | 规模 |
|---|---|---|
| 模型 | SpliceAI 五模型集成预训练权重(随 pip 包) | 零样本,未重训 |
| 真值 | ClinVar GRCh37,SNV,染色体 1/2/17 | 1900 个变异(见下) |
| 参考序列 | Ensembl GRCh37 染色体 1/2/17 | — |

变异分组:致病·典型剪接位点 700、致病·内含子非典型 300、良性·同义 500、良性·其他 400。SpliceAI 为 1883/1900 打了分。

## 结果

### 1. 典型剪接位点:近乎完美(承诺成立)

| 对比 | AUROC |
|---|---|
| 致病典型剪接 vs 良性 | **0.998** |
| 全部致病 vs 良性 | 0.905 |
| 致病内含子非典型 vs 良性 | **0.689** |

致病典型剪接变异的 delta 中位数 0.99,良性为 0.00。按官方 0.5 阈值:典型剪接召回 98.1%,良性假阳性率 0.7%。这一类变异 SpliceAI 基本已解决。

### 2. 边界:离剪接位点越远,越失明(证实边界)

致病变异按"到预测剪接事件的距离"分层,delta≥0.5 的检出率:

| 距剪接位点 | 变异数 | delta 中位 | 检出率(delta≥0.5) |
|---|---|---|---|
| 0–2 bp(典型位点) | 734 | 0.99 | **94.1%** |
| 3–10 bp | 90 | 0.15 | 35.6% |
| 11–50 bp | 176 | 0.01 | **4.5%** |

- 致病内含子非典型变异整体:delta 中位数仅 0.02,0.5 阈值下只召回 15%,0.8 阈值下只召回 7%。也就是说**这类致病变异约 85% 被漏判为"无效应"**。
- 信号几乎全部集中在剪接位点 ±2 bp;离开 10 bp 就基本归零。

这正对应第 06 栏:预训练分数在模型擅长的位置(剪接位点语法)可靠,一旦变异的调控机制不在这套语法内(深内含子、远端增强子、组织特异调控),低分不等于无效应。"零样本"不能外推到模型没学过的调控类别。

## 对矩阵这一行的修改建议

1. 第 05 栏"零样本预测变异效应"应按变异类别限定:典型剪接位点变异可交付(AUROC ~1.0);深内含子/远端调控变异须标注"低分不可解释为阴性",并给湿实验(minigene/MPRA)兜底。
2. 交付剪接预测时同时报"到最近剪接位点的距离",作为可信度分层。
3. 第 06 栏的边界完全正确,建议作为硬性免责声明并给量化锚点(离位点 11–50 bp 检出率 4.5%)。

## 限制

- **只测了 SpliceAI 一个模型,一个任务(剪接)**:Pangolin、Enformer/Borzoi/AlphaGenome(序列→表达/染色质)、ChromBPNet(细胞特异可及性)需要 GPU 或更大下载,未测;"顺式调控活性/E-G 连接"这一半承诺未直接检验。
- 只用了染色体 1/2/17 的 ClinVar SNV;ClinVar 注释本身有提交偏差,致病剪接变异天然富集在典型位点。
- "内含子非典型"用 ClinVar 分子后果字段近似,部分可能并非剪接机制致病(会让这类的真实可检出率略有出入),但距离分层(94%→36%→4.5%)是直接从预测位置算的,稳健。
- 没有用实验性剪接文库(Vex-seq/MFASS)做定量校准,因此没有直接量化"MPRA 标签 vs 内源染色质"的偏差;这里用 ClinVar 临床真值 + 距离衰减来体现同一边界。

## 复现

```bash
python -m venv svenv && svenv/bin/pip install "numpy<2" "tensorflow-cpu==2.15.1" spliceai pyfaidx "setuptools<81"
# ClinVar: ftp.ncbi.nlm.nih.gov/pub/clinvar/vcf_GRCh37/clinvar.vcf.gz
# 参考: Ensembl GRCh37 染色体 1/2/17 fasta 合并为 ref.fa
export VB_DATA=...   # 放 variants.vcf / variants_sel.parquet / ref.fa
svenv/bin/spliceai -I variants.vcf -O spliceai_out.vcf -R ref.fa -A grch37
python 01_eval_spliceai.py   # 用主 venv (pandas/sklearn)
```
