# 微生物耐药(AMR)、毒力与药物代谢转化:公开数据实测

从微生物基因组预测耐药/毒力/药物转化。本次用公开数据做最干净的已知答案:**AMR 基因型→表型**——
携带已知耐药基因能否预测实测药敏,以及这个关系随药物/机制变化的边界。

结论先行:**查出耐药基因→确实耐药(阳性预测很准,如碳青霉烯酶→碳青霉烯耐药 96–98%);
但"没查到耐药基因"≠敏感——70% 的碳青霉烯耐药菌不带任何已知碳青霉烯酶,靠孔蛋白缺失/外排/突变耐药,基因检测看不到(危险的漏检)**。
用于精准用药预警:基因型适合"排除用药(rule-in)",不适合"确认可用(rule-out)"。

## 数据与方法(全部公开)

| 环节 | 来源 |
|---|---|
| 表型(真值) | BV-BRC(PATRIC)肺炎克雷伯菌实测药敏(Laboratory Method),~10 万条记录 |
| 基因型 | BV-BRC sp_gene 的 NDARO(= NCBI AMRFinderPlus 获得性耐药基因目录)条目 |
| 检验 | 2,355 个成功取到基因型的基因组,12 种抗生素,逐药算灵敏度/特异度/PPV/漏检 |

基因→药物类用标准获得性耐药知识映射(碳青霉烯酶→碳青霉烯;aac/aph/ant→氨基糖苷;sul/dfr→磺胺/甲氧苄啶;qnr/gyrA/parC→喹诺酮等)。

## 结果

### 1. 已知答案成立:耐药基因→耐药(阳性预测准)

携带碳青霉烯酶的基因组 meropenem 耐药率:
- **blaKPC+ → 98%** 耐药
- 任意碳青霉烯酶+ → **96%** 耐药
- 碳青霉烯酶− → 37% 耐药

基因在,表型就耐药——方法在"基因存在"这一侧非常可靠。各药 PPV:磺胺复方 0.95、meropenem 0.91、妥布霉素 0.89、环丙沙星 0.77。

### 2. 核心边界:基因缺失 ≠ 敏感(漏检严重)

| 指标(以 meropenem 为例) | 值 |
|---|---|
| PPV(基因在→耐药) | 0.91 |
| 特异度 | 0.97 |
| **灵敏度(耐药菌被基因标出的比例)** | **0.42** |
| **很严重误差 VME(漏判的耐药)** | **0.58** |

**70% 的 meropenem 耐药菌不带任何已知碳青霉烯酶**——它们靠孔蛋白缺失(ompK35/36)、外排泵、ESBL/AmpC + 渗透屏障等机制耐药,获得性基因面板看不到。全部 12 药的漏检率(VME)在 0.41–0.86,即只靠耐药基因检测会漏掉大量真实耐药。

### 3. 对精准用药预警的意义

- **可交付(rule-in)**:检出耐药基因 → 高置信度判"该药不可用"(PPV 0.9+)。碳青霉烯酶、磺胺/甲氧苄啶、氨基糖苷修饰酶等获得性机制尤其可靠。
- **不可交付(rule-out)**:未检出耐药基因 **不能** 判"该药可用"——非获得性机制(孔蛋白/外排/靶点突变)的耐药会被漏掉。临床用药预警必须以表型药敏兜底,基因型只能加速"排除"。
- 不同机制差异明显:喹诺酮(突变为主)、头孢(窄谱 vs ESBL 变体难以仅凭基因家族名区分)比碳青霉烯酶/磺胺更难。

## 限制

- **基因→药物映射较粗**:按基因家族名映射,未区分具体等位变体(如 blaTEM/blaSHV 的窄谱 vs ESBL 变体、blaOXA 的碳青霉烯酶 vs 非碳青霉烯酶型),导致头孢类 PPV 被低估、部分过预测。精确做法需 AMRFinderPlus 的等位级 class/subclass。
- **只做了 AMR,毒力与药物代谢转化未实测**:BV-BRC sp_gene 同样提供毒力因子(VFDB/Victors)与药靶,可检出毒力基因,但毒力/致病表型需感染模型验证,本次未做;肠道菌药物生物转化(如 Zimmermann 2019 的菌×药代谢)是另一套数据,未覆盖。
- BV-BRC 表型来自多实验室汇总,折点标准不一、基因组-表型连接偶有噪声;本次只用 Laboratory Method、R/S 二分,去除 Intermediate。
- 单一物种(肺炎克雷伯菌);其他病原体的机制构成不同,结论需各自标定。
- 未做 MIC 回归(只做 R/S 二分类),也未纳入基因拷贝数/表达/启动子突变。
