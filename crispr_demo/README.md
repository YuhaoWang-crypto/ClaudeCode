# 细菌基因组编辑前后比对 — 可运行 Demo

一个完整、可复现的小型案例：对一株细菌做 CRISPR/Cas9 编辑，编辑前后各做一次全基因组
重测序，然后比对出**改了什么、改了多少、改在哪、有没有脱靶**。

数据是模拟生成的（结构与真实 Illumina 下机数据一致，只是规模缩小），
但**流程里跑的全部是真实的生信工具**：fastp / BWA / samtools / bcftools / Delly / SnpEff。
整条流程在普通容器里约 15 秒跑完。

## 快速开始

```bash
# 依赖（Ubuntu/Debian）
apt-get install -y bwa samtools bcftools fastp delly snpeff tabix

cd crispr_demo
python3 scripts/01_make_reference.py     # 生成参考基因组 + 注释 + sgRNA 设计
python3 scripts/02b_make_cds_protein.py  # 生成 CDS/蛋白校验文件（供 snpEff 建库）
python3 scripts/02_simulate_reads.py     # 施加编辑结果，模拟 PE150 测序数据
bash    scripts/03_run_pipeline.sh       # 质控→比对→变异检测→过滤→比较→SV→注释
python3 scripts/04_analyze.py            # 脱靶扫描、频率换算、与真值比对
python3 scripts/05_make_report.py        # 生成 HTML 报告
```

报告在 `report/index.html`。

## 这个 demo 模拟的实验

一株大肠杆菌样的菌株（`DEMO_chr1`，60 kb 迷你染色体，47 个基因），用两条 sgRNA 编辑：

| sgRNA | 靶基因 | 目的 |
|---|---|---|
| sgRNA-1 | `pheA` | HDR 精确敲入 24 bp 终止盒 |
| sgRNA-2 | `lacZ` | 靠 NHEJ/MMEJ 的 InDel 把基因敲掉 |

两个样本：

- `WT_parent` — 编辑前的亲本克隆，120×
- `EDIT_pool` — 编辑后筛选得到的菌群，150×

**关键设定**：两个样本都带有 4 个相对参考基因组的"亲本变异"。实验室菌株和公共参考基因组
本来就有差异，这 4 个变异与编辑无关。如果只测编辑后的样本，它们会被误报成编辑结果 ——
这正是必须测编辑前样本的原因。

## 预设的编辑结果（真值）

| 编号 | 类别 | 位置 | 改动 | 设定频率 |
|---|---|---|---|---|
| A | 在靶 | 12,617 | pheA 敲入 24 bp 终止盒 → 提前终止 | 1.00 |
| B | 在靶 | 26,314 | lacZ 7 bp 缺失 → 移码 | 0.55 |
| E | 在靶 | 25,900 | 跨切点 1,150 bp 大片段缺失 | 0.45 |
| C | 脱靶 | 38,227 | yjgF 1 bp 插入 → 移码（3 个错配的脱靶位点） | 1.00 |
| D | 脱靶 | 33,214 | 基因间区 5 bp 缺失（4 个错配的脱靶位点） | 0.30 |
| F | 背景 | 49,656 | rpoB 错义突变，与 sgRNA 无同源性 | 1.00 |

B 和 E 在同一个切点上互斥（55% 的细胞是小缺失，45% 是大缺失）。
参考基因组里还人为"种"了一个与 sgRNA-2 只差 2 个错配的位点（`nuoF`），
但该位点没有编辑 —— 用来检验"预测到脱靶位点"不等于"真的脱靶"。

## 流程结果

- 真值事件 **10/10 全部检出**，编辑特异变异中无法解释的假阳性 **0 个**
- 频率估计的最大偏差约 6 个百分点，全部落在各自的 95% 置信区间内
- 单倍体模型（`--ploidy 1`）会漏掉 30% 频率的亚克隆脱靶，混合群体必须用保留等位基因
  频率的检测方式
- 1,150 bp 缺失完全不出现在 SNV/InDel 的 VCF 里，只能靠覆盖度塌陷 + Delly 的
  异常配对/断裂读段检出

## 几个值得注意的技术点

**VCF 的 InDel 左对齐。** 敲入设计在 12,617，bcftools 报在 12,614。比对真值时必须
允许这个位移，否则会误判成漏检。

**长插入的 AD 会低估频率。** pileup 把被软剪切的读段算作参考支持，24 bp 敲入按 AD 算
只有 0.62，按"必须完整跨越事件区间"重新计数才是 1.00。`04_analyze.py` 里两种都算。

**局部频率不等于群体频率。** lacZ 7 bp 缺失的局部 VAF 是 1.00，因为携带大片段缺失的
那 45% 细胞在该位点根本没有读段。用局部覆盖度（以编辑前样本归一化）换算回去才得到 0.56。

**脱靶归因要两头看。** 只看"编辑后独有"会把自发突变误报成脱靶；只看"与 sgRNA 相似"
会把没发生编辑的位点误报成脱靶。本 demo 两类反例都有。

## 局限

脱靶打分只用了错配数和种子区位置的简化规则，真实项目应当用 Cas-OFFinder 做全基因组搜索、
CFD/MIT 评分排序，并用 GUIDE-seq / CIRCLE-seq 等实验方法验证。短读段看不全倒位、易位和
质粒骨架整合，细菌项目通常补一条长读段测序。模拟数据不含 GC 偏好、嵌合读段、索引跳跃等
真实噪声，所以这里 100% 的比对率和 0 假阳性在真实项目中不会出现。
