## 为什么几何描述子不是纯粹的凑合

沙漠 / 排斥 / 炎症这个三分类是相对肿瘤边界定义的。但把定义拆开看：

| 表型 | 它的几何长什么样 |
|---|---|
| 沙漠型 | 哪里都几乎没有浸润 |
| 排斥型 | 有浸润，但聚成带状或环状，**不进入它所包围的组织内部** |
| 炎症型 | 浸润分布在组织内部 |

**只有中间那一列提到了肿瘤。** "聚成带状、不进入内部"是关于一个点模式在组织区域内如何排布的陈述，
可以直接测量。

### 核心描述子：渗透（penetration）

对每一个组织 patch，算它到最近的 TIL 阳性 patch 的距离。

- **炎症型**：分布短尾——没有哪里离淋巴细胞很远。
- **排斥型**：长尾——带状浸润把大片内部留在外面。
- **沙漠型**：也是长尾，但几乎没有 TIL 可供测距——所以渗透必须和"量"一起读，不能替代它。

这正是原文两步结构的几何版本：**先用量分出沙漠，再用渗透分排斥与炎症。**

### 在理想表型上验证

三个人工构造的表型放在同一个组织圆盘上：

| 描述子 | 沙漠 | **排斥** | **炎症** |
|---|---|---|---|
| TIL 占组织比例 | 0.010 | **0.317** | **0.161** |
| **unreached 比例** | 0.015 | **0.506** | **0.000** |
| **penetration p90** | 0.070 | **0.493** | **0.017** |
| band_index（带状程度） | 0.00 | **16.45** | 4.69 |
| Moran's I | 0.000 | 0.962 | −0.003 |

**排斥型的浸润量比炎症型还多**（0.317 vs 0.161），所以"量"完全分不开它们；
而渗透分得干干净净（unreached 0.506 vs 0.000）。四条测试把这个性质钉住了。

### 尺度无关

距离除以组织的等效半径，计数除以组织面积。否则描述子编码的是标本大小——
那是取材的性质，不是免疫反应的性质。有专门的测试验证：把标本放大一倍，
归一化后的描述子不变。

共 **24 个描述子**：量 3、聚集 4、渗透 4、形状 3、多尺度 10（Ripley's L 与 lacunarity 各 5 个尺度）。

## 生物学验证：这三组是不是名副其实

这一步决定前面所有东西有没有意义。136 例全部有 RNA-seq（其中 45 例是这一轮补下的）。

**预设的可证伪排序**：炎症型的 CD8/干扰素信号最高，沙漠型最低，排斥型居中但高于沙漠型。

| 转录组签名 | 沙漠 | 排斥 | 炎症 | Kruskal p | 排序 |
|---|---|---|---|---|---|
| **CD8 核心签名** | −0.392 | −0.033 | **+0.106** | **0.026** | ✅ 成立 |
| TIS（18 基因炎症） | −0.250 | +0.121 | +0.092 | **0.023** | ⚠️ 排斥略高于炎症 |
| 细胞溶解（GZMA/PRF1） | −0.324 | −0.155 | +0.192 | 0.109 | ✅ 成立但不显著 |
| **EPCAM（上皮阴性对照）** | −0.059 | −0.038 | +0.087 | **0.846** | 干净（无差异） |

CD8 与 TIS 都显著（p=0.026 / 0.023），阴性对照干净（p=0.85）。
**这三组携带真实的免疫生物学信号，不是几何噪声的任意切分。**

TIS 那一行的排序被打破了（排斥 +0.121 略高于炎症 +0.092），但两者差距很小，
而且这在生物学上并非不可能——排斥型肿瘤常有活跃的干扰素信号却伴随物理性排斥。
不过在 n=45/45 上，这个差距也完全在噪声范围内，不应过度解读。

⚠️ 一个必须自我纠正的点：EPCAM 那一行的"排序"方向上也成立（−0.059 → −0.038 → +0.087），
但它的 Kruskal p=0.85。**方向成立而不显著，就是噪声。** 报告里同时给出方向和 p 值，
就是为了防止只看方向。

### 排布在"量"之外多带来了什么

用给定 TIL 量的偏 Spearman 相关（这样描述子就不能只是在复述"有多少浸润"）：

| 描述子 | 与 CD8 的边际 ρ | **给定量后的偏相关** |
|---|---|---|
| interface_density | −0.402 (p<0.001) | **−0.185** |
| largest_cluster_share | +0.277 | +0.146 |
| unreached_fraction | −0.180 | +0.144 |
| morans_i | +0.296 | +0.143 |
| gini_cluster_size | +0.396 | +0.133 |

n=136 时 p<0.05 对应 |ρ| ≈ 0.17，所以**只有 interface_density 一个越过了线**。

诚实的结论：**排布确实携带"量"之外的信息，但幅度很小**（偏相关 0.13–0.19）。
而且我看了 24 个描述子，所以这个排名本身也带多重性——单个 |ρ|=0.185 在 24 次比较里不算什么。

## 监督实验：MRI 能不能预测这个表型

这是本项目第一次能同时测原文的**两个**任务——`RM-peri`（沙漠 vs 排斥）此前完全无法评估。

| | **RM-whole**<br>炎症 vs 其余 | **RM-peri**<br>沙漠 vs 排斥 |
|---|---|---|
| 样本 | n=91（26 阳性） | n=65（34 阳性，炎症例已剔除） |
| 选中模型 | random_forest | random_forest |
| 训练集 CV | 0.641 | 0.585 |
| 置换零分布 95% | 0.681 | 0.701 |
| **置换检验 p** | **0.096** | **0.326** |
| **锁定测试集 AUC** | **0.713**<br>95% CI [0.512, 0.881] | **0.440**<br>95% CI [0.180, 0.710] |
| **原文报告** | 0.985 | 0.984 |

两个任务的多重性门槛 0.730，最佳 CV 观测 0.641 —— **没过**。

**RM-whole 是本项目至今最好的结果**：锁定测试集 0.713，CI 下界 0.512 高于 0.5。
换用几何表型标签，把测试集 AUC 从上一轮的 0.567（三分位 TIL 量标签）提到了 0.713。

**但有三条必须同时说：**

1. **置换检验没过。** 快速版里 p=0.049，完整的 300 次置换下变成 **p=0.096**。
   又一次同样的教训：置换次数一多，"显著"就消失了。这与纹理特征那次是同一种现象。
2. **RM-peri 是零结果**：0.440（CI [0.180, 0.710]），
   置换 p=0.326。**原文这个任务报的是 0.984。**
3. **测试集只有 28 例**（8 阳性），
   CI 宽 0.369。这个划分分不出 0.71 和 0.88。

## 全项目范围的多重性核算

每个实验都对**它自己**试过的变体做了校正。但没有人对**整个项目**试过的目标做校正——
而"局部校正、全局搜索"正是本项目一直在测量的那种失败模式，它同样适用于我们自己。

`scripts/project_multiplicity.py` 把项目里评估过的每一个二分类目标收集起来，重算门槛。

项目至今评估过的**全部 10 个二分类目标**：

| 目标 | 来源 | 训练集 CV | 自身零分布 95% |
|---|---|---|---|
| texture features only | model optimization | 0.642 | 0.644 |
| RM-whole | geometry experiment | 0.641 | 0.681 |
| Moran's I high vs low | model optimization | 0.622 | 0.621 |
| tertile split (primary) | model optimization | 0.590 | 0.619 |
| RM-peri | geometry experiment | 0.585 | 0.701 |
| morphology features only | model optimization | 0.536 | 0.624 |
| ComBat by scanner | model optimization | 0.520 | 0.613 |
| extreme tertiles only | model optimization | 0.512 | 0.665 |
| kinetic features only | model optimization | 0.486 | 0.635 |
| median split | model optimization | 0.459 | 0.627 |

**全项目门槛（10 个目标下零分布最大值的 95 百分位）：0.742**
最佳 CV 观测：0.642（texture features only）→ **没过**。

锁定测试集不受这条 CV 门槛保护——它是一次独立的单次评估。
但它同样不能免疫于此前的搜索：**被评估的那个目标，是在看过其他目标之后才选定的。**

| 到达锁定测试集的目标 | 测试集 AUC | 95% CI | |
|---|---|---|---|
| RM-whole（几何表型） | 0.713 | [0.512, 0.881] | CI 不含 0.5 |
| RM-peri（几何表型） | 0.440 | [0.180, 0.710] | CI 含 0.5 |
| 三分位 TIL 量（上一轮主分析） | 0.567 | [0.344, 0.789] | CI 含 0.5 |

**诚实的总结**：几何标签把测试集 AUC 从 0.567 提到 0.713，这是真实的改进；
但在项目已经试过 10 个目标之后，它既没过全项目门槛，置换检验也只到 p=0.096。
正确的表述是**「值得预注册一次重复验证的线索」，不是「已经建立的结果」**。

## 这一轮学到了什么

1. **几何路线是可行的，而且不是凑合。** 它在人工表型上干净地分开了排斥与炎症，
   在真实数据上产生的三组携带显著的免疫转录组信号，阴性对照干净。
2. **它把 RM-peri 从"完全无法评估"变成了"可以评估"** ——这是本轮最实质的进展。
3. **排布在量之外的增量很小。** 偏相关 0.13–0.19，只有一个越过显著线。
   这限制了任何基于排布的模型的天花板。
4. **标签侧扩到了 136，影像侧还是 91。** 下一步真正的瓶颈是专家分割，不是 TIL 标签。
5. **置换次数不够会制造"显著"。** 这一轮里两个结果在快速版（40–60 次置换）下 p<0.08，
   在完整版（200–300 次）下都退回不显著：纹理特征 0.073 → 0.060 且不再越过自身零分布，
   RM-whole 0.049 → 0.096。**置换检验的次数本身就是一个会影响结论的参数**，
   报告时必须写出来。本项目所有最终数字都用完整次数。
