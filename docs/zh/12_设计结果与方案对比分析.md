## 1. gRNA 设计:脱靶可能性、覆盖缺口、效果

### 1.1 脱靶可能性(预期)

设计通过三层过滤把脱靶风险压到最低(见 `03_脱靶预测.md`):

| 过滤 | 作用 | 预期效果 |
|------|------|----------|
| 无 0-mismatch 其他位点 | 排除完全脱靶 | 硬性,近 100% 引导满足 |
| 无外显子 1-mismatch 脱靶 | 排除最危险的近脱靶 | 淘汰约 5–15% 候选 |
| CFD 特异性 ≥ 0.2 | 综合特异性下限 | 从 Brunello 取子集时绝大多数已达标 |

**预期结论:** 若以 **Brunello**(每基因 4 条、已做脱靶最小化)为核心再补足,预期
**>95% 入选引导为高特异性**(无外显子近脱靶)。真实分布要跑 GuideScan2 才能给出
每条引导的 `n_off_1mm / n_off_exonic / CFD` 三列。

### 1.2 覆盖缺口:哪些激酶难覆盖

这是设计中最需要提前预警的部分。**并非所有 518 个激酶都能拿到 6 条高质量引导**,
难点集中在几类:

| 难覆盖类别 | 代表 | 为什么难 | 应对 |
|------------|------|----------|------|
| **高同源旁系家族** | AURKA/B/C、CDK 家族、PIM1/2/3、AKT1/2/3、MAP2K 家族、RAF(BRAF/RAF1/ARAF) | 引导易在旁系上出现近匹配 → 过滤后可用引导数下降 | 可能只剩 3–4 条达标;必要时人工检视 CFD 边界 |
| **有加工假基因/多拷贝** | 部分含 retrogene 的激酶 | 增加"多完美匹配"风险 | 严格 0-mismatch 过滤会淘汰,导致候选变少 |
| **短 CDS / 少组成型外显子** | 小激酶、单外显子基因 | 早期组成型外显子窗口小 → PAM 可选位点少 | 放宽切割窗口或接受 <6 条 |
| **高/低 GC 区基因** | GC 极端的激酶座位 | GC 过滤(30–70%)剔除多数候选 | 局部放宽或改用替代 PAM |

**预期量级(估计,需实跑确认):** 约 **~500/518 基因可拿满 6 条**达标引导;
**约 10–20 个基因**需人工处理(拿到 3–5 条,或放宽某项过滤)。这类基因应在
`data/selected_guides.tsv` 里用 `n_guides<6` 或 `flag` 列标出,并在解读时降低置信度
(单基因假阴性风险高)。

> 关键提醒:高同源家族(AURK、CDK、AKT、PIM)既难设计**又**是重要靶点。它们即使
> 拿到引导,也要警惕"一条引导切多个旁系"造成的表型串扰——解读时看多引导是否一致。

### 1.3 效果(on-target 活性,预期)

- **活性排序**:Rule Set 3 + DeepSpCas9 双模型取综合排名,预期入选引导中位活性高。
- **冗余保护**:6 条/基因(比全基因组库的 4 条更冗余)→ 单基因假阴性率低;要求
  6 条中 ≥3 条一致才算命中,进一步压低假阳性。
- **经验背书**:核心取自 Brunello,已在多项全基因组筛选中实验验证,不是纯计算预测。

## 2. 为什么想到化学基因组 / 合成致死筛选

这不是额外加戏,而是一条清晰的推理链:

1. **纯 dropout 的盲区**:必需性筛选只看得到细胞在标准培养下的依赖——大多是
   **泛必需基因**(所有细胞都需要),情境特异的脆弱性看不到,转化价值有限
   (泛必需靶点往往不可成药、毒性大)。
2. **对照臂本来就要跑**:双臂设计里溶剂(DMSO)臂是必需性筛选的实验组;在它旁边
   再加一个加药臂,**边际成本极低**(单药只 +3 样本、+约 13M reads),信息量却翻倍。
3. **激酶是最可成药的靶类**:KO × 抑制剂 = 直接映射到**联用治疗**。激酶组筛选做
   合成致死,产出天然就是"哪个激酶敲了能让某药更有效"——可直接接临床。
4. **临床现实倒逼**:靶向单药几乎必然耐药(如 BRAFi 单药耐药),标准解法是**联用**;
   合成致死筛选正是系统性地**找联用伙伴**。这也是我用 A375+vemurafenib 举例、并查到
   ≥36 项 BRAFi+MEKi 试验来印证的原因。
5. **数据基础**:DepMap/CCLE 已证明大量依赖是**选择性**的,只在特定遗传背景或药物
   压力下显现——这类信号纯 dropout 抓不到,必须靠"背景/药物 × KO"的交叉设计。

一句话:**必需性告诉你细胞离不开谁;合成致死告诉你加了药之后细胞离不开谁——后者
才指向可落地的联用策略。**

## 3. 两种方案效果对比

| 维度 | 必需性 / 丢失筛选(A 线) | 化学基因组 / 合成致死(B 线) |
|------|--------------------------|------------------------------|
| **检测目标** | 该细胞系依赖的激酶 | 改变药物敏感性的激酶(增敏/耐药) |
| **比较** | T_end(DMSO) vs T0 | T_end(Drug) vs T_end(DMSO) |
| **主分析** | BAGEL2(贝叶斯因子) | drugZ(normZ) |
| **统计功效** | **高**——信号强、无需剂量窗口、有 CEG/NEG 校准 | **中**——取决于剂量窗口是否设对(易失败点) |
| **信号来源** | 敲除→细胞死/增殖慢 | 敲除在药物压力下的**增量**效应 |
| **对照** | T0 参照 + 泛必需/非必需基准 | 溶剂臂扣除基础必需性(关键) |
| **KO 的适用性** | 好——丢失即信号 | **增敏方向强,耐药方向弱**(激活型耐药 KO 查不到,需 CRISPRa/ORF) |
| **转化价值** | 较弱——泛必需靶点难成药 | **强**——直接产出联用候选 |
| **典型失败模式** | 倍增次数不足→必需信号未分离 | 剂量太低(无压力)/太高(压垮群体丢覆盖度) |
| **成本** | 基础成本(溶剂臂 + T0) | 边际成本(单药 +3 样本) |
| **何时用** | 找新依赖、建 baseline、做细胞系画像 | 找联用伙伴、机制解析、克服耐药 |

### 3.1 关键结论

- **功效**:A 线(必需性)统计功效更高、更稳,因为丢失是强信号且不依赖外部药物
  窗口;B 线(合成致死)功效取决于剂量,是整个实验最脆弱的环节。
- **价值**:B 线转化价值更高——它直接回答"加什么药能增效",而 A 线多产出泛必需
  的、难成药的靶点。
- **互补而非二选一**:两者检测的是不同层面的依赖。**合并设计**让 B 线搭 A 线的
  便车(共享文库、转导、T0),用最小增量成本同时拿到两套结论——这就是我们最终
  采用双臂方案的原因。
- **方法学边界**:KO 筛选对**增敏/合成致死**方向强,对**激活型耐药**方向天然欠
  功效(临床耐药多由 RTK 上调、COT、CRAF 等获得功能事件驱动)。要系统查耐药,应
  另做 **CRISPRa 或 ORF 过表达**筛选,而非敲除。

## 4. 要拿到"真实结果"还需做什么

本设计给的是方案与预期。要把第 1 节的"预期"变成"实测",需要:

1. 运行引导设计流程(CRISPOR / GuideScan2 / FlashFry)→ 产出 `data/selected_guides.tsv`
   与 `data/offtarget_report.tsv.gz`(真实 per-guide 活性 + 脱靶 + CFD)。
2. 统计:达标引导数分布、每基因引导数、被 flag 的覆盖缺口基因清单。
3. (可选)在你的细胞系变异背景下重算脱靶(见 `03` 第 5 节)。
