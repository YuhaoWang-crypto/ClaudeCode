# 加药臂实操：剂量预实验、给药方案与命中判读（含可替换范例）

本页把 `07_两种筛选设计.md` 里的"加药臂"落到可直接执行的程度。范例采用
**A375（BRAF^V600E 黑色素瘤）+ BRAF 抑制剂 vemurafenib（PLX4032）**，仅作
模板——把细胞系、药物、剂量换成你自己的即可（占位符标为 `<...>`）。

> 说明：范例中的具体细胞系/药物只是示例锚点。真正决定加药臂成败的是**你在
> 自己细胞系上实测的剂量-反应**，而不是文献 IC 值——所以下面第 1 步是必做的。

**范例药物核对（ChEMBL v34 实查）：**

| 项 | 值 |
|----|----|
| 药物 | Vemurafenib（Zelboraf；研究代号 PLX4032 / RG7204） |
| ChEMBL ID | CHEMBL1229517 |
| 机制 | **BRAF（丝/苏氨酸激酶）抑制剂**，直接结合，针对 **V600E** 突变型 |
| 靶点 | BRAF（CHEMBL5145，UniProt P15056 V600E） |
| 状态 | 已上市（2011 FDA 批准，first-in-class，USAN 词干 `-rafenib` = RAF 激酶抑制剂） |

即：加药臂对 A375（BRAF^V600E）施加的是**通路（MAPK）靶向压力**，正好让"敲除
后改变 MAPK 依赖性"的激酶显形——与 `07/08` 的合成致死逻辑一致。

## 1. 剂量预实验（定 IC20–IC30）——必做

目的：找到一个**亚致死浓度**，在整个筛选期施加温和而持续的选择压力，既不压垮
群体、又能让"增敏/耐药"的引导显著偏移。

### 1a. 短期剂量-反应（72 h）

| 项 | 设置 |
|----|------|
| 板型 | 96 孔（或 384），每浓度 ≥3 复孔 |
| 接种 | `<2000–5000>` 细胞/孔，贴壁 24 h（按细胞倍增时间调整，保证 72 h 内不长满） |
| 药物梯度 | 8–10 点，2–3 倍系列稀释，跨越预期 IC50 上下各两个数量级 |
| 对照 | 等体积 DMSO 溶剂孔 + 无细胞空白孔 |
| 孵育 | 72 h |
| 读出 | CellTiter-Glo（ATP 发光）或 resazurin，归一到溶剂孔 |
| 拟合 | 四参数逻辑斯谛曲线 → 读出 GI50/IC50，以及 **IC20–IC30**（抑制增殖 20–30% 的浓度） |

### 1b. 慢性剂量校验（关键，常被跳过）

72 h 的 IC 与**筛选期（~3 周）持续给药**下的等效抑制不同。用小规模生长曲线
验证所选浓度在长程下确实只把**增殖速率**压低约 20–30%：

- 6 孔板，`<所选 IC20–IC30 浓度>` vs. DMSO，各 3 复孔。
- 每 2–3 天计数/传代 10–14 天，画累计群体倍增曲线。
- 目标：加药臂倍增速率约为溶剂臂的 **70–80%**。据此微调终浓度。

**产出：** 一个终浓度 `<C_screen>`（例：vemurafenib 常在亚微摩尔级；以你的实测
为准），供筛选加药臂使用。

## 2. 给药方案

| 项 | 设置 |
|----|------|
| 起点 | T0（嘌呤筛选后）分流，一半进溶剂臂、一半进加药臂 |
| 浓度 | 加药臂恒定 `<C_screen>`；溶剂臂等体积 DMSO |
| 补药 | 每次换液/传代（每 2–3 天）重新补足药物至 `<C_screen>` |
| 时长 | 至约第 21 天（≈ 8–10 次群体倍增） |
| 覆盖度 | 两臂全程维持 **≥1000× 每引导细胞数**（加药臂增殖慢，必要时加大起始量或延时以累计足够倍增） |
| 重复 | 每臂 ≥3 生物学重复 |

## 3. drugZ 对比矩阵（合成致死/耐药读出）

drugZ 比较的是**同一 T_end 下 加药 vs. 溶剂**（不是 vs. T0——那会混入基础
必需性）：

| 对比 | control（-c） | treatment（-x） | 读出方向 |
|------|----------------|------------------|----------|
| 合成致死/增敏 | T_end(DMSO) ×3 | T_end(Drug) ×3 | **加药下更丢失** → 敲除使药物更致命（增敏/合成致死） |
| 耐药/抗性 | 同上 | 同上 | **加药下富集** → 敲除赋予耐药 |

drugZ 单次运行同时给出两个方向（normZ 负=增敏，正=耐药）及 rank、FDR。

## 4. 预期命中类别（兼作内部阳性对照）

以 BRAFi 范例说明两类信号——**类别是可靠的，具体基因请以你的数据和文献为准**：

- **耐药/富集（敲除 → 存活）：** 重新激活 MAPK 通路的节点。经典类别是
  **RTK 介导的旁路重激活**（如 EGFR、PDGFRB、IGF1R、FGFR 家族）、以及
  RAF/MEK 层的代偿（RAF1/CRAF、MAP2K1、MAP3K8/COT）。这些在耐药方向出现，
  说明筛选压力窗口设对了。
- **增敏/丢失（敲除 → 更易死）：** 与 MAPK 抑制**合成致死**的存活/反馈节点
  （如维持增殖的细胞周期激酶、抑制通路反馈重激活的成分）。它们在加药臂比溶剂
  臂更强丢失。

> 判读要点：先看这些**已知类别**是否按预期方向出现——若出现，说明剂量与压力
> 窗口合理，新命中才可信；若两个方向都平，多半是剂量太低或时长不足。
