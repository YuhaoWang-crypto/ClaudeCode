# 引导 RNA（sgRNA）选择——挑选最优引导

目标：为每个激酶基因挑选一组 sgRNA，使其能够 (a) 在所有转录本的早期外显子
切割、确保功能缺失；(b) 高效切割（高 on-target 活性）；(c) 特异性好
（脱靶风险低，详见 `03_脱靶预测.md`）。

## 1. 核酸酶与 PAM

- **SpCas9**，PAM = `NGG`，20-nt 间隔序列（spacer）。默认首选：on/off-target
  模型最成熟，且有最多经过验证的现成文库。
- 可在蛋白/mRNA 层面考虑**高特异性变体**（eSpCas9(1.1)、HiFi Cas9）以降低
  脱靶切割；它们不改变引导设计，但提升编辑精确度。

## 2. 切在哪里（位置规则）

1. **靶向早期组成型编码外显子**——限定在所有蛋白编码转录本共有（组成型）
   的最靠 5′ 的外显子，通常在 **CDS 的 5–65%** 窗口内。早期移码 → NMD/截断。
2. **避开第一个外显子/起始密码子附近**（下游 ATG 可能重新起始翻译而"逃逸"），
   也避开最后一个外显子（会逃避 NMD）。
3. **优先编码激酶结构域（或其上游）的外显子**，即使产生框内 indel 也能破坏
   催化功能。
4. **避开可变/跳跃外显子**——落在盒式外显子上的引导会漏掉缺该外显子的异构体。
5. 确保这条 20-mer **唯一**映射到目标位点（见脱靶文档）。

## 3. On-target 效率打分

用现代活性模型对候选 spacer 排序，保留高分者：

| 模型 | 说明 |
|------|------|
| **Rule Set 3（Sanson et al. 2018）** | 当前 Broad 标准；Brunello 文库的基础。**主排序器。** |
| **DeepSpCas9（Kim et al. 2019）** | 深度学习 on-target；强力的独立交叉验证 |
| **Azimuth / Rule Set 2（Doench et al. 2016）** | 应用广、验证充分，作为备选 |

取**综合排名**（例如 Rule Set 3 + DeepSpCas9 的百分位均值），避免仅凭单一
模型的偏差选到引导。

## 4. 硬性序列过滤（任一不通过即淘汰）

- **连续 T：** spacer 内不得出现 `TTTT`（会提前终止 Pol III 转录）。
- **GC 含量：** 保持 30–70%（<25% 或 >80% 淘汰）。
- **同聚物：** 任何碱基不得连续 ≥5；避免极端重复。
- **克隆位点冲突：** 内部不得含 **BsmBI（`CGTCTC`）/ Esp3I** 或
  **BbsI（`GAAGAC`）** 位点（及其反向互补）——会破坏 Golden-Gate 组装。
  需与你载体的克隆酶匹配。
- **常见 SNP：** 淘汰与你细胞系背景中高频 dbSNP 变异重叠的 spacer 或 PAM
  （否则引导与真实基因组不匹配）。
- **U6 起始：** 用 U6 启动子时首位偏好 `G`；若 spacer 不以 G 开头，在前面
  补一个 G（成 21-nt）或改选以 `G` 开头的位点。

## 5. 每基因引导数与冗余

- **每基因 6 条 sgRNA** 是这种小型激酶组文库的推荐默认——比全基因组文库
  （常用 4 条）冗余更高，因为聚焦文库扩增成本低。若追求最高置信度且细胞/
  测序读数充足，可用 **每基因 8 条**。
- 尽量把 6 条引导分散到 **≥2 个组成型外显子**，避免单个注释错误的外显子
  拖垮整个基因。
- 去冗余：绝不纳入切割位点相同或极近（≤2 nt 偏移）的两条引导。

## 6. 对照（要内建到文库中）

| 对照类型 | 数量 | 作用 |
|----------|------|------|
| **非靶向对照（NTC）** | ~200–250 | 零假设分布/归一化基线 |
| **基因间"安全"切割** | ~50 | 控制切割毒性（与基因敲除无关的 DNA 损伤） |
| **阳性必需（激酶）** | 如 PLK1、CDK1、AURKB、EEF2K… | 预期强烈丢失 → 确认筛选有效 |
| **泛必需（非激酶）** | Hart CEGv2 子集 | 必需性分类器的基准（ROC/PR） |
| **非必需参照** | Hart NEGv2 子集 | 分类器校准的阴性基准 |

基因间切割对照在**激酶**筛选中尤其重要：激酶包含 DNA 损伤节点，你需要把
真实依赖性与通用双链断裂毒性区分开。

## 7. 复用已验证文库 vs. 从头设计

**强烈建议从已验证文库出发、取激酶组子集**，再补足：

- **Brunello**（人，每基因 4 条，Rule Set 2/3，脱靶最小化）——取激酶组
  符号的子集 → 立即获得经过实验验证的核心。
- **TKOv3**（Hart 实验室，~71k 条，全基因组）——备选子集来源。
- 用上述规则通过 **CRISPOR**、**GuideScan2** 或 **FlashFry** 每基因再补
  2 条新设计引导（补到 6 条），填补缺口、提升冗余。

完全从头设计也可以，但与经充分基准测试的公共文库存在重复；混合方案能同时
获得已验证引导与冗余。

## 8. 工具汇总

| 任务 | 工具 |
|------|------|
| 端到端候选设计 + 打分 + 脱靶 | **CRISPOR**（网页/命令行）、**GuideScan2** |
| 批量/全基因组设计 | **FlashFry**、**GuideScan2**（预计算） |
| On-target 重新打分 | Rule Set 3（`rs3`）、DeepSpCas9 |
| 组成型外显子注释 | Ensembl BioMart / GENCODE basic + APPRIS 主异构体 |

## 本阶段输出

每基因一张表（`data/selected_guides.tsv`，由你运行时生成——工作文件，按
文件名引用），字段包括：
`gene, transcript, exon, spacer(20nt), PAM, strand, cut_site, rs3_score,
deepcas9_score, GC, cfd_specificity, chosen(bool)`。
