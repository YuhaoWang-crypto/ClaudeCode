# 分析命令速查（MAGeCK / BAGEL2 / drugZ）

一份可直接改用的命令清单，串起 `06_分析.md` 与 `07/08` 的双线分析。占位符标为
`<...>`。假设已装好 `mageck`、`BAGEL2`（`BAGEL.py`）、`drugz`（`drugz.py`）。

---

## 0. 输入文件约定

- **文库文件** `library.csv`：三列 `sgRNA_id,sequence,gene`。
- **样本**（对应 `templates/sample_sheet.csv`）：
  `plasmid, T0_1..3, DMSO_1..3, DRUG_1..3`。

---

## 1. 计数：FASTQ → 计数矩阵

```bash
mageck count \
  --list-seq library.csv \
  --sample-label plasmid,T0_1,T0_2,T0_3,DMSO_1,DMSO_2,DMSO_3,DRUG_1,DRUG_2,DRUG_3 \
  --fastq plasmid.fq T0_1.fq T0_2.fq T0_3.fq \
          DMSO_1.fq DMSO_2.fq DMSO_3.fq DRUG_1.fq DRUG_2.fq DRUG_3.fq \
  -n kinome_screen
# 产出 kinome_screen.count.txt（引导×样本计数矩阵）+ .countsummary.txt（质检）
```

质检看 `.countsummary.txt`：比对率（≥65%）、零计数引导、Gini 指数。

---

## 2. A 线——必需性/丢失（溶剂组 vs. T0）

### 2a. BAGEL2（主，贝叶斯因子）

```bash
# 计算 fold-change（以 T0 为参照列）
BAGEL.py fc -i kinome_screen.count.txt -o kinome_fc -c T0_1,T0_2,T0_3

# 计算 Bayes Factor（用 CEGv2/NEGv2 先验）
BAGEL.py bf -i kinome_fc.foldchange -o results/essentiality_bagel.tsv \
  -e CEGv2.txt -n NEGv2.txt -c DMSO_1,DMSO_2,DMSO_3
# BF 越高越必需；配合 precision-recall 用 CEG/NEG 校准阈值
```

### 2b. MAGeCK RRA（辅，基因级 LFC/排名）

```bash
mageck test -k kinome_screen.count.txt \
  -t DMSO_1,DMSO_2,DMSO_3 -c T0_1,T0_2,T0_3 \
  -n results/essentiality_mageck
```

> 拷贝数偏差校正：必需性结果建议再过一遍 **Chronos/CERES**，避免扩增区切割毒性
> 被误判为依赖性（见 `03_脱靶预测.md` 第 5 节、`06_分析.md` 第 3 节）。

---

## 3. B 线——化学基因组/合成致死（加药 vs. 溶剂）

### drugZ（主）

```bash
python drugz.py \
  -i kinome_screen.count.txt \
  -o results/synlethal_drugz.tsv \
  -c DMSO_1,DMSO_2,DMSO_3 \
  -x DRUG_1,DRUG_2,DRUG_3
# normZ < 0 且 FDR 小 → 增敏/合成致死；normZ > 0 → 耐药/抗性
# 默认配对；重复非配对时加 --unpaired
```

### MAGeCK MLE（辅，多条件设计矩阵）

`design_matrix.txt`：

```
Samples     baseline   drug
DMSO_1      1          0
DMSO_2      1          0
DMSO_3      1          0
DRUG_1      1          1
DRUG_2      1          1
DRUG_3      1          1
```

```bash
mageck mle -k kinome_screen.count.txt -d design_matrix.txt \
  -n results/synlethal_mle
# 看 'drug' beta 系数：负=增敏，正=耐药
```

---

## 4. 判读与验证清单

1. **质检门槛先过**（比对率、Gini、重复相关 ≥0.8、CEG/NEG 的 ROC-AUC）。
2. **必需性：** BF > 阈值 + 6 条引导一致 → 依赖激酶；映射 Manning 家族/通路。
3. **合成致死：** drugZ 增敏方向命中 + 已知类别按预期出现（见 `08` 第 4 节）。
4. **交叉参考** DepMap/CCLE 同谱系依赖性。
5. **验证：** 多引导一致（已内建）+ 单引导阵列敲除 + **cDNA 回补**证明 on-target。
