# 确定靶基因集（人类激酶组）

完整定义、Manning 分类各组数量、权威数据来源及可复现的抓取命令见
[`../../data/kinome_targets.md`](../../data/kinome_targets.md)（英文原表）。
本页给出中文摘要。

## 摘要

- **核心靶集：** 人类 **518 个蛋白激酶**（Manning et al. 2002）。
- **推荐默认：** 518 个蛋白激酶 **+ 约 20 个脂质激酶 ≈ 538 个基因**。
- **可扩展：** ~635（加入代谢型小分子激酶）或 ~750–900（加入假激酶、
  调节亚基），视具体生物学问题而定。

## 为什么要从权威库抓取、而不是手写基因列表

基因符号会随版本变动，且激酶组的边界本身有判断成分（假激酶、非典型
PIKK、代谢激酶）。应从 **HGNC 基因组 1258（"Protein kinases"）** 抓取，
再映射到 **Ensembl/GENCODE** 转录本，这样引导 RNA 设计才能按
`02_引导设计.md` 精确靶向**早期组成型外显子（constitutive exon）**。
每个基因最终选定的引导列表是生成的工作文件（`data/selected_guides.tsv`），
在总结中按文件名引用。

## Manning 分类（蛋白激酶各组大致数量）

| 组 | 说明 | 大致数量 |
|----|------|----------|
| TK | 酪氨酸激酶（受体型 + 非受体型；EGFR、ABL1、SRC…） | ~90 |
| TKL | 类酪氨酸激酶（RAF、IRAK、LRRK2…） | ~43 |
| STE | STE7/11/20（MAP2K、MAP3K…） | ~47 |
| CK1 | 酪蛋白激酶 1 家族 | ~12 |
| AGC | PKA/PKG/PKC（AKT1-3、PKC、S6K、ROCK…） | ~63 |
| CAMK | 钙/钙调蛋白依赖型（CAMK、AMPK/PRKAA、CHK…） | ~74 |
| CMGC | CDK/MAPK/GSK3/CLK（CDK1-13、MAPK1/3、GSK3B…） | ~61 |
| RGC | 受体型鸟苷酸环化酶 | ~5 |
| Other | Aurora、PLK、NEK、IKK、WEE1、TTK… | ~83 |
| Atypical | ATM/ATR/mTOR/DNA-PK/PIKK、ABC1、RIO、TAF1… | ~40 |

数量为近似值，确切成员取决于注释版本。
