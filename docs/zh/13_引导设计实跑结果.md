# 引导设计实跑结果(真实数据)

这一份不是预期,是**实跑产出**。用当前权威数据源真正把激酶组比对到已发表引导库,
统计覆盖、脱靶相关 QC 与 on-target 活性。

## 数据来源(均本会话实拉)

| 数据 | 来源 | 版本/规模 |
|------|------|-----------|
| 人类蛋白激酶清单 | **UniProt pkinfam**(Swiss-Prot 策展) | release 2026_02(2026-06-10),**512 个**蛋白激酶 |
| 引导序列 + Rule Set 2 分 | **Broad GPP Brunello** 文库 | 全基因组 76,441 引导 / 19,114 基因 + 1,000 非靶向对照 |
| 基因符号别名解析 | **HGNC REST**(genenames.org) | 逐个解析 prev/alias symbol |

> Brunello 原始文件 9.2 MB(`broadgpp-brunello-library-contents.txt`),体积大,
> **按文件名引用**、不入库、不加链接。产出的小表已入库。

## 产出文件(仓库内)

- `data/selected_guides.tsv` —— **2,024 条真实引导**(506 激酶 × 4),含当前符号、
  Brunello 符号、UniProt、rank、spacer、PAM、外显子、链、Rule Set 2 分、GC。
- `data/kinome_symbols.txt` —— 512 个激酶符号。
- `data/coverage_stats.json` —— 下列统计的机读版。

## 1. 覆盖:是否有没覆盖的?

| 指标 | 结果 |
|------|------|
| 激酶组总数(pkinfam) | **512** |
| 直接符号匹配到 Brunello | 495(96.7%) |
| 经 HGNC 别名找回 | **+11** |
| **合计覆盖** | **506 / 512 = 98.8%**,每基因 4 条引导 |
| **真正缺口(需自设计)** | **6 个** |

### 别名找回的 11 个(Brunello 用 2016 旧符号)

`CILK1→ICK`、`GRK2→ADRBK1`、`GRK3→ADRBK2`、`COQ8A→ADCK3`、`COQ8B→ADCK4`、
`HASPIN→GSG2`、`MAP3K20→ZAK`、`MAP3K21→KIAA1804`、`PAK5→PAK7`、`PEAK3→C19orf35`、
`PRP4K→PRPF4B`。这就是最初"17 个未覆盖"的主因——**符号漂移**,而非设计失败。

### 真正缺口 6 个(直接 + 别名均查无)

`CDK8`、`GRK1`、`PDPK2P`、`PRAG1`、`RSKR`、`STK38`。已逐个用 csv 解析核实
Brunello 中确为 0 条(同时 CDK1/2/4/6/9、BRAF、AKT1 均为 4 条,排除解析错误)。

- **`PDPK2P`** 是**假基因**——应从蛋白激酶靶集中剔除,不需引导。
- 其余 **5 个蛋白编码激酶**(CDK8、GRK1、PRAG1、RSKR、STK38)需**从头设计**引导
  (CRISPOR/GuideScan2),补进文库。CDK8、STK38 是常见基因,属 Brunello 已知的
  个别遗漏。

## 2. On-target 效果如何?

对 2,024 条入选引导的 Rule Set 2 分统计:

| 指标 | 值 |
|------|-----|
| 中位数 | **0.668** |
| 均值 | 0.669 |
| ≥0.6(高活性)占比 | **92.7%** |
| <0.2(弱活性)占比 | **0.0%** |

结论:入选引导预测活性整体很高,几乎不含弱引导。Brunello 本身以 Rule Set 2 择优,
这一分布是实验验证过的库的真实反映,非纯计算预测。

## 3. 脱靶可能性(已算 + 待算)

### 已算(序列层面 QC,基于 2,024 条)

| 检查 | 结果 |
|------|------|
| poly-T(TTTT,Pol III 终止) | **0 条** |
| GC 极端(<25% 或 >80%) | **4 条**(0.2%),中位 GC 50% |
| 同一 spacer 跨不同激酶基因(库内碰撞) | **0 条** |

Brunello 在设计时已做**脱靶最小化过滤**(Doench 2016),入选引导本身即经特异性筛选;
上述序列 QC 进一步确认无明显硬伤。

### 待算(需基因组索引,本环境未跑)

**全基因组 per-guide CFD/MIT 脱靶枚举**需要 GuideScan2 / Cas-OFFinder 对人类基因组
索引运行——这需要多 GB 的基因组数据与专用工具,当前沙箱未安装。因此
`data/offtarget_report.tsv.gz`(每条引导的 `n_off_1mm / n_off_exonic / CFD`)尚未生成。
要补齐,需在有基因组索引的机器/云上跑 GuideScan2(见下"下一步")。
