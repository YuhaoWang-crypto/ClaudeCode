# 脱靶预测

每条候选 spacer 都要评估 Cas9 在基因组其他位置切割的风险。在混池筛选中，
脱靶切割会制造假依赖性（一个"命中"其实是旁观基因），并增加切割毒性噪声，
因此按特异性过滤与 on-target 效率同等重要。

## 1. 决定脱靶切割的因素

- 基因组某位点与 spacer 的**序列相似度**（可容忍错配，尤其在远离 PAM 的 5′ 端）。
- **错配的位置与类型**——靠近 PAM 的种子区（seed，约 10–12 nt）错配比远端
  错配破坏性大得多；rG:dT 摆动错配常被容忍。
- **非经典 PAM**——SpCas9 也会在 `NAG`/`NGA` 弱切割；枚举时应纳入。

## 2. 枚举候选脱靶位点

穷举找出每条 spacer 在给定编辑距离内的所有基因组位点：

- **Cas-OFFinder**——穷举、免比对，可枚举到 N 个错配（及 bulge），GPU 加速。
  是"存在哪些位点"的金标准。
- **GuideScan2**——预计算的全基因组特异性，索引高效；按错配数返回脱靶计数
  及一个综合特异性分。
- **CRISPOR**——适合候选集；报告 MIT + CFD 特异性，并列出各脱靶位点及注释
  （外显子/内含子/基因间）。

搜索参数：对 `NGG` 枚举 **≤4 个错配**的位点；另对 `NAG`/`NGA` PAM 检查
≤3 个错配。

## 3. 特异性打分

两个互补的综合分（0–1，越高越特异）：

- **CFD 特异性分**（Doench 2016）——按位置/类型加权；**主要**脱靶指标。
- **MIT 特异性分**（Hsu 2013）——较老但仍常报告；作为次要校验。

按 GuideScan2/CRISPOR 的方式为每条引导计算一个全基因组综合特异性——它把整个
脱靶谱概括成一个数字。

## 4. 过滤规则（引导若不满足则淘汰）

按顺序执行，硬性在前：

1. **除目标位点外，全基因组无完全匹配（0 错配）。**
2. **无落在任意基因 CDS/外显子内的 1-错配脱靶**（尤其另一个激酶——会混淆筛选）。
3. **无"种子区 + 外显子"组合下的 2-错配脱靶。**
4. **CFD 特异性 ≥ 0.2**（能承受则收紧到 ≥ 0.3–0.5；聚焦文库每基因候选多，
   有条件严格）。
5. 优先选那些脱靶只落在**基因间/内含子**且错配 ≥3 的引导。

在通过者中，再按 on-target 分（见 `02_引导设计.md`）排序，每基因取前 6。

## 5. 结合细胞系的精细化（推荐）

脱靶风险取决于**你实际筛选所用的基因组**，而非参考基因组：

- 若有该细胞系的变异数据（如 CCLE/DepMap 或自测 WGS），屏蔽那些因 SNP 而
  形成或消除脱靶匹配的位点。
- 拷贝数扩增会造成**切割毒性**（扩增区大量切割会杀死细胞，与基因功能无关）。
  标记预期切割位点或脱靶位点落在扩增子内的引导（Munoz 2016 / CERES 式拷贝数
  偏差）——分析阶段（`06_分析.md`）也会通过 CERES/Chronos 校正。

## 6. 实验验证（可选，混池筛选通常不需要）

若某个高价值命中必须排除脱靶效应：

- 用 **GUIDE-seq**、**CIRCLE-seq / CHANGE-seq** 或 **DISCOVER-seq** 对单条
  引导实测全基因组切割。
- 对筛选命中，更简洁的验证是**多条独立引导一致**（每基因 6 条已内建）加上
  **cDNA 回补**。

## 本阶段输出

每引导一张脱靶表（全基因组，体积大——在总结中按**文件名引用**、不加链接）：
`data/offtarget_report.tsv.gz`，字段包括
`spacer, cfd_specificity, mit_specificity, n_off_0mm, n_off_1mm, n_off_2mm,
n_off_exonic, worst_offtarget_locus, pass(bool)`。
