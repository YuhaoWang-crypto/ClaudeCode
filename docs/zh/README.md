## 一览

- **靶基因：** ~518 蛋白激酶（Manning 分类）；可扩展到 ~635（加脂质 + 代谢）
  或 ~750（广义"激酶组"）。
- **引导：** 每基因 6 条 sgRNA（高置信度可选 8 条）+ ~250 非靶向 + ~50 基因间
  切割 + 阳/阴性必需对照 → **~3,600–5,000 条引导文库**。
- **On-target 打分：** Rule Set 3（Sanson 2018）/ DeepSpCas9，早期组成型外显子，
  覆盖全部转录本。
- **脱靶：** CFD 特异性 ≥ 0.2 过滤，无完全/1-错配外显子脱靶，用 GuideScan2 +
  Cas-OFFinder 验证。
- **规模：** 全程维持 ≥1000× 每引导细胞数，MOI ~0.3，≥3 个生物学重复。
- **测序：** 每引导约 1000 读数（5k 文库约 5M 读数/样本），gDNA 用量按保留
  ≥1000× 基因组覆盖度设定。
