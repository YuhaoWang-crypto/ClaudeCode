# 两种筛选设计：必需性 + 化学基因组/合成致死（合并一次实验完成）

结论先行：**不必做两次实验。** 用同一个激酶组文库、同一株 Cas9 细胞系、
同一次转导，设置**溶剂（DMSO）组**与**加药组**两个平行臂，即可同时得到两套
结果：

- **必需性/丢失筛选** = 溶剂组 **T_end vs. T0**（哪些激酶是这株细胞的依赖）。
- **化学基因组/合成致死筛选** = **加药组 vs. 溶剂组（同一 T_end）**（哪些激酶
  敲除会改变对药物的敏感性）。

溶剂组一举两用：它既是必需性筛选的实验组，又是加药组的对照。

---

## 1. 实验臂与时间点

```
                       ┌─ 溶剂(DMSO)组 ──传代/加溶剂──► T_end (DMSO)
质粒 ─►转导─►嘌呤筛选─►T0 ─┤
                       └─ 加药组 ───────传代/加药────► T_end (Drug)
```

| 样本 | 时间 | 用途 |
|------|------|------|
| 质粒（plasmid） | 制病毒前 | 文库输入参照、质检 |
| T0 | 筛选后（约第 7 天） | 两种分析共同的起点参照 |
| T_end（DMSO） | 约第 21 天 | 必需性（vs. T0）+ 合成致死的对照（vs. 加药） |
| T_end（Drug） | 约第 21 天 | 合成致死（vs. DMSO） |

- **重复：** 每臂 ≥ 3 个生物学重复（独立感染）。
- **T0 共享：** T0 只需一套（3 重复），两臂共用同一批转导细胞在加药前分流。

### 样本数与测序（精确计数）

计算器为保守起见把 T0 按"每臂各一"计数（得 13 样本）。实际共享 T0 后：

```
质粒 1 + T0 ×3 + T_end(DMSO) ×3 + T_end(Drug) ×3 = 10 个样本
```

- 每样本约 **4.4M 读数**（1000/引导 × 1.25 上浮）。
- 10 样本 → **约 44M 读数**，远小于一张 NovaSeq lane。
- 若加多个药物剂量/多个药物，每多一个加药臂 +3 样本、+约 13M 读数。

其余规模数字（每样本维持 ≥3.5M 细胞、约 23 µg gDNA/样本、MOI 0.3 需铺
约 13.5M 细胞）见 `05_筛选与测序.md`；用以下命令复算：

```bash
python3 scripts/coverage_calculator.py --genes 518 --guides-per-gene 6 \
  --controls 400 --coverage 1000 --arms 2 --timepoints 2 --replicates 3
```

## 2. 关键差异点：加药臂如何设

必需性筛选无需额外设定；**合成致死臂的成败取决于药物剂量与压力窗口**：

1. **先做剂量预实验**：在筛选细胞系上测该药的剂量-反应曲线，选一个**亚致死
   剂量**——通常 **IC20–IC30**（约抑制 20–30% 增殖）。太高会把群体压垮、丢失
   覆盖度；太低则没有选择压力、看不到差异。
2. **持续给药**：从 T0 分流后在整个传代期维持该浓度（每次换液补足），跑到
   ~8–10 次倍增。
3. **全程维持覆盖度**：加药臂即使增殖变慢，也必须保持 **≥1000× 每引导细胞数**
   ——必要时增加起始细胞数或延长时间以累计足够倍增。
4. **DMSO 匹配**：溶剂组用与加药组等体积的 DMSO，排除溶剂本身的影响。

### 遗传背景版的合成致死（可选替代/补充）

若你的合成致死问题是"某基因型下哪些激酶变必需"（而非药物），把**加药臂换成
等基因对（isogenic pair）**：在同一文库下分别筛 **野生型 vs. 突变型**（如
TP53⁺ᐟ⁺ vs. TP53⁻ᐟ⁻，或 KRAS 突变 vs. 校正）细胞系，比较两者的丢失谱。
实验结构与上面相同，只是"两臂"变成"两株细胞系"。

## 3. 两套分析分别怎么跑

同一份引导计数矩阵（见 `06_分析.md` 第 1 节），跑两条分析线：

### A. 必需性/丢失分析（溶剂组）

| 步骤 | 方法 |
|------|------|
| 比较 | T_end(DMSO) **对** T0 |
| 主方法 | **BAGEL2**（用 CEGv2/NEGv2 先验给出校准的贝叶斯因子 BF） |
| 辅助 | **MAGeCK RRA**（基因级 LFC/排名） |
| 校正 | **Chronos/CERES** 拷贝数偏差校正 |
| 判读 | BF > 阈值且多引导一致 → 该激酶为依赖；映射到 Manning 家族/通路找富集 |

### B. 化学基因组/合成致死分析（加药 vs. 溶剂）

| 步骤 | 方法 |
|------|------|
| 比较 | T_end(Drug) **对** T_end(DMSO)（同一时间点，消去纯必需性效应） |
| 主方法 | **drugZ**（专为加药 vs. 对照的合成致死/抗性调优） |
| 辅助 | **MAGeCK MLE**（多条件设计矩阵） |
| 判读 | 加药下更丢失 → **增敏（合成致死）**；加药下富集 → **耐药/抗性** 基因 |

> 要点：合成致死看的是**加药 vs. 溶剂**，而不是加药 vs. T0——后者会把"本来
> 就必需"的激酶混进来。溶剂组正是用来扣掉这部分基础必需性的。

## 5. 一页流程清单

1. 建 Cas9 稳定株并验活性 → 克隆激酶组文库（`04_文库构建.md`）。
2. 剂量预实验定 IC20–IC30。
3. 大规模转导（MOI 0.3，≥13.5M 细胞）→ 嘌呤筛选 → 收 T0（3 重复）。
4. 分流：DMSO 臂 + 加药臂，各 3 重复，全程维持 ≥3.5M 细胞/样本，给药至 ~21 天。
5. 收 T_end 两臂 → 提 gDNA（约 23 µg/样本）→ 两步 PCR → 测序（约 44M 读数）。
6. 计数矩阵 → A 线 BAGEL2（必需性）+ B 线 drugZ（合成致死）→ 质检 → 命中判读
   与验证（多引导一致 + cDNA 回补）。
