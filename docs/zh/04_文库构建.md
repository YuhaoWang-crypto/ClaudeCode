# 文库构建

把选定的 spacer 列表变成克隆完成、经过质检（QC）的混池慢病毒质粒文库。

## 1. 载体选择

| 策略 | 载体 | 适用场景 |
|------|------|----------|
| **双载体（推荐）** | 稳定表达 **Cas9** 的细胞系（如 lentiCas9-Blast）+ **lentiGuide-Puro**（仅 sgRNA） | 病毒滴度高、编辑效率通常更高更均一，最适合筛选 |
| 单载体 | **lentiCRISPRv2**（Cas9 + sgRNA + Puro） | 无法预制 Cas9 细胞系时；滴度较低 |

推荐做法：先构建**你筛选细胞系的 Cas9 稳定表达衍生株**，验证 Cas9 活性
（如用报告系统或针对已知必需基因的对照引导），再把激酶组引导克隆进
**lentiGuide-Puro**。

## 2. 寡核苷酸池设计

每个文库成员是一条合成寡核苷酸：

```
[5' PCR/扩增接头] - [BsmBI 位点] - [G] - [20-nt spacer] - [BsmBI 位点] - [3' 接头]
```

- BsmBI（Esp3I）Golden-Gate 位点的方向设计为把 20-mer 装入载体的 sgRNA 骨架，
  克隆过程中被去除。
- 若 spacer 不以 `G` 开头则在前面补 G（用于 U6 转录）。
- 所有寡核苷酸等长；可变区仅为那 20-mer。
- 以**芯片合成寡核苷酸池**订购（Twist、Agilent/SurePrint、GenScript）。约
  5,000 个成员即一个小池。

## 3. 克隆流程

1. **扩增** 寡核苷酸池，用限循环数 PCR（尽量少循环以减少偏倚和重组；用高保真
   聚合酶）。
2. **Golden-Gate 组装**（BsmBI/Esp3I）进入酶切后的载体——一锅法酶切+连接。
   （若用线性化骨架，Gibson 是替代方案。）
3. **电转** 高效、重组缺陷型 *E. coli*（Endura / Lucigen）。梯度铺板以**计数
   菌落**。
4. **克隆阶段的覆盖度：** 收集 **每条引导 ≥ 50–100× 菌落**（如 5k 文库需
   ≥ 25 万–50 万菌落）以保留代表性。刮取全部菌落一起处理，**不要单独挑取**。
5. **Maxiprep** 混池质粒。

## 4. 质粒文库质检（制病毒前）

- **对质粒池做 NGS**（与筛选相同的扩增子读出）。计算：
  - **代表性：** ≥ 95% 设计引导可检出。
  - **偏斜（skew）：** 前 10% : 后 10% 读数比 **< 10×**（理想 < 6×）。
  - 引导计数的 **Gini 指数 < 0.10**（分布紧致）。
  - 任何基因的整套引导都无大范围丢失。
- Sanger 抽检若干菌落，确认骨架连接正确。

## 5. 慢病毒生产与滴度测定

1. 把文库质粒与包装质粒（psPAX2 + pMD2.G）共转染 HEK293T；收集并浓缩病毒。
2. **在真正的筛选细胞系上测滴度**：转导梯度稀释病毒，测嘌呤霉素抗性比例 →
   计算功能性 MOI。
3. 以 **MOI ≈ 0.3** 筛选（按泊松分布约每细胞 1 个整合；约 26% 细胞被感染，
   且被感染细胞中绝大多数只携带单条引导）。

## 本阶段交付物

- 克隆完成、序列验证的质粒文库（maxiprep）。
- 质粒质检 NGS 数据（**FASTQ 按文件名引用**，如 `plasmid_qc_R1.fastq.gz`——
  体积大，不在总结中加链接）+ 一张小的引导计数表和质检指标报告（可链接）。
- 已测滴度、已分装的慢病毒储液。
