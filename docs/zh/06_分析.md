# 分析流程

## 1. 从读数到引导计数矩阵

1. 按样本索引**拆分（demultiplex）**。
2. **修剪**到恒定骨架锚点，提取 20-nt spacer。
3. 把 spacer **比对**到文库（精确或 ≤1 错配）——用 `MAGeCK count`、
   `mageck-count` 或自写精确匹配器。丢弃不匹配任何设计引导的读数。
4. 生成**引导 × 样本计数矩阵**。记录比对率（应 ≥ 65–75%）与每样本总读数。

## 2. 判定命中前的质检门槛

- **比对率** ≥ 65%；**零计数引导**少（多数引导可检出）。
- 每样本计数的 **Gini 指数**（质粒/T0 应紧致，< ~0.1；随时间 Gini 升高反映
  真实选择）。
- **重复相关性**（对 log 计数或 LFC 的 Pearson/Spearman）≥ ~0.8。
- **PCA/聚类**应按时间点/条件分开，而非按批次分开。
- **阳性对照丢失：** 必需激酶（PLK1、CDK1、AURKB…）与 Hart CEGv2 泛必需基因
  丢失；NTC 与 NEGv2 保持平稳。
- 已知必需 vs. 非必需基准集的 **ROC-AUC / 精确率-召回率**——判断"筛选是否
  成功"的头号指标。

## 3. 统计分析（按筛选类型选择）

| 筛选类型 | 方法 | 说明 |
|----------|------|------|
| **丢失/必需性** | **MAGeCK（RRA）**、**MAGeCK-MLE**、**BAGEL2**（贝叶斯因子） | BAGEL2 借助 CEGv2/NEGv2 先验给出校准的必需性 |
| **相对对照的正/负选择** | **MAGeCK test**、**drugZ** | drugZ 专为化学基因组/合成致死（加药 vs. DMSO）调优 |
| **多条件/时间序列** | **MAGeCK-MLE**、**JACKS**、**CRISPhieRmix** | 建模设计矩阵；跨引导共享信息 |

- **归一化**到总读数或非靶向/中位数；MAGeCK 的中位比归一化是不错的默认。用
  NTC 构建零假设。
- 对必需性分析做**拷贝数偏差校正**（CERES / **Chronos**），使扩增区切割毒性
  不被误读为依赖性。
- 报告**基因级 LFC、FDR 和排名**，以及每引导一致性（6 条引导是否一致？标记
  仅由 1 条离群引导支撑的基因）。

## 4. 解读激酶组命中

- 将命中与同谱系的 **DepMap/CCLE** 依赖性数据交叉比对（这是已知的共同依赖
  还是选择性依赖？）。
- 把命中映射到**激酶家族/通路**（Manning 分组、KEGG、Reactome），找富集的
  信号节点而非孤立基因。
- 若考虑治疗价值：把命中与**可成药激酶**及现有抑制剂交叉（ChEMBL 机制/活性、
  临床试验格局）以确定后续优先级。

## 5. 顶级命中的验证

- **多引导一致性**（已内建）是第一道过滤。
- 单引导阵列式敲除/竞争实验；**cDNA 回补**以证明 on-target；有工具化合物时用
  药理学确认。

## 输出

- `results/guide_counts.tsv`（小——可链接）。
- `results/gene_summary.tsv`（MAGeCK/BAGEL 基因级——小，可链接）。
- 质检报告（HTML/PDF）。原始 FASTQ 和完整计数 BAM 体积大，在总结中**按文件名
  引用**、不加链接。
