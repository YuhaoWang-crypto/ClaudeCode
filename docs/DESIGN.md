# 多中心版本的研究设计

多中心有两个收益，量级不同、性质也不同：

- **准确度确实会提高**。在真实效应量固定的对照模拟里，从原文规模（单中心 n=182）
  到多中心（n=900、6 中心、ComBat + 留一中心），诚实 AUC 从 0.663 升到 0.82–0.84，
  约 **+0.16**。其中最大的一块来自样本量本身（+0.185），而不是来自"多中心"这件事。
- **报出来的那个数变得可证伪**。这一条比前一条重要。

注意这两条合起来并**不**意味着新数字会超过 0.985 —— 它不会，也不该。
0.985 与 0.83 不是同一个量：前者是"同院同批病人一次随机划分上的表现"，
后者是"在一家没见过的医院里的表现"。详见 [`WHY_099_AUC.md`](WHY_099_AUC.md)。

---

## 0. 先说清楚要复现的是什么

原文（*Front Immunol* 2022;13:1080048）的设计，逐条列出（均已核对原文）：

| 项 | 原文 |
|---|---|
| 队列 | 182 例手术，3:1 分为训练 137 / 验证 45；另有新辅助队列 64 例 |
| 影像 | 3T Philips Achieva，轴位 3D DCE-MRI，0.6×0.6×2 mm，对比后连采 4 期，间隔 74 s |
| 病理 | 抗 CD8 单抗（1:400, M7103, Dako）IHC；QuPath 自动计数，单位 个/mm² |
| 分区 | 肿瘤中心 (TC) 与浸润前沿 (IF) 分别评估 |
| 表型 | 沙漠型 / 排斥型 / 炎症型 |
| 分割 | 在**减影图**（平扫减第 2 期）上由一位 10 年经验放射科医师勾画 |
| 瘤周定义 | **全瘤的内侧 2 mm 环**（注意：是肿瘤**内**的一圈，不是瘤外组织） |
| 特征 | 每区每期 833 个 = 1 体积 + 64 纹理 + 768 小波（12 个变换 × 64） |
| 小波 | db2（ratio = 1/2, 2/3, 3/2, 2）、coif1、sym4 |
| 筛选 | ICC < 0.8 剔除 → **按 AUC 取前 50** → LASSO（5 折 CV 选 λ） |
| 模型 | RM-whole：炎症 vs 其余；RM-peri：沙漠 vs 排斥 |
| 结果 | RM-whole 0.973 / 0.985；RM-peri 0.993 / 0.984 |
| 外部验证 | **无**（原文自陈："performance needs testing with … an external cohort"） |

两个复现时必须明说的偏差：

- **纹理特征 64 vs 61**。原文的 64 = 经典 27 特征 Haralick GLCM + GLRLM 16 + GLSZM 16 +
  NGTDM 5。PyRadiomics 的 IBSI 对齐实现给 24 + 16 + 16 + 5 = **61**，少的 3 个是被
  刻意删掉的冗余项（对称 GLCM 下 Sum Average 恒等于 2 × Joint Average）。
  这个差别对任何结论都没有影响，但复现时应当写出用的是哪个数，而不是悄悄凑成 64。
- **"12 个小波变换"的来源不明**。6 个滤波器配置要产生 12 张图，只能是每个滤波器出 2 张
  （低通近似 + 高通细节）。而标准 3D DWT 每个滤波器出 8 个子带，那会是 48 张图、3,072 个特征。
  本项目默认复现原文的计数，`full_3d=True` 可切到另一种读法。见
  `mri_cd8_til/features/wavelet_bank.py`。

原文没有说清"按 AUC 取前 50"这一步是在 182 例上做的还是只在 137 例训练集上做的。
**这个区别值大约整个头条结果** —— 量化见 [`WHY_099_AUC.md`](WHY_099_AUC.md)。

## 1. 标签：这是真正的瓶颈，不是样本量

配对 CD8 IHC 空间表型的公开 MRI：**0 例**。所以只有两条路：

**路线 A（推荐）：TCGA-BRCA n=136，当原文缺的外部验证集。**
影像来自 TCIA，空间 TIL 标签来自 Saltz 图谱（patch 级，能算中心/前沿密度），
CD8 特异性用 RNA-seq 的 CD8A/CD8B 做锚定。四家厂商、多家机构。
`labels/spatial.py` 把 patch 图谱落到三分类；阈值是**拟合出来的**，因此
必须只在训练集上拟合 —— 在全体上拟合再评估，就是本项目批评的那种泄漏。

**路线 B：I-SPY2 n=717，把样本量抬起来。**
但转录组标签**只支持 RM-whole，不支持 RM-peri**（沙漠与排斥的差别纯粹是空间的，
bulk 表达谱没有机制表达它）。这条约束写死在 `labels/schema.py` 里。

**路线 C（最贵但最正确）：自己攒多中心 CD8 IHC。**
公开数据替代不了这条。如果目标是发一篇能被采信的论文，
3–5 家中心、每家 150–250 例、统一 IHC 判读 SOP + 双人盲法，是绕不开的。
公开数据的作用是把这件事的**风险先降下来**：先用 Tier A/B 确认效应量到底是 0.75 还是 0.90，
再决定值不值得投这笔钱。

## 2. 影像预处理：多中心成败主要在这里

MR 强度没有物理单位。同一个人同一块组织，在 GE SIGNA 和 Siemens Skyra 上就是不同的数。
不处理，pooled 模型学到的一部分就是扫描仪。`imaging/preprocess.py` 的顺序和各步防的东西：

1. **N4 偏置场校正** —— 线圈灵敏度，随厂商与线圈几何变化的低频梯度。
2. **重采样到统一体素栅格** —— 纹理特征定义在体素点阵上；在 0.6×0.6×2.0 训练、
   在 0.8×0.8×1.0 应用，等于在同一个特征名下喂进了不同的量。
3. **强度归一化** —— 把任意单位放到同一尺度。
4. **固定 bin width 离散化**（提取时）—— 用固定 bin **数量**会让 bin 宽度取决于每个病灶
   自己的强度范围，把第 1–3 步刚去掉的扫描仪依赖又请回来。IBSI 对任意单位模态推荐固定 bin width。

各向异性要特别小心：0.6×0.6×2.0 下，若按体素数做等半径腐蚀，面内会比层间多吃掉 3.3 倍组织。
`imaging/roi.py` 的形态学半径按各轴 spacing 分别算，所以 2 mm 环在三个方向都是 2 mm。

## 3. ROI：内环与外环都要报

原文的"瘤周"是**内侧 2 mm 环**。两种选择各有代价，所以两种都实现了：

- **内环**：只含肿瘤体素，对分割外溢和乳腺边界稳健；但**看不到瘤周间质** ——
  而排斥型淋巴细胞正是待在那里。
- **外环**：能看到间质，符合排斥表型的生物学动机；但对分割方式极其敏感，
  很可能编码的是"这个肿瘤旁边有多少脂肪"。

一个在外环上赢过全瘤模型的瘤周模型，有可能只是在读脂肪/腺体背景。
`RegionSpec` 默认同时给出内环 2 mm 与外环 3/5 mm，外环还会被裁到体表 mask 内以免采到空气。

小 ROI 必须挡掉：被 2 mm 环腐蚀后剩几十个体素的病灶，其纹理矩阵在数值上是不稳定的，
默认 `min_voxels=64`。悄悄留着它们，就是在给后面的特征筛选制造噪声。

## 4. 特征稳定性：两个不同的问题，别混成一个

原文用 ICC < 0.8 剔除。这没错，但那个 ICC 测的是**观察者间分割差异**，只是特征漂移的一个来源。
一个特征可以在同一家医院两位放射科医师之间完美可重复，同时在换扫描仪时彻底失效。

`modeling/stability.py` 把两件事分开：

- **扰动 ICC(2,1)**：对输入做保标签的小扰动（mask 膨胀/腐蚀 ±1 mm、面内旋转 ±5°、加 2% 噪声）
  重新提特征，保留数值扛得住的。不需要第二位观察者。
- **批次主导度**（在 `modeling/combat.measure_batch_effect`）：单因素 ANOVA 的 η²，
  剔除方差主要由中心解释的特征。

两个筛选都是**无监督**的（完全不碰结局），所以在全体数据上做**不构成标签泄漏**。
这一点值得精确说明，因为它是本流水线里唯一可以合法放在交叉验证循环外面的预处理步骤。

## 5. ComBat：两个容易搞错的地方

`modeling/combat.py` 实现经验贝叶斯 ComBat（Johnson 2007），并在两处刻意设了硬约束：

**协变量保护。** 免疫表型在各中心的分布从来不是均匀的。不保护生物学变量就去掉"中心"，
会连信号一起去掉。但把结局当协变量传进去，测试折又拿不到结局 ——
"fit 时用、transform 时不用"是一种隐蔽的泄漏。所以本实现：默认不用协变量；
一旦 fit 时给了协变量，transform 时**必须**也给，否则直接报错。

**没见过的中心。** 留一中心验证保证测试批次在 fit 时没出现过。两种正当答案都提供：

- `reference`（M-ComBat）：新批次用**它自己的特征**做标准化。不碰标签，所以不是泄漏。
- `error`：拒绝执行。适用于"部署时只来一张片子"的场景 ——
  那时根本估不出批次统计量，这是 ComBat 类放射组学**真实的部署限制**，不是 bug。

## 6. 验证：按"有多难被糊弄"排序

| 方案 | 估计的是什么 |
|---|---|
| 单次随机划分 | **这一次划分**上的表现，仅此而已 |
| 重复分层 CV | 内部表现的平均 |
| 嵌套 CV | 计入调参代价的内部表现 |
| **留一中心** | **在一家从没见过的医院里的表现** |
| 置换零分布 | 标签打乱后这套流水线能拿到多少 |

原文报的是第一种。对一个要在医院之间流通的模型，**留一中心**才是回答实际问题的那个估计。

置换零分布在 p ≫ n 时尤其重要：如果一套流水线在打乱标签上能拿 0.75，
那它在真标签上的 0.85 的含义就要重新算 —— **只有两者之差是真的**。
重复次数也不是形式：n=182 上单次 5 折 CV 的划分间方差足够大，
换个种子能差 0.05 AUC；只报一次的结果，等于邀请自己去报最好的那次。

## 7. 报什么

AUC 之外必须报的：

- **AUC 的置信区间**。n=45 上的 0.985，95% CI 是 [0.941, 1.000]；
  一个 0.900 的模型在同一划分上是 [0.789, 1.000]。**两个区间重叠** ——
  这个划分分不出 0.90 和 0.985。
- **校准**（截距、斜率、Brier）。斜率 < 1 是过拟合的经典特征：预测在两端都太极端。
  一个排序很好但校准很差的模型，在任何固定阈值上都会做出坏决策 ——
  而"选谁做免疫治疗"就是一个固定阈值决策。
- **决策曲线净获益**。净获益始终不能同时超过 treat-all 与 treat-none 的模型，
  AUC 再高也没有临床用途。
- **每个中心分别的表现**，不只是汇总。

## 8. 落地顺序

1. `scripts/refresh_inventory.py` —— 重新实测数据可得性（几分钟）。
2. 拉 TCGA-BRCA 的 136 例 MRI + Saltz TIL 图谱，建 Tier A 标签。
3. 拉 I-SPY2 的 717 例 + GSE194040，建 Tier B 标签（只做 RM-whole）。
4. 用 MAMA-MIA 的预训练 nnU-Net 出分割，人工核一遍 —— 这一步省掉最多人力。
5. 提特征（`features/extractor.py`），跑扰动 ICC 与批次 η²。
6. 在 Tier B 上训练（n=717，多中心，ComBat + 留一中心），
   在 Tier A 上做真正的外部验证（n=136，从未参与训练）。
7. 报第 7 节的全套指标，附置换零分布。

预期：**RM-whole 的诚实跨中心 AUC 落在 0.70–0.85**。

这个区间有三个独立来源，且彼此吻合：同类研究中唯一做过真外部中心测试的那篇报 **0.704**
（加临床变量 0.767）；本项目的多中心对照模拟给 **0.82–0.84**；
鼻咽癌那篇同院留出就已经掉到 **0.785**。

RM-peri 会更低，而且只能在 Tier A 的 136 例上评估 —— Tier B 根本没有能力评它。

若真实结果就落在这个区间，那它比 0.985 有用得多 —— 因为它是下一家医院能复现的那个数。
