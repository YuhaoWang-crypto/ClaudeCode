# IS621 bridge recombinase — activity engineering

Single-mutation predictions for the IS621 bridge recombinase (326 aa; IS110 family;
Durrant/Hsu *Nature* 2024), ranked by consensus across **ESM-1v, ESM2, ProteinMPNN, and
ESM-IF** (run on GPU via Modal) and interpreted on the cryo-EM structure **PDB 8WT9**.

- **[REPORT.md](REPORT.md)** — full analysis, top-5 candidates, structural rationale, caveats.
- **`analysis/is621_viewer.html`** — interactive 3D viewer of the complex with candidate sites.
- **`analysis/`** — reproducible pipeline (Modal scripts, ranking, annotation, figures) and data.
