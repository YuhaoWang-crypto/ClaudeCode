# grn-pipeline

A small, fully-runnable pipeline that applies four "irreducibility / symmetry"
mathematical tools to gene-regulatory and metabolic networks, on concrete
literature-grounded systems where every number is *computed*, not asserted.

| Module | Tool | System | Key result |
|---|---|---|---|
| `m1_symmetry` | graph automorphism → quotient | RTK/RAS/RAF/MEK/ERK | \|Aut\|=S₃; 9→7 nodes (3 RAS paralogues → 1 core) |
| `m2_crnt` | CRNT deficiency δ | A⇌B⇌C vs Schlögl | δ=0 monostable / δ=1 bistable switch |
| `m3_efm` | elementary flux modes | 4-metabolite network | 3 irreducible flux generators span the cone |
| `m4_dnb_lyapunov` | DNB / critical slowing / Lyapunov | 2-gene fold bifurcation | LLE→0, SD/autocorr/DNB rise at tipping point |
| `m5_kras_real` | symmetry breaking on a real target | KRAS G12C + covalent drugs (ChEMBL/Boltz/Inductive Bio) | covalent G12C drug breaks paralog symmetry S₃(6)→S₂(2) |
| `m6_integrate` | binding → network stability | sotorasib vs adagrasib | real ChEMBL+Boltz binding → engagement → DNB biomarker |
| `m7_screen` | Boltz-2.1 library screen | 10 G12C ligands (ChEMBL) | ranked by binding; 4 analogues out-rank sotorasib |
| `m8_clinical` | biomarker → trial endpoints | CodeBreaK 100 (NCT03600883) | layers mapped to ORR/DOR, PFS/OS, Cmax/AUC, QTc |
| `m9_occupancy` | PK occupancy → μ calibration | sotorasib (IC50=30 nM) | 98% occupancy at approved dose → network near tipping |
| `m10_validate` | Boltz ranking vs ChEMBL truth | 5 G12C ligands w/ measured IC50 | opt_score tracks potency (ρ=+0.6); binding_confidence doesn't (ρ=−0.2) |
| `m11_fibration` | input-tree fibration (Morone) | expanded MAPK paralogue graph | 27→11 fibers; generalises M1 automorphism to fiber representatives |
| `m12_dualphos` | real ERK double-phospho core | Markevich-style mass-action | CRNT deficiency δ=2; bistable ERK switch; EFM = 2 futile cycles |
| `m13_fim_sloppy` | FIM / sloppy / stiff axes | ERK dual-phospho ODE | sloppy spectrum (38 orders); flux-ratio observables load best |
| `m14_atlas` | 18-pathway systematic atlas | JAK-STAT…mevalonate | fibration compression + biomarker class per pathway; JAK-STAT top (3.0×) |
| `m15_markevich_mm` | exact Markevich 2004 MM ERK cycle | published parameters (JCB 2004) | reproduces bistable window [39.25, 57.38] nM + 3-state table to the decimal |
| `m16_erk_dnb` | DNB / critical slowing on the real switch | M15 saddle-nodes 39.25/57.38 nM | λ_max→0, τ≈4720 s at boundaries; SD/autocorr/DNB rise (early warning) |
| `m17_realdata` | validate M16 on real single-cell ERK imaging | Pertz-lab EKAR traces (FGF pulses + EGF dose) | lag-1 autocorr rises before ERK pulses (p≈0.004); variance flat; EGF all supra-threshold — partial validation |
| `m18_titration_benchmark` | positive control: MEKi titration across the real bifurcation | simulated from M15 Markevich switch | variance & lag-1 autocorr PEAK near threshold (≈5×), tracking τ — pipeline is sensitive, not blind |
| `m19_switch_library` | migrate the critical-slowing engine to many pathways | 10 canonical bistable switches (MAPK, Rb-E2F, apoptosis, Cdc2, CaMKII, Wnt, Cdc42, lac, Schlögl, master-TF) | 10/10 show variance+autocorr rising to their saddle-node — biomarker is universal to the bifurcation |
| `m20_literature_bistable` | multi-variable literature switches + hysteresis | Rb-E2F (Yao 2008), apoptosis (Eissing 2004) topology | bistability + hysteresis loops reproduced; eigenvalue→0 at folds (exact params not open-access-fetchable) |
| `m21_oscillators` | extend framework to oscillatory (Hopf) pathways | Goodwin (circadian), p53-Mdm2, Brusselator (glycolytic) | approaching Hopf: variance rises AND a spectral peak sharpens at the intrinsic frequency — distinct from saddle-node |
| `m20b_biomodels_exact` | fetch + simulate EXACT curated models (fills M20 gap) | Markevich2004 (BIOMD27), Legewie2006 apoptosis (BIOMD102) | download method = biomodels GitHub mirror + libRoadRunner; official Km5=78 confirms hand-coded M15 (states to the decimal); Legewie caspase switch bistable in XIAP synthesis |
| `m22_snic_mixed` | mixed bifurcation: saddle-node ON a limit cycle (SNIC) | θ / Ermentrout-Kopell normal form (cell-cycle / excitable) | finite-amplitude spikes whose period diverges (T~π/√I, log-log slope −0.50; frequency→0) — signature distinct from both Hopf and pure saddle-node; ISI mean+CV both grow |

## netjac — network-Jacobian diagnostics platform

A second package, [`netjac/`](netjac), builds on exact BioModels kinetics (SBML
via libRoadRunner). It keeps three objects separate: the state Jacobian,
which gives eigenvalues and stability; the elasticities, which are the network
edges; and the flux-control matrix dFlux/dEnzyme. It then demos three
diagnostic directions:

| Demo | System | Key result |
|---|---|---|
| `d1_edge_biomarker` | Teusink 2000 glycolysis (BIOMD64) | loss of PFK–ATP feedback leaves the metabolome identical (max \|Δln x\| 9e-16). Static panel AUC 0.62 vs a model-predicted challenge edge readout AUC 0.91. Passive covariance inversion needs ~1e6 samples (stiff) |
| `d2_perturbation_relaxation` | Teusink, Wolf 2000 oscillations (BIOMD206), **real CGMacros CGM (n=45)** | eigenvalues recovered from 1–2-analyte pulses; Hopf read as ringing damping from NADH alone. Real data: meal recovery rate vs HbA1c ρ=−0.44 (p=0.002), but no information beyond fasting glucose |
| `d4_patient_jacobian` | Holzhütter 2004 human glycolysis/PPP (BIOMD70) × **TCGA-KIRC (537 tumours + 72 normals)** | 609 patient-specific Jacobians. Recovers Warburg and an ALDOB-loss aldolase bottleneck (10 % of tumours lose the steady state, OS HR 1.69). Every survival signal reduces to a single-gene proxy (BPGM, ALDOB). The chassis is the bottleneck |
| `d5_pairwise_to_network` | user's tumour–immune & macro models, Goodwin, random nets, **curated physiology atlas** (Topp, Sturis, Tolić, Lemaire, Komarova, Miao, Borghans) | Every equilibrium classified; 2×2 sub-systems combined exactly through the Levins loop decomposition + Hurwitz. All pairs stable ≠ whole stable (Sturis: 0/15 unstable pairs, 110-min Hopf cycle via the 5-step delay loop). Topp diabetes saddle-node at d0 = 0.0735 (= analytic). A linear centre is not a limit cycle. May bound |
| `d6_baroreflex_jacobian` | **real** beat-to-beat ECG + BP, PhysioNet Autonomic Aging | 286 subjects. BRS positive control: ρ=−0.54 with age (p=9e-18). With age the delay-embedded loop mode decays more slowly (ρ=−0.23, beyond BRS p=6e-4) and the VAR spectral radius moves toward 1. The pairwise 2×2 Jacobian alone cannot produce the Mayer oscillation |
| `d7_state_judgments` | user's macro model + **real FRED data** (UNRATE−NROU, CPI YoY−2) | Beyond eigenvalues: energy function (γ, δ are the only dissipation), reactivity, noise quasi-cycles, lead-lag (contemporaneous corr 0.02 vs lagged 0.72), critical policy lag τ* = 0.78, controllability, pole placement. Real data: 1960–83 δ ≈ 0 (near-centre), 1984–2007 δ = 0.56 (soft landing) |
| `d8_module_cases` | Topp, Sturis, Lemaire (BioModels) + **real PhysioNet Fantasia** (40 subjects) | One case per module. Only β-cell turnover moves the diabetes tipping margin (insulin sensitivity: 0). Ultradian Hopf at hepatic delay 24.6 min. Insulin is the informative readout; the three bone drugs have gain rank 1. Artificial-pancreas glucose-only Hopf at k ≈ 3859 vs LQR with insulin-on-board. RSA 35.6 vs 9.2 ms/SD, segment reliability 0.87 |
| `d9_micro_to_macro` | statistical physics of ensembles: **8 CPTAC proteomes** (tumour vs normal), **Replogle K562 Perturb-seq** (1,970 knockdowns, 10.7 GB single cell), islet scRNA, β-cell population model on Topp | Tumours are higher-dimensional and more weakly coupled than normals (7/8). Of ~3×10⁸ protein pairs, most tumour-vs-normal "rewiring" disappears once 1–5 macro modes are subtracted. Negative feedback hides in static correlation (theory + 6/8 indications). Anti-FDT knockdowns recover the textbook homeostats (proteasome p=1e-8, tRNA synthetases, UPR, actin, sterol). Sparse MRA gives 7,291 split-half-replicated direct edges (4× known-interaction enrichment vs 1.6× for total responses). β-cell threshold heterogeneity sets the macro loop gain and the converge/diverge boundary |
| `d10_signs_genomewide_thresholds` | **CPTAC phosphoproteomes** (8 indications), **genome-wide K562 Perturb-seq** (11,258 knockdowns), human β-cell **Patch-seq** + published Ca²⁺ recruitment | Kinase→kinase SIGNOR signs are visible in the activity layer after protein normalisation and mode removal (7/8 indications, p=0.008), not in abundance (p=0.16). 61,993 directed edges among 3,426 genes (FDR 1.8%, 98% sign replication in the independent essential screen). The homeostat atlas replicates (ρ=0.69) and adds sterol/LXR and ER-QC candidates. Measured triggering-threshold width w≈0.21 vs 0.81 implied by the Topp curve: macro gradedness comes from amplification |
| `d11_recovery_state` | Teusink glycolysis (ground truth), **K562 Perturb-seq** + **Norman 2019 doubles**, **NHANES 2005–16 OGTT with linked mortality**, CGMacros | Nested static → challenge → dose → recovery models with paired increments and FP at fixed sensitivity. Hidden feedback defect: static AUC 0.66 (FP 74 %) → one challenge 0.996 (FP 0.4 %), and only the feedback edge restores the recovery. Homeostats: response transfers to unseen families (0.63 vs static 0.06). Single responses predict which double restores the state (AUC 0.89 vs 0.55). OGTT adds no mortality information beyond fasting glucose + HbA1c (ΔC ≈ 0) |
| `d12_timecourse_cell_state` | **GEO GSE75210** (O'Connell 2016, TF-seq): wild-type vs *Myd88*⁻/⁻ macrophages, 12 innate stimuli × 8 time points × 2 replicate plates (384 RNA-seq libraries) | Real time-series test of the D11 framework with textbook positives. Routing (which inputs need MyD88): static t=0 AUC 0.50, any stimulated time point ≈ 1.0, trajectory area 1.0 with replicate r 0.91 and zero misclassification on the held-out replicate. Genotype is already visible statically (dynamics add nothing). Lost core = NF-κB primary-response genes; IRF arm kept under LPS. Bypass inputs (LPS, zymosan, Poly(I:C)) restore NF-κB amplitude and shape (gain ≈ 1, within the WT positive-control range) but add an interferon programme. Euclidean restoration scores are noise-dominated; use projection |
| `d13_human_challenge_state` | **GEO GSE52428** (Woods 2013): 41 adults inoculated with H3N2/H1N1, 2 pre-challenge + 14 blood samples to 108 h; **GSE17156** rhinovirus/RSV for transfer | Human tissue-level test with a clinical known positive (symptomatic infection). Pre-challenge state: AUC 0.59–0.72, FP 50–70 %. Adding the response at 36 h / 60 h / the trajectory reaches 0.93 with 0 % FP when leaving a whole strain out, and transfers to rhinovirus/RSV (0.88–0.89; static 0.59–0.62). Core = type I IFN programme (111 genes replicated in both strains; null 0). Illness is a collective mode (label-free PC1 AUC 0.90), so one textbook ISG (RSAD2, IFI44L) matches the module while small-n data-driven picks do not beat random sets. Lymphopenia recovers by 108 h; the IFN programme has not |
| `d14_treatment_restoration` | **GSE85034** psoriasis on adalimumab / methotrexate (weeks 0–16), **GSE130588** atopic dermatitis dupilumab vs **placebo**, **GSE16879** IBD mucosa before/after infliximab | Does treatment return tissue to balance? Restoration is the projection on a leave-one-out cohort disease axis, which removes regression to the mean (placebo week 4: −0.04). Psoriasis PASI75 responders reach 0.96 at week 16 (83 % ≥ 0.75); molecular restoration tracks PASI (ρ 0.58). Dupilumab vs placebo: 0.63 vs −0.04 (wk 4), 1.06 vs 0.43 (wk 16), matching the paper's 68.8 %/110.8 % vs −10.5 %/55 %. Restoration is axis-specific: Th2 +1.12 vs −0.01, interferon 0.25 vs 0.24. Inflammation and proliferation restore first; barrier/lipid and epithelial modules lag. Week-1 IL-17 module restoration predicts PASI75 (AUC 0.78, n.s.). In IBD, static severity already predicts response (0.94) |
| `d15_state_pipeline` | D14 data through the generic pipeline `netjac/statepipe.py` (skill `.claude/skills/state-restoration`) | Steady state → order parameters → core network → dynamics dy/dt = J(y−y_D)+b0+b·u → minimal adjustment. Steps 1–3 pass on all three datasets. Dynamics beats no-change by 17–31 % in CV error and matches the arm mean. The slow mode is the barrier/epithelium module, which D14 observed restoring last. Dupilumab acts on T cell/DC and Th2, not interferon. Pre-specified lever check FAILED: from a single observational treatment, levers are bottlenecks (barrier), not causal drivers (IL-17); causal levers need perturbational J |
| `d16_causal_lever` | **Replogle 2022 genome-wide CRISPRi** (11,258 knockdowns), **Norman 2019 doubles** | Re-tests the lever check D15 failed, with a causal J from perturbation data. Identity: in `minimal_adjustment` the effect of lever j is J⁻¹e_j = −R[:,j], the measured response to perturbing j — the formalism was fine, it needed a J whose inverse reproduces measured responses. Ground truth (439 held-out knockdowns, leave-one-out, perturbed gene excluded from module scores): the causal response library names the module that was actually broken 66 % [61–70 %] of the time vs 25 % naive, 15 % covariance, 7 % chance, 10 % permutation null. Errors go to causally nested modules (mitoribosome→complex I). Doubles: AUC 0.89, best-partner ranking 54 % vs 21 % chance; a linear J cannot beat additivity there, by construction |
| `d17_keratinocyte_lever` | **GSE305982** keratinocyte + fibroblast cytokine panel (IL-9/IL-13/IL-17A/IL-22/IL-26/IFN-γ, 3 h and 24 h), vs psoriasis (GSE85034) and atopic dermatitis (GSE130588) lesional displacement | Answers the psoriasis lever question D15 got wrong, in the relevant cell type. With a measured keratinocyte response library the top lever for psoriasis at 24 h is **IL-17A** (cos +0.231 vs IFN-γ +0.132), the clinically validated target, with a positive coefficient so restoration means blockade; IL-13 is negative. The fibroblast library misses in all 4 settings, so the right cell type is necessary. Crossed specificity: IL-13→AD +0.181 [0.154, 0.207] ✅, IL-17A→psoriasis +0.026 [−0.009, +0.061] n.s. Not fully passed: AD's top lever at 24 h is IL-22 (IL-13 4th; hit only at 3 h), and psoriasis flips to IFN-γ under a rank-based metric. One donor, no IL-4 |
| `d18_il4_and_combinations` | **GSE36287** keratinocyte panel incl. **IL-4** and TNF (3 donors), **GSE24767** matched IL-17 / TNF / **IL-17+TNF** | Closes D17's two gaps. With IL-4 present the psoriasis result replicates on independent data and a different platform (IL-17A cos +0.220, next +0.104) and its crossed specificity becomes significant (+0.174 [0.147, 0.201] vs +0.026 n.s. in D17). **IL-4, not IL-13, is the AD-specific lever** (+0.097 [0.070, 0.125] vs IL-13 +0.004 n.s.), explaining D17's AD miss; AD top-1 is still IFN-γ, and TNF is not psoriasis-specific. Combinations: the measured IL-17+TNF beats linear superposition (+0.053 [0.031, 0.074]), but the apparent 65 % non-additivity is mostly donor noise (synergy-vector donor r 0.10 vs 0.54 for the response); leave-one-donor-out shows synergy is real and concentrated at IL19, S100A7A, DEFB4A, SERPINB4, IL23A — the psoriasis signature genes |
| `d19_slow_module_relapse` | **GSE30768** psoriasis efalizumab: lesion → week 12 (clear) → **FLARE** in 4 patients; **GSE229605** resolved vs non-lesional epidermis (13 pairs) | First test of the D14-derived prediction that an unrestored slow module marks relapse risk. Premise replicated in a fourth drug: at week 12, clinically clear, proliferation is fully restored (+1.05) while barrier/lipid is not (+0.10). New: the flare returns to the original lesion position on the disease axis (median φ +0.95), so the lesion behaves like an attractor. The predictive claim itself is **not answerable here** — all 4 patients relapsed, and with one post-treatment sample the residual and the rise share that sample with opposite signs, so the cosine is confounded; the n=4 ordering runs the wrong way. Independent cohort: long-resolved skin shows no residual inflammatory displacement and no over-response to T-cell challenge, so what lags is not the inflammatory programme |
| `d20_secukinumab_closed_loop` | **GSE102725** PSORITUS secukinumab withdrawal trial (10 patients, weeks 0/16/32, randomised continue vs placebo); **GSE11903** etanercept (15 patients) | Closes the loop on the D17/D18 lever prediction with the drug that blocks the predicted lever. IL-17A does rank #1 of 9 for secukinumab (cos +0.375 [0.247, 0.483], shuffle p < 1e-4) — but the ranking is 95 % explained by how much each lever looks like psoriasis (Spearman +0.95), and after projecting the disease axis out IL-17A falls to +0.058. The crossed control kills the drug-level reading: etanercept's effect ranks IL-17A **first** too (+0.54, above its own target TNF +0.40), difference-of-differences −0.120 [−0.296, +0.083]; the two drug effects are cos +0.671 to each other. So lever ranking is indication-level, not drug-level. Also: barrier again lowest at PASI 98 (+0.38 vs 0.98–1.08, a fifth drug, 4/12 coverage); randomised withdrawal returns to the lesion position (+0.86 vs −0.01, attractor result now randomised); residual still does not predict relapse (own −0.33 vs other −0.11; ρ +0.10, p 0.87) |
| `d21_lincs_drug_levers` | **GSE70138** LINCS L1000 Phase 2: 118,050 level-5 signatures, 2,171 compounds, 7 main cell lines | Swaps the nine-cytokine lever library for ~1,800 real compounds scored the Connectivity-Map way. Machinery check passes (16 antiproliferatives lower the measured proliferation module, AUC 0.72), but the drug-level positive control **fails in all four variants**: 23 psoriasis therapies vs 28 unrelated drugs gives AUC 0.634 (p 0.055) / 0.514 / 0.520 / 0.556 across {measured 978 genes, disease genes} x {cosine, CMap-style rank}; the best psoriasis drug ranks #166 of 1768 and the two known psoriasis *aggravators* score above the therapies in the disease-gene space. | `d22_scar_after_cause_removed` | **GSE7895** bronchial epithelium (21 never / 52 current / 31 former smokers, 1–504 months since quitting); **GSE145358** coeliac duodenum (15 paired patients on a gluten-free diet then gluten-challenged, 6 healthy controls) | Asks the restoration question where the CAUSE is removed and no drug is holding anything down. In the only identifiable comparison, an age-matched 40–60 window (n = 5 vs 7), secretory/mucous (+0.93 vs +0.20) and squamous/basal structure (+0.62 vs −0.39) stay displaced at p 0.03 (BH q 0.091) while xenobiotic metabolism and cilia are back: the predicted ordering, at suggestive strength. Coeliac: a residue exists on the gluten-free diet (crypt proliferation +0.51, epithelial absorption +0.41, q 0.073) but the housekeeping control drifts +0.36 — bulk composition change makes housekeeping genes useless as a negative control here, so this cohort cannot separate a molecular scar from a global shift. Clean result: re-exposure moves the tissue along the leave-one-patient-out disease axis (median cos +0.52), the attractor behaviour of D19/D20 in a third disease and with the cause rather than a drug |
| `d23_three_mechanisms` | **GSE11903** etanercept + **GSE102725** secukinumab + **GSE69967** tofacitinib (with a placebo arm): three mechanisms, one disease, per-patient effect vectors | One disease axis: cross-cohort disease-vector cosines (+0.51 to +0.72) sit in the same range as the patient-to-patient cosines inside one cohort (+0.48 to +0.66), so a disease axis transfers across studies and platforms. | `d24_cooccurrence_sensitisation` | **Frangieh/Izar 2021 Perturb-CITE-seq** melanoma via scPerturb: 218,331 cells x 24 surface proteins (HLA-A, CD58 and four isotype controls), CRISPR KO x {control, IFN-γ, TIL co-culture} | Tests the co-occurrence hypothesis — that Cov(antigen presentation, adhesion) within cells carries information the means do not.
