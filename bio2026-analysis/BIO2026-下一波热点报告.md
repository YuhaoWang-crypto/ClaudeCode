# BIO2026 资产清单解读：卖家市场偏倚校正后的下一波热点预测

**数据源**　BIO2026 AssetsExport（对外推介资产：管线 + 公司），共 **11,976** 个资产
**方法**　把"卖方摆上货架的东西"当作滞后/同期指标做偏倚校正，用早期 + 学术 + 未被买家验证的稀缺信号反推 2–4 年后的下一波
**日期**　2026-07-09
**定位**　面向 **BD / 授权买家** 的方向性判断，非二级市场择时

---

## 一、执行摘要

BIO 的资产清单本质是"卖方选择拿出来推的东西"。它系统性地高估**当下最好融资、最好授权**的品类——卖方会主动往热词上靠。因此**货架上数量最多的东西（ADC、通用 TCE、自免、细胞因子）其实是"当前这一波"的证据，往往已经拥挤、正在见顶**，而不是下一波。

要找下一波，必须对原始数量做偏倚校正。校正后，信号最强的领先主题是：

1. **纳米抗体 / VHH / 单域抗体** —— 下一代多特异、口服、入脑的"基础积木"
2. **KRAS/RAS 的第二代**（G12C 之外：pan-RAS、G12D、RAS(ON)）
3. **肿瘤间质靶向 PSMA/FAP**（放射配体 + FAP-TCE 双线）
4. **蛋白降解剂 PROTAC / 分子胶**（从肿瘤外扩到自免、CNS）
5. **二代神经退行**（tau / synuclein / **TDP-43**，ALS/FTD 信号密集）

但**真正的 α 不在单一模态，而在"成熟模态 × 新适应症"的收敛交叉口**——例如 TCE 跨进自免、降解剂进 I&I、口服生物药、入脑生物药、体内 CAR。这些交叉点数量还小、几乎全是早期、卖方还没大规模贴热词，是这份货架里最值得盯的部分。

**池子的整体特征**（支撑"用早期学术信号做反推"的合理性）：

| 指标 | 数值 | 含义 |
|---|---|---|
| 早期占比（临床前 + Ph1 + 发现/优化） | **≈ 62%** | 这是一个以早期科学为主的池子 |
| 学术 / 院校来源 | **27.5%**（3,289 个） | 用户最看重的"大学早期项目"层足够厚 |
| 已 partnered（买家已验证） | **仅 4.8%**（508 个） | 绝大多数尚未被买家定价，反推空间大 |

## 二、加权逻辑（为什么不能直接看数量）

卖家市场的两个系统性偏倚：

1. **热词趋同**——卖方把资产往当下最好授权的品类语言上包装，所以原始数量是**当前热度周期**的同期/滞后指标，不是下一波。
2. **需要找钱才参展**——清单偏向资本密集型模态，以及更小的、学术型的卖方。

每个主题的 **Next-Wave 分数** = 5 个标准化（z-score）项的加权和：

| 方向 | 权重 | 项 | 逻辑 |
|:--:|:--:|---|---|
| ＋ | 1.2 | **不成熟度差**（early − late 占比） | 形状在"上升"还是"见顶" |
| ＋ | 1.1 | **早期富集** | 科学领先商业 2–4 年；集中在临床前/Ph1 = 方向 |
| ＋ | 1.0 | **学术来源占比** | 院校资产受"可发表的新颖性"驱动，最少被授权时尚污染 |
| − | 0.7 | **拥挤惩罚** log(N) | 货架越满 = 交易越拥挤 = 越晚 |
| − | 0.6 | **已 partnered 率** | 已被买家验证 = 今天的波，价值已定价 |

> 一句话：**高早期 + 高学术 + 上升形状 + 稀缺 + 未被买家抢 = 领先信号**；**高数量 + 高 partnered = 正在主流化的当前波。**

## 四、真正的 α：模态 × 新领域的收敛交叉口

单看模态排名会被"数量"拉平。下一波往往出现在**成熟模态跨进新适应症**的交叉口——这里数量还小、几乎全早期、卖方还没大规模贴热词。

| 收敛交叉点 | 资产数 | 早期% | 学术% | 论点 |
|---|--:|--:|--:|---|
| **TCE → 自免 / I&I（非肿瘤）** | 90 | 80 | 3 | CD3 双抗从肿瘤跨进精准免疫，跟随"B 细胞清除治自免"浪潮 |
| **降解剂 → I&I（肿瘤之外）** | 57 | 77 | 11 | PROTAC/分子胶进入炎症与自免，绕开不可成药靶点 |
| **分子胶（molecular glue）** | 59 | 61 | 7 | 比经典 PROTAC 更小、更口服友好，独立成势 |
| **口服生物药 / 口服多肽** | 296 | 69 | 13 | 一旦跑通即重构给药经济学 |

## 五、早期学术层里反复出现的具体靶点

在 **1,633 个"学术 + 早期"资产**（用户最看重的一层）里，高频复现、尚未进入商业热词的具体名字：

- **神经**：TDP-43 / ALS（复现最密）、FTD（额颞叶痴呆）
- **免疫/髓系**：GPR84（髓系 GPCR）、GARP（TGF-β/Treg）、CD74、STAT3
- **肿瘤**：TNBC（三阴乳腺）、GBM、PDAC（难治实体瘤）、AR（前列腺）、HDAC
- **其他**：AMD（眼底）、SCD（镰状细胞）、GVHD、HLA 修饰

这些是"科学动能已在积累、但还没变成拥挤赛道"的候选。

## 七、诚实的边界

- **关键词匹配有噪声**：主题靠名称/描述的正则聚合，`senescence/aging`、`cytokine` 等宽词会虚高；数字是量级参考，不是精确计数。
- **卖方自报**：适应症、开发阶段均为参展方自填，可能夸大阶段或蹭热点；partnered 字段缺失约 11%。
- **"下一波"取决于你是谁**：本模型指向 **BD/授权买家** 的下一波 ≠ **二级市场** 的下一波——后者时间轴更短、更看临床读出。
- **拥挤惩罚会误伤长青模态**：ADC、TCE 数量大被压分，不代表衰退——它们既是当前波、也仍在扩张，只是不再"逆向便宜"。
- **缺时间轴**：这是单次快照，无法看同比增速。真正的动能应叠加 **BIO2025 同款导出**做 diff（强烈建议的下一步）。

## 八、建议的下一步

1. **同比增速版（最有价值）**：拿到 BIO2025 AssetsExport，对每个主题算增速。**动能（Δ）比快照更可信**——今年新增最快的主题才是真正的领先信号。
2. **主题下钻**：对排行榜任一主题导出具体公司/资产清单（含阶段、是否 partnered、网站），做成可直接接触的 BD 目标表。
3. **外部交叉验证**：用 ClinicalTrials.gov / PubMed 核对前几个信号是否真在加速（试验注册数、论文数的时间趋势），排除"卖方一厢情愿"。
