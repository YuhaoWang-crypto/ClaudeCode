## 二、为什么判定色谱图是合成的

`01_ab1_qc_forensics.py` 的 7 项检验（见 `results/qc_forensics_report.txt`）：

| # | 检验 | 实测 | 真实数据应有 |
|---|---|---|---|
| T1 | 峰间距标准差 | **0.000 scan**（恒为 13） | >1，随读长单调漂移 |
| T2 | 分析道长度 | **9555 = 735 × 13**，整除 | 与碱基数无整除关系 |
| T3 | 主峰高变异 | **CV=0.003**；首50峰/末50峰=**1.00**；735 个峰只有 11 种高度 | CV 0.3~0.8；末端衰减数倍 |
| T4 | 峰形对称性 | 峰心等距两点强度差 **0.0057**（近乎完美高斯） | >0.03（毛细管拖尾） |
| T5 | 基线 | 51.2% 的点**恰好等于 0**，**零个负值** | KB 扣基线后必然出现负值与涨落 |
| T6 | 质量值 QV | 735 个碱基**全部 QV=50**，唯一取值 1 个 | 读段两端必然衰减 |
| T7 | 内部数组自洽性 | PBAS/PCON/PLOC=**735**，而 P1AM/P2AM/P2BA/P1WD=**252** | 全部相等 |

另有元数据矛盾：头部 `RUND=2026-03-20`，但 `RunN1=Run_ABI-PC_2023-03-13`、`BCTS1=2023-03-13`、
`CTID1=20230313-FY041-020-020-f`、`SMED1=Jan 01, 2023`、`TUBE1=E2`（文件名却是 E08）。
说明该文件是**以一份 2023 年的旧 ab1 为模板重写生成**的。

`results/chromatogram_evidence.png` 四联图直观对比：
A/B = 合成分析道（等高等宽高斯、跨 735 碱基毫无衰减），
C/D = 原始道（染料团、指数衰减、真实噪音与变化的峰高）——两者一眼可辨。

## 三、三条互不相关的序列

用 `02_raw_trace_basecall.py` 自估染料串扰矩阵、解混、独立寻峰，从**未被改写的原始道**
反演出 898 nt 序列，再与文件内各序列做局部比对（30 次序列打乱作对照）：

| 比较 | 局部比对分 | 打乱对照 | Z |
|---|---|---|---|
| 原始道反演 vs **自身前 300 nt**（阳性对照） | 600 | 20±2 | **+262.8** |
| 原始道反演 vs **PBAS1 判读序列** | 24 | 21±2 | +1.3 |
| 原始道反演 vs **P2BA1 内嵌 252 nt** | 19 | 19±1 | −0.2 |
| PBAS1 vs P2BA1 | 20 | 19±2 | +0.3 |

即**原始波形与所报告的序列毫无关系**（与随机打乱无异）。BLAST 证实：

* **PBAS1（735 bp，报告序列）** → *E. coli* Nissle 1917 染色体，728/735 = 99.05%，E=0
* **原始道反演（898 nt）** → 慢病毒/哺乳表达载体（pCDH-CMV-MCS-lox-EF1-Puro-lox、
  pLV、pFUSE、piggyBac 等同源骨架），505/564 = 90%（10% 差异来自无迁移率校正的粗解混）
* **P2BA1（252 nt）** → 无显著同源（符合"次选碱基"本应是噪音的性质）

原始道来自 2023 年那份模板文件的哺乳载体样品；判读序列则另有来源。

## 四、序列的具体生物学分析

### 4.1 定位

`PBAS1` 反向互补后比对到 *E. coli* K-12 MG1655（`NC_000913.3`）。该位点野生型基因顺序为
`purC – bamC(nlpB/dapX) – dapA – gcvR`（均在负链）。读段呈**两臂分裂**：

```
右臂 (bamC 侧)  读段   1-365   <->  MG1655 2,598,517-2,598,881
左臂 (gcvR 侧)  读段 365-735   <->  MG1655 2,599,760-2,600,130
                       ↑ 重叠 1 bp 微同源 "T"
```

**缺失区间 = MG1655 2,598,882 – 2,599,759 = 878 bp**

| 基因 | 坐标 | 落入缺失区 |
|---|---|---|
| purC | 2,596,905-2,597,618 | 0 bp (0%) |
| bamC | 2,597,831-2,598,865 | 0 bp (0%) |
| **dapA** | **2,598,882-2,599,760 (879 bp)** | **878 bp (99.9%)** |
| gcvR | 2,599,906-2,600,478 | 0 bp (0%) |

断点序列（小写 = bamC 侧 / 大写 = gcvR 侧）：

```
...aggcgcgacttttgaacagagtaagccatcaaatctccctaaact | GGGCCATCCTCTGTGCAAACAAGTGTCTCAATGGTACGTTTGGTA...
```

### 4.2 解读

1. **dapA 被完整敲除。** 878/879 bp 被删除，只余起始密码子的 1 个碱基，无残留可读框。
2. **无痕（markerless）敲除。** 连接处只有 1 bp 微同源，**没有** FRT(34 bp)、loxP(34 bp) 或
   任何抗性表达盒——符合 λ-Red + FLP/I-SceI 无痕或 CRISPR 辅助的无标记缺失。
3. **邻近基因完好。** bamC 读到的 116 个密码子翻译后与参考 BamC 蛋白 **116/116 = 100%** 一致
   （`MAYSVQKSRLAKVAGVSLVLLLAACSSDSRYKRQ...`，含典型脂蛋白 lipobox `LAAC`）；
   与野生型 *E. coli* 基因组比对该段为 **365/365 = 100%**。gcvR 侧同样完整。
   说明缺失精确、未波及 BAM 复合体组分与甘氨酸裂解系统调控子。
4. **表型含义。** dapA 编码 4-羟基-四氢吡啶二羧酸合酶（DHDPS），是赖氨酸/DAP 支路第一个
   限速步骤。ΔdapA 无法合成 meso-DAP，肽聚糖无法交联，**离开外源 DAP 即裂解死亡**——
   这正是工程益生菌（EcN 底盘活菌药物）标准的**营养缺陷型生物封闭（biocontainment）**设计。
5. **与已发表基因组吻合。** GenBank `CP171242.1`（"*E. coli* Nissle 1917"，2024 年提交，
   治疗性益生菌研究）在同一位点**同样缺失 dapA**，读段对它 735/735 全长比对 99.05%；
   而 50 条命中基因组中**只有它**含此连接点，其余野生型菌株都在断点处一分为二
   （两段 HSP 在基因组上相隔 ~880 bp）。
6. 文件名中的 **"DAPA21"** 与此完全自洽——很可能是 dapA 敲除克隆 #21 的验证测序。

## 五、建议

1. **向擎科索要真实原始 ab1**，并说明本文件色谱图为合成、且原始道属于另一份 2023 年的
   哺乳载体样品。在拿到真实数据前，这份文件不能进实验记录、不能作为克隆验证凭证、
   更不能用于报批或论文补充材料。
2. 拿到新文件后先跑 `01_ab1_qc_forensics.py` 复核。
3. dapA 敲除的关键结论（878 bp 无痕缺失、两侧基因完整）本身很可能是对的，但需要
   **真实色谱图 + 双向测序**（正反向引物各一条，覆盖整个断点）来确认。
4. 建议补做表型验证：无 DAP 的 M9/LB 平板上不生长、加 DAP（50–100 µg/mL）恢复生长。
