# 案例 2：`37HVPX_1_D12.ab1`

一份独立送检的 .ab1。与案例 1（DAPA21）无关：内容是一个**双价 VHH CAR 慢病毒转移载体**表达盒。

---

## 一、这份文件是什么

| | 案例 1 `DAPA21` | 案例 2 `37HVPX_1_D12` |
|---|---|---|
| ABIF 标签数 | 126 | **10**（仅够查看器打开的最小集） |
| 仪器元数据 | 完整伪造（3730xl / POP7 / BigDye v3 / 泳道 / 日期） | **完全没有** |
| 原始道 DATA1-4 | 有，但属于另一份 2023 年的哺乳载体样品 | **没有** |
| 读长 | 735 bp | **4580 bp** |
| 质量值 | 全部恒为 50 | Q4–50，均值 10.6，中位数 10 |
| 色谱图 | 等高等宽高斯，伪装成真实电泳 | 方波渲染，4 采样点/碱基，**峰高 = 20 × QV（r = 0.9965）** |

案例 2 看起来是一次**诚实的格式转换**（FASTQ/FASTA → .ab1 供 SnapGene/Chromas 查看），不是伪造的 Sanger 谱图。

## 二、但质量值与序列对不上

**不可能是 Sanger**：4580 bp，毛细管电泳物理上限约 1000–1200 bp。

**也不是纳米孔原始读段**——文件声称 Q9–12（≈10% 每碱基错误率），但序列几乎零错误：

| 读段窗口 | 该窗平均 QV | QV 隐含错误率 | BLAST 最佳一致性 |
|---|---|---|---|
| 1–500 | 16.4 | 5.0% | 464/464 = **100%** |
| 501–1000 | 10.2 | 9.6% | 267/311 = 86% |
| 1001–1500 | 9.8 | 10.6% | 271/345 = 79% |
| 1501–2000 | 9.1 | 12.5% | 180/229 = 79%（骆驼 VHH mRNA） |
| 2001–2500 | 9.0 | 12.5% | 287/291 = 99% |
| 2501–3000 | 9.0 | 12.5% | 500/500 = **100%** |
| 3001–3500 | 9.8 | 10.6% | 500/500 = **100%** |
| 3501–4000 | 10.5 | 9.0% | 439/440 = 99% |
| 4001–4500 | 11.2 | 7.6% | 500/500 = **100%** |

79–86% 的三个窗口落在 VHH / CAR 自定义区，公共库里没有确切参考，**不代表测序错误**。

两条判据：

1. 三个独立的 500 bp 窗口对公共参考 **500/500 = 100%**。若真为 Q10，单个 500 bp 窗口全对的概率约 `0.9^500 ≈ 10⁻²³`。
2. 1488 nt 的 CAR 阅读框译出 495 aa，**无移码、无提前终止**，结构域边界完全正确。ONT 错误以插入缺失为主，Q10 的原始读段不可能让 1488 nt 阅读框毫发无损。

结论：序列是**打磨过的**（consensus / 组装 / 或设计图），那条 Q9–12 的质量串不是它的质量。

## 三、一处确实像纳米孔

读段 3' 末端有 **36 bp 折返**：在回文位点 `CAGCTG` 处掉头，接着读回前面序列的反向互补。

```
载体正义方向最后 60 bp:
GACCAATGACTTACAAGGCAGCTG | CCTTGTAAGTCATTGGTCCCTCATATCTCCTCCTCC
                            = revcomp(GGAGGAGGAGATATGAGGGACCAATGACTTACAAGG)
```

这是 ONT 建库时双链未分开的典型假象。所以底层数据很可能真是纳米孔的——但这份 .ab1 是成品，不是证据。

## 四、序列内容：二代双价 VHH CAR 慢病毒转移载体

坐标为载体正义方向（= 文件内序列的反向互补），全长 4580 bp。

| 位置 | 元件 |
|---|---|
| 1..~850 | HIV-1 env 片段 / **RRE**（茎环 136–171） |
| 861..899 | **cPPT / CTS** |
| 1176..~2350 | **人 EF-1α 启动子**（完整含内含子；供体 1400，受体 2341） |
| 2358..2401 | MCS：NheI–AgeI–BglII–XhoI–SacI–HindIII–EcoRI |
| 2402..2416 | Kozak `GCCGCCACC` + ATG |
| **2411..3898** | **CAR 阅读框，1488 nt / 495 aa** |
| 3890..3904 | 终止密码子 TAA + XbaI |
| 3919..~4500 | **WPRE** |
| 4510..4544 | **3'ΔU3 LTR** 起始 |
| 4545..4580 | 折返假象 |

CAR 结构（495 aa）：

```
CD8α 信号肽 (1-21) → VHH1 (22-142) → (G4S) 连接子 → VHH2 (148-260)
  → CD8α 铰链 (273-317) → CD8α 跨膜 (318-341) → 4-1BB (342-383) → CD3ζ (384-495)
```

即标准 **BBζ 二代 CAR**。共刺激域是 **4-1BB**（`KRGRKKLLYIFKQPFMRPVQTTQEEDGCSCRFPEEEEGGCEL`），不是 CD28。

两个 VHH 都带骆驼科单域抗体特征：

* FR2 hallmark——VHH1 `WYRQ`、VHH2 `WGRQ`（常规抗体是 `WVRQ`）
* CDR1–CDR3 额外二硫键——VHH1 的 CDR1 `RYTSSGCNVG` 与 CDR3 `NIAPPYTTHCASRRF` 各含一个 Cys；VHH2 的 CDR3 `AENVDCYGGYCYRANY` 含两个

blastp 查不到确切来源，最佳命中是各种羊驼纳米抗体、仅 70–75% 一致——属于**自有 / 未公开的 VHH**，从序列判断不出靶点。

## 五、能不能用

* **序列内容本身合理**：ORF 干净、元件齐全、结构域边界准确、Kozak 正确。作为一张"图纸"没问题。
* **但它不能自证**：序列是打磨过的、质量串又和序列对不上，这份 .ab1 **无法证明手上的质粒真的长这样**。

要真正验证，需要 ONT 的完整交付：

1. 原始 reads —— FASTQ（或 POD5）
2. 比对结果 —— BAM + 覆盖深度曲线
3. 组装 / consensus FASTA + 组装工具与版本
4. **CAR 插入片段（2411–3898）上的覆盖深度**，以及有没有 reads 完整跨过整个插入片段

有了 2 和 4 才谈得上"验证"；现在这份只是把结论渲染成了一张图。
