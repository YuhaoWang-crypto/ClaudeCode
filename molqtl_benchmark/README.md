# 顺式 / 反式分子 QTL 因果定位:公开数据实测

检验矩阵这一行的承诺:cis-eQTL 定位(tensorQTL)、精细定位(SuSiE)、共定位与因果方向(coloc / MR)、
"仅凭单份基因型预测基因表达"(PrediXcan 权重)。

结论先行:**同祖源内 eQTL 定位和共定位可靠;换祖源后复现率和预测精度大幅下降,用错祖源的 LD 做精细定位基本全错;共定位分不清高度连锁的两个变异,也不能指认因果基因**。

## 数据

| 用途 | 数据 | 说明 |
|---|---|---|
| eQTL 定位与表达预测 | GEUVADIS:1000 Genomes 淋巴细胞系,462 人,21、22 号染色体 31 万 SNP、899 个基因 | 欧洲 373 人随机分为训练 261 / 留出 112;非洲 YRI 89 人全部留出 |
| 预训练表达权重 | PredictDB GTEx v8 弹性网络,淋巴细胞系(GTEx 147 人训练) | GEUVADIS 个体不在 GTEx 中 |
| 精细定位 / 共定位真值 | 150 个真实基因组区段(真实 LD)上模拟表型 | 因果变异已知 |
| 真实位点 | 1p13(SORT1)× LDL 胆固醇:GLGC 2021 欧洲人 GWAS + GTEx 五个组织 eQTL | 已有实验结论:rs12740374 在肝脏特异调控 SORT1(Musunuru 2010) |

## 结果

### 1. cis-eQTL:在没见过的人里能否复现

在 261 名欧洲人中找到 141 个 eGene(FDR 5%),取每个基因的最强变异到留出人群里检验。

| | 留出欧洲人(112) | 非洲 YRI(89) |
|---|---|---|
| 方向一致 | 93.6% | 85.7% |
| 复现(p<0.05 且同向),占全部 141 个 | **77.3%** | **33.3%** |
| 效应量相对训练集的中位比值 | 0.86 | 0.59 |
| 变异在该人群中不存在或单态 | 0 | 15 个 |

两组人数相近,差异主要来自祖源(LD 结构和等位基因频率不同)。

### 2. 单份基因型预测表达

每个基因计算预测值与实测表达的相关系数 r。

| 权重来源 | 基因数 | 欧洲人 中位 r | YRI 中位 r | r ≤ 0 的基因占比(欧洲 / YRI) |
|---|---|---|---|---|
| GTEx 预训练权重(官方报告交叉验证中位 ρ = 0.37) | 112 | **0.15** | **0.09** | 14% / 26% |
| 本地训练,全部基因 | 894 | 0.00 | 0.00 | 65% / 71% |
| 本地训练,仅训练集内显著的 eGene | 141 | 0.28 | 0.15 | 8% / 25% |

- 预训练权重搬到新队列后,精度约为官方报告值的四成;只有 29% 的基因 r > 0.3。
- 两条染色体 899 个基因里只有 112 个有预训练模型,多数基因根本没有可用权重。
- 官方报告的模型质量与实测 r 的秩相关只有 0.29,不能靠它挑出哪些基因预测得准。

### 3. 精细定位(SuSiE,真值已知)

| LD 来源 | 95% 可信集含因果变异的比例(1 / 2 / 3 个因果变异) | 每次运行的错误可信集数 |
|---|---|---|
| 个体水平数据 | 0.99 / 0.93 / 0.94 | 0.01–0.12 |
| 汇总统计 + 样本内 LD | 1.00 / 0.97 / 0.95 | 0.00–0.07 |
| 汇总统计 + 同祖源外部 LD(112 人) | 0.71 / 0.69 / 0.65 | 0.41–0.76 |
| 汇总统计 + 异祖源 LD(YRI 89 人) | **0.05 / 0.06 / 0.06** | **约 8.9** |

- LD 匹配时覆盖率达到标称的 95%;可信集中位 4–10 个 SNP,最高 PIP 的 SNP 只有 50%–61% 是真因果变异。
- 多个因果变异时检出率下降:1 个 0.99,2 个 0.71,3 个 0.60。
- 用异祖源 LD:每个区段报出约 9 个可信集,几乎全是假的。
- 同祖源但参考样本很小(112 人)时覆盖率也只有约 0.7。真实参考面板更大,这个数字偏悲观;但它说明 LD 参考的规模和匹配度都要管。

### 4. 共定位(coloc,真值已知)

| 真实情况 | 判为"共享因果变异"(PP.H4 > 0.8)的比例 |
|---|---|
| 同一因果变异,强 eQTL | 97% |
| 同一因果变异,弱 eQTL(解释 4% 方差) | 67% |
| 两个不同变异,r² < 0.1 | 0% |
| 两个不同变异,r² 0.3–0.7 | 5% |
| 两个不同变异,r² 0.8–0.95 | **89%** |
| 只有 GWAS 信号,无 eQTL | 0% |

### 5. 真实位点:SORT1 × LDL

| 基因 | 肝脏 | 肌肉 | 脂肪 | 血液 | 淋巴细胞系 |
|---|---|---|---|---|---|
| SORT1 | **1.00** | 0.03 | 0.05 | 0.04 | 0.06 |
| PSRC1 | 1.00 | 0.97 | 0.00 | 0.84 | 0.08 |
| CELSR2 | 1.00 | 1.00 | 0.01 | 0.00 | 0.06 |

(表中为 PP.H4。)

- SORT1 只在肝脏共定位,最强 eQTL 变异正是 rs12740374;Wald 比值为 −0.11(表达每升高 1 个标准差,LDL 下降),方向与已知实验结论一致。
- 但肝脏里 SORT1、PSRC1、CELSR2 三个基因的 PP.H4 都是 1.00,CELSR2 在肌肉里也是 1.00。共定位无法告诉你哪个基因是因果基因,这一步靠的是功能实验。
- 换成非相关组织,SORT1 的信号完全消失:缺对应组织的 QTL 时得不出结论。

## 对矩阵这一行的修改建议

1. 第 05 栏"TWAS 表达预测"应注明:只对有模型的基因可用,且精度按独立队列实测值(中位 r ≈ 0.15)而非官方交叉验证值报告。
2. "祖源匹配 LD"应从"预处理要点"升级为硬性前置条件:客户祖源与参考不匹配时,精细定位结果不交付。
3. 共定位结果应表述为"信号共享的候选基因列表";同一位点多个基因同时阳性时不指认单一靶基因。
4. 第 06 栏的边界(缺对应组织 QTL 不能强推因果)与实测一致,可保留。

## 未测 / 限制

- **反式 eQTL 热点、单细胞 sc-eQTL(SAIGE-QTL)没有测**:462 人对反式效应检出力不足;OneK1K 个体数据需申请。
- FINEMAP、TwoSampleMR 软件包、FUSION 未测;MR 只做了单变异 Wald 比值,未做多工具变量和多效性检验。
- 只用了 21、22 号染色体和淋巴细胞系一个组织。
- GEUVADIS 表达矩阵是对全部 462 人统一做过 PEER 校正的版本,训练/留出之间在归一化层面不是完全独立。
- 精细定位和共定位的真值来自模拟(真实 LD + 模拟表型),各 150 个区段,单一效应量设定。
- 真实位点只有 SORT1 一个,是领域内最干净的例子,不代表一般位点的难度。
