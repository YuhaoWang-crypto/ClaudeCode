# 疾病风险分层与临床标志物面板:公开数据实测

检验矩阵这一行的两类承诺与它标注的边界。
承诺(第 05 栏):"输入客户单份基因型、单份 cfDNA 或单份组学矩阵,直接计算研究性 PRS 评分 或输出 挂钩临床预后的标志物面板候选"。
边界(第 06 栏):**"单人数据只能'打分',绝对不能验证目标人群的 AUC、校准度或临床增量价值"**。

结论先行:**打分能做,验证不能**。公开 PRS 权重跨祖源完全不可移植(用欧洲阈值会把 91% 的东亚人判为 T2D 高遗传风险);
锁定的表达预后面板在训练集看着很好(C 指数 0.66–0.82),到独立样本掉到 0.53–0.72,常常还不如"年龄+分期",跨癌种迁移等于抛硬币。

## 数据(全部公开)

| 部分 | 数据 | 说明 |
|---|---|---|
| PRS 跨祖源 | 1000 Genomes 2504 人(5 大洲群)+ PGS Catalog 公开权重:T2D、LDL、身高、CAD | 部分基因组(已抽取染色体 2/3/7),用于展示分布漂移,非绝对风险 |
| 预后面板 | TCGA 泛癌表达(UCSC Xena)+ 整理生存表,4 个癌种 LUAD/LUSC/KIRC/BRCA | 各 494–1081 例,8000 高变基因取前 2500 |

## 结果

### 1. PRS:同一套权重,换祖源就不可解释(证实边界)

把每个人的 PRS 换算成"相对欧洲人分布的标准差(z)",再看用欧洲人 95 百分位阈值判为"高遗传风险"的比例:

| 性状 | 各祖源 PRS 均值(z,欧洲=0) | 被欧洲阈值判为"高风险"的比例 |
|---|---|---|
| T2D | SAS +1.45, AMR +0.79, EAS **+2.76**, AFR +1.36 | EUR 3.6% → **EAS 90.9%**, SAS 42%, AFR 38%, AMR 20% |
| CAD | SAS +0.66, EAS +0.72, AFR +0.72 | EUR 5% → SAS 17%, EAS 15%, AFR 9% |
| 身高 | SAS −0.73, EAS −0.73, AFR +0.68 | — |
| LDL | 各祖源接近,AFR −0.54 | EUR 3.6% → 其余 <2% |

同一套权重,东亚人的 T2D PRS 整体比欧洲人高 2.76 个标准差——这几乎全是等位基因频率/连锁差异造成的假象,不是真实风险差。
所以**一个客户的原始 PRS 分数,脱离祖源匹配的参照分布就无法解释**;而这个参照、以及校准和 AUC,都无法从单个样本里得到。这正是第 06 栏那句话。

### 2. 预后面板:能打分,但"增量价值/校准"验证不了(证实边界)

在每个癌种内 60% 训练锁定弹性网络 Cox 面板,40% 独立测试,重复 3 次(OS C 指数):

| 癌种 | 训练集(表观) | 面板·独立测试 | 年龄+分期·独立测试 | 面板+年龄+分期 | 面板基因数 |
|---|---|---|---|---|---|
| LUAD | 0.757 | 0.609 | **0.671** | 0.658 | 29 |
| LUSC | 0.660 | 0.534 | **0.577** | 0.561 | 7 |
| KIRC | 0.769 | 0.716 | 0.748 | **0.779** | 29 |
| BRCA | 0.817 | 0.596 | **0.731** | 0.694 | 45 |

- **乐观偏差**:训练集 C 指数(0.66–0.82)到独立测试掉 0.1–0.22(BRCA 0.82→0.60)。单看训练集会严重高估。
- **增量价值常为负**:LUAD、LUSC、BRCA 三个癌种里,单用"年龄+分期"就比表达面板准;把面板加进去也没超过临床变量(BRCA 面板+临床 0.69 < 临床单独 0.73,面板反而拖累)。只有 KIRC 面板有独立贡献。
- **跨癌种迁移失效**:把某癌种锁定的面板用到别的癌种,C 指数 0.44–0.58(基本是 0.5),个别低于 0.5。
- **防泄漏对照**:训练标签随机打乱后,独立测试 C 指数 0.46(≈0.5),说明流程本身不泄漏。

## 对矩阵这一行的修改建议

1. 第 05 栏保留"打分",但明确:PRS 必须随附祖源匹配的参照分布,否则单个分数不可解释;非欧洲祖源直接标"需要本祖源参照"。
2. 预后面板的精度必须报独立测试 C 指数,不报训练集;并强制与"年龄+分期"基线比较增量,没有增量就不交付。
3. 第 06 栏那句边界完全正确,建议作为交付物的硬性免责声明,并给出量化锚点(欧洲阈值下东亚 T2D 高风险率 91%;预后面板独立测试常不敌临床变量)。

## 限制

- **PRS 是部分基因组**(染色体 2/3/7):1000G 全基因组 VCF 下载过慢,只抽取了部分染色体的权重位点。漂移的方向和量级与全基因组文献一致,但绝对 z 值会随纳入位点变化;这里用于展示"跨祖源不可移植",不作绝对风险。
- 没测真正的疾病结局 PRS-AUC(1000G 是健康样本,无疾病表型);用祖源间分布漂移替代,直接对应"单样本不能验证校准/AUC"。
- 预后面板只做了 TCGA 内部随机切分 + 跨癌种迁移,没有真正的独立医院队列(如 GEO 外部验证);cfDNA 片段组学(FinaleToolkit)、BayesPrism/Scissor 未测。
- 面板用前 2500 高变基因、弹性网络 Cox、3 次重复,未做大规模超参搜索;结论是方向性的。
- TCGA 生存为 OS;未区分癌症特异生存与竞争风险。
