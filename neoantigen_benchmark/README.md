# 新抗原呈递与免疫受体筛选:公开数据实测

检验矩阵这一行的承诺与它自己标注的边界。
这一行里 MHCflurry 等模型负责"筛出真正能被 HLA 呈递的候选新抗原",
第 06 栏的边界原文:**"预测结合不等于真实免疫原性或 T 细胞杀伤"**。
这正是本次要量化的东西。

结论先行:**呈递/结合预测很强(AUROC 0.94),但它几乎不能预测免疫原性(AUROC 0.50–0.59);
预测为强结合的肽里约 73% 在 T 细胞实验中并不免疫原性**。矩阵标注的边界被数据完全证实。

## 数据(全部公开)

| 用途 | 数据 | 规模 |
|---|---|---|
| 模型 | MHCflurry 2.0 预训练呈递模型(openvax,含亲和力 + 加工 + 呈递) | 支持 14,854 个等位基因 |
| 免疫原性真值 | IEDB T 细胞实测(query-api.iedb.org),人类、HLA-I、线性 8–11 肽、4 位分辨率单等位基因 | 46,799 个肽-等位基因对,阳性 12,752 / 阴性 34,047,151 个等位基因 |
| 呈递诱饵 | 人类 SwissProt 蛋白组随机抽取、长度/等位基因匹配的肽 | 38,256 条 |
| 防泄漏 | 按文献年份切分;MHCflurry 2.0(2020-06 发布)训练数据截至约 2019 | 2021 年后的 9,657 对 |

说明:MHCflurry 预测的是结合/呈递,**从不用免疫原性标签训练**,所以 IEDB 的阳性/阴性结果是对"结合≠免疫原性"这条边界的独立检验。

## 结果

### 1. 呈递预测:很强(符合承诺)

真实表位 vs 蛋白组随机诱饵:

| 指标 | 值 |
|---|---|
| AUROC(呈递分数) | **0.945** |
| AUROC(−亲和力) | 0.943 |
| 2% 诱饵假阳性率下的表位召回 | 64% |
| 真实表位中预测强结合(<500 nM)的比例 | 75.5% |
| 随机诱饵中预测强结合的比例 | 3.5% |
| 2021 年后未见表位 vs 诱饵的 AUROC | **0.94** |

模型能把真实 HLA 配体和随机肽清楚分开,且在训练数据之后的新表位上不退化。这一步"从海量突变里筛出能被呈递的候选"是靠谱的。

### 2. 免疫原性:接近随机(证实边界)

在所有做过 T 细胞实验的肽里,用结合/呈递分数区分免疫原性(阳性)与非免疫原性(阴性):

| 分数 | 全部已检测肽 AUROC | 仅预测强结合肽 AUROC |
|---|---|---|
| 呈递分数 | 0.576 | 0.593 |
| −亲和力 | 0.594 | 0.629 |
| 加工分数 | 0.524 | — |

- 把肽限定为"预测强结合"后,AUROC 仍只有约 0.59:一旦肽能结合,结合分数几乎不再携带免疫原性信息。
- **预测强结合的肽里,只有 27% 在 T 细胞实验中阳性**(即 73% 的强结合肽不免疫原性)。这正是把"结合候选"当成"真实靶点"的代价。
- 分等位基因看:六个数据最多的等位基因 AUROC 为 0.48–0.65,HLA-A*24:02 甚至低于 0.5。

### 3. 防泄漏切分:免疫原性 AUROC 降到 0.50

只用 2021 年后(MHCflurry 训练数据之后)的文献:

| 任务 | AUROC |
|---|---|
| 呈递(2021 后表位 vs 诱饵) | **0.94** |
| 免疫原性(全部) | **0.504** |
| 免疫原性(仅强结合肽) | 0.521 |

呈递能力在未见数据上保持不变;免疫原性预测则恰好等于抛硬币。
近两年数据多来自 SARS-CoV-2 等系统性筛选(阳性和阴性都是强结合肽),去掉了"结合"这个混杂,于是结合分数对免疫原性的区分力彻底消失——这是最干净的证据。

## 对矩阵这一行的修改建议

1. 第 05 栏"突变肽呈递与免疫原性排序"应拆成两件事:**呈递排序可交付(AUROC 0.94),免疫原性排序不可交付(AUROC ≈ 0.5)**。不要把结合/呈递分数当免疫原性评分对外输出。
2. 新抗原优先级清单应标注:这是"可被呈递的候选",预期其中只有约四分之一具备 T 细胞免疫原性,须经 ELISpot/多聚体等湿实验确认。
3. 第 06 栏原有的边界表述完全正确,建议从"边界"提升为交付物的硬性免责声明并给出量化值(强结合肽阳性率约 27%)。

## 限制

- **只测了 MHCflurry 一个模型**:BigMHC、TransPHLA、MHCII 类(HLAIIPred)、TCR 聚类(GLIPH2)未测;本结论针对 HLA-I 结合/呈递预测这一类方法,免疫原性这一环各家普遍接近随机,但未逐一复测。
- **IEDB 的"阴性"是有噪声的负例**:一次 T 细胞实验阴性受供体 HLA 背景、检测方式影响,不等于该肽绝不免疫原性。这会让免疫原性 AUROC 偏低一些,但方向稳健,与文献(TESLA 等)一致。
- IEDB 的阳性肽是研究者挑过的(本身偏向会结合),这会抬高"全部已检测肽"那一列的 AUROC;2021 后切分部分消除了这一点。
- 没有逐突变做蛋白酶体加工/TAP 转运建模,也没有自体肽耐受扣除;免疫原性的真实决定因素(TCR 库、中枢耐受)本就不在结合模型的范围内。
- 没有真正的新抗原验证队列(如 TESLA,需申请);这里用 IEDB 泛表位数据作为可公开下载的替代。
