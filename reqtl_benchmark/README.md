# 刺激 / 药物响应型 reQTL 与精准用药预警:公开数据实测

这是一个独立命题。**response eQTL(reQTL)**是只在特定刺激/药物/免疫激活下才出现(或显著改变)的 eQTL——
基因型决定一个人对刺激的转录响应。精准用药角度:静息态(抽血直接测)看不到这些 GxE 调控变异,
谁对免疫挑战/药物响应不同,要在"挑战态"才暴露;只用静息态数据做响应预测会系统性漏掉它们。

本次用 eQTL Catalogue 里同供体、同细胞、不同刺激条件的数据集(远程 tabix,全公开)实测。

结论先行:**每种刺激产生约 1,000–1,450 个"响应获得型"eGene(静息态看不到),占受刺激 eGene 的 22–38%;
确认其中约 77–81% 的主效变异在基线确实无显著效应、受刺激后效应约 1.5–2 倍;IFN/病毒类刺激的 reQTL 基因显著富集干扰素响应基因(OR 1.7–2.0),而非 IFN 诱导的 TLR2 刺激不富集(OR 0.9)**。生物学自洽,精准用药预警的遗传基础成立。

## 数据(全部公开,eQTL Catalogue 远程 tabix)

| 细胞 | 条件 | n | 来源 |
|---|---|---|---|
| 单核细胞 | naive / LPS / R848 / 流感病毒 / Pam3CSK4 | ~200 | Quach_2016 |
| 巨噬细胞 | naive / IFNγ | 84 | Alasoo_2018 |

每条件用 `.permuted.tsv.gz`(每基因主效 + 置换 p)定 eGene(BH q<0.05);reQTL 确认用 `.all.tsv.gz` 远程 tabix 把受刺激主效拿回基线查。

## 结果

### 1. 静息态漏掉的响应型 eQTL(精准预警的核心)

| 刺激 | 响应获得型 eGene | 占受刺激 eGene 的比例(基线看不见) |
|---|---|---|
| 单核 +LPS | 1,045 | 22% |
| 单核 +R848 | 1,309 | 29% |
| 单核 +流感 | 1,445 | 32% |
| 单核 +Pam3 | 1,268 | 25% |
| 巨噬 +IFNγ | 642 | 38% |

受免疫/药理挑战后,22–38% 的 eGene 在静息态根本不显著。**只用静息态(常规抽血转录组/eQTL)做个体响应预测,会系统性漏掉约 1/4–1/3 的关键调控变异。**

### 2. 这些确实是真 reQTL,不是阈值假象

把受刺激的主效变异拿回基线全量数据查(单核+流感,n=147 抽样):

| 指标 | 流感 | IFNγ |
|---|---|---|
| 基线不显著(p>1e-4)的比例 | 77% | 81% |
| 效应量倍数(刺激/基线)中位 | 2.05× | 1.49× |

多数响应获得型 eGene 的主效在基线确实无效应、受刺激后效应翻倍——是真正的基因型×刺激互作。约 30–40% 达到"基线 p>0.01 且效应降半"的强确认标准。

### 3. 已知答案:IFN/病毒 reQTL 富集干扰素基因

reQTL 基因在 MSigDB 干扰素响应基因集里的富集(Fisher OR):

| 刺激 | OR | p |
|---|---|---|
| 单核 +LPS | 2.0 | 1.2e-3 |
| 单核 +R848 | 1.7 | 1.0e-2 |
| 单核 +流感 | 1.7 | 5.7e-3 |
| 巨噬 +IFNγ | 1.9 | 1.7e-2 |
| 单核 +Pam3(TLR2,不诱导 IFN) | **0.9** | 0.66(不富集) |

诱导干扰素的刺激(LPS/R848/流感/IFNγ)在干扰素响应基因上制造 reQTL,而不诱导 IFN 的 Pam3CSK4 不富集——完全符合已知免疫生物学。刺激间 reQTL 重叠也有规律(细菌/TLR 类 LPS~Pam3 Jaccard 0.38,病毒类流感与它们重叠低 0.13)。

## 对"精准用药预警"的意义与边界

1. reQTL 真实存在且可观测:基因型确实决定对免疫/药理刺激的转录响应方向与幅度。做响应预测/用药预警,**必须纳入挑战态(刺激后)数据**,静息态面板不够。
2. 可交付的是"在该刺激下,携带某基因型者该基因响应更强/更弱"的候选清单;要落到真实临床药物响应,还需:① 刺激体系与目标药物机制对应(本次是免疫刺激,不是具体药物暴露);② 与药物响应 GWAS 共定位确认因果;③ 前瞻队列验证。本次只到"遗传基础存在且可检出"这一层。

## 限制

- 刺激是免疫挑战(LPS/IFNγ/病毒/TLR 激动剂),**不是具体治疗药物的暴露**;"药物响应型 reQTL"用免疫刺激作代理,真实药物(他汀、化疗等)的 reQTL 需对应的处理-eQTL 数据集。
- reQTL 用"条件特异 eGene + 受刺激主效在基线失效"界定,未做完整的基因型×条件交互模型(需个体水平数据);"响应获得"计数会把部分功效/阈值边界基因算进去,强确认比例约 30–40%。
- 样本量中等(单核 ~200、巨噬 84),弱 reQTL 检出力有限;基线"丢失"的 eGene(lost)部分是功效问题,未深究。
- 富集用 MSigDB Hallmark 集 + HGNC Ensembl→符号映射,少数基因漏映射。
- 没有做与疾病/药物响应 GWAS 的共定位(精准预警落地的关键一步),属下一步。
