VC · 虚拟检测委托台 Virtual Assay Desk

一个能被证伪的委托，
不是一次查询。

知识库和产品的分界线只有一条：客户能提交的东西是谁定义的。从下拉菜单里选一项、看一份早就算好的答案，那是知识库。粘贴你自己的化合物清单、基因清单或单药组合，让模型在你的输入上跑，拿回一份能直接下单排板的交付物——那才是服务。

下面三个委托台是可操作的：输入框里的内容随便改、随便粘贴，每次运行都在浏览器里真实计算。

形态对齐湿实验 CRO：委托单 → 检测 → 报告 → 结算。

差别只在"检测"那一步是计算而不是移液。所以报告必须长得像 CRO 报告：hit 列表、板图、对照设计、QC、适用域告警，外加一份明确写着"这些我们不出，必须你去测"的清单，和一条可以对账的结算条款。

Straight answers

你问的四件事，逐条回答。

高通量筛选、药效模拟、多细胞组合——三个问题的答案分别是"能，但只能排序"、"部分，只有方向没有数值"、"不能"。把这三条分开说清楚，比笼统说"能做虚拟细胞"有用得多。

能做

虚拟高通量预筛 = 排序 + 排板

  • HTS 预筛：10³–10⁵ 化合物 → 一块 96/384 板。这是本产品的主战场
  • MoA 归类与去重：结构 / 转录 / 形态最近邻检索
  • 结构警报与成药性：PAINS、Michael 受体、Lipinski / Veber
  • 基因筛选设计：靶点排序 + 对照 + 文库规模与测序深度
  • 组合空间瘦身：n² → 96 孔，含单药对照与浓度矩阵
  • 板图与对照设计：边缘效应规避、随机化、阴阳性对照布位

部分能做

方向与相对排序，没有绝对数值

  • 药效"模拟"：能给转录响应方向、通路、MoA 类别；不能给 IC50 数值
  • 剂量-时间：只能在已测网格内部插值，不能外推
  • 跨细胞选择性：相对排序可信，绝对治疗窗不可信
  • 毒性前哨：风险分诊与对照设计，不是 DILI 结论
  • 耐药：支路假设与早期预警指标，不是发生时间

不能做

写进合同的排除条款

  • 多细胞共培养 / 免疫杀伤 / 微环境模拟：没有可训练的配对数据，任何号称能做的都是外推
  • 类器官与 3D 培养终点
  • 绝对 IC50 / EC50 与完整剂量曲线
  • 未经配对标签校准的蛋白、分泌、活力读数
  • 从细胞系外推到患者响应
  • 监管级毒理放行
关于"多细胞组合模拟"。这是被问得最多、也最该直接拒绝的一条。要模拟共培养或免疫杀伤，需要成对的「单培养 → 共培养」扰动数据作为训练与验收标准，公开数据里没有这样的规模。现在能诚实做的只有一件事：分别给出各个细胞类型的预测，并明确标注"两者相互作用未建模"。把两条单细胞预测拼起来叫共培养模拟，是这个领域最常见的过度承诺。

Virtual assay desk

下单，然后看报告。

三类委托各有独立的输入契约。输入框里的示例数据只是起点——清空、粘贴你自己的清单，结果会跟着变。所有计算在你的浏览器里完成，不上传任何数据。
