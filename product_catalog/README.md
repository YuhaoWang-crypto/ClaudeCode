## 1. 为什么按细胞系立项，而不是按模型立项

选细胞系的第一个问题不是"它像不像病人"，是"**它有没有能训练和验收的底座数据**"。
没有底座就没有噪声天花板，没有噪声天花板就没有验收标准，所有模型分数都无法解释。

三种底座各自决定不同产品线能否成立：

- **扰动底座** — 该系自有的全基因组 / 必需基因扰动数据（Perturb-seq）
- **化合物底座** — L1000 签名 + 药敏（GDSC / PRISM）
- **形态底座** — Cell Painting（JUMP / BBBC021）

| 细胞系 | 来源 / 适应症背景 | 扰动 | 化合物 | 形态 | 可支撑的产品线 |
|---|---|---|---|---|---|
| K562 | CML · BCR-ABL 阳性 | 全 | 部分 | 无 | CellTwin · PerturbSim · ToxTwin · ResistSim |
| RPE1 | 视网膜色素上皮 · 近二倍体非癌 | 全 | 无 | 无 | CellTwin（对照）· PerturbSim |
| MCF7 | 乳腺癌 ER+ | 无 | 全 | 部分 | CellTwin · PhenoScreen · ResistSim · CombiRank |
| A549 | 肺腺癌 · KRAS 突变 | 无 | 全 | 全 | CellTwin · PhenoScreen · CombiRank |
| U2OS | 骨肉瘤 · 形态筛主力 | 无 | 无 | 全 | CellTwin · PhenoScreen |
| HepG2 | 肝癌 · 肝毒性代理 | 部分 | 全 | 无 | CellTwin · ToxTwin |
| Jurkat | T 细胞白血病 · 免疫代理 | 部分 | 无 | 无 | PerturbSim |
| PC9 / HCC827 | 肺腺癌 · EGFR 敏感突变 | 无 | 部分 | 无 | ResistSim |
| 客户自有系 | 按项目 | 按项目 | 按项目 | 按项目 | 先做 CellTwin 可行性判定 |

> **反直觉的读法。** 模态最全的 MCF7 / A549 / HepG2 恰恰没有系内全基因组扰动数据；
> 有扰动数据的 K562 / RPE1 在化合物和形态侧几乎是空的。所以基因扰动线和化合物表型线
> 必须走不同细胞系，不要指望一条系包打全场。

## 3. 能力边界（合同级）

这是本家族与市面其他"虚拟细胞"产品的主要区别：**第三档写进合同附件作为排除条款**，
不藏在脚注里。三档划分依据见 [`VIRTUAL_CELL.md` §3](../VIRTUAL_CELL.md)。

### ✅ 直接替代
- 靶点在该系的表达、拷贝数、突变与融合状态（CCLE 直接查）
- 该靶点在该系是否为必需基因（DepMap CRISPR 直接查，比任何模型都准）
- 化合物结构警报：PAINS / Brenk / NIH 干扰子与类药性
- sgRNA 全基因组脱靶枚举与 CFD 特异性打分（穷举，不是预测）
- 细胞系身份与交叉污染核对（STR / SNP 指纹）

### 🟡 排序后测
- 化合物的转录响应方向与 MoA 归类（须先打赢 L1000 检索基线）
- 单基因敲低的下游通路 —— 仅限该系有扰动底座覆盖的靶点及邻域
- 化合物–靶点结合排序（`opt_score` ρ≈+0.6；`binding_confidence` ρ≈−0.2，选错等于反着排）
- n² 组合空间的优先级排序
- 启动子 / 剪接变异的顺式效应（须带 ±40bp 位置置换对照）
- 网络失稳早期预警：方差与 lag-1 自相关在分岔点附近上升

### ❌ 不承诺
- 外推到没有扰动底座的新细胞系 —— oracle 上下文特征比不给还差
- CRISPRa / 过表达 / 敲入后果 —— 敲低训练的模型迁过去 `r = 0.009`，等于掷骰子
- 绝对 IC50 与完整剂量–响应曲线，只排序不给数
- 时间动力学、代谢物浓度与滴度（FBA 的定义就给不了）
- 从细胞系外推到患者响应
- 监管级毒理放行结论

## 4. 结算口径

不报相关系数，报**富集倍数**和**每个真阳性的实验成本**。示意算例：

```
初筛库容量                     10,000
历史真实命中率                 0.5%   → 50 个真阳性
虚拟预筛取头部                 500    (5%)
头部命中率（8× 富集）          4%     → 20 个真阳性
──────────────────────────────────────────────
实验量 ↓ 20×   │   召回 40%（丢掉 30 个真阳性）
```

划不划算取决于**一个 hit 的边际价值对一个孔的边际成本**。靶点富集的小库不值得做预筛；
十万级表型库、或动物实验前的排序，杠杆才起来。每个项目的验收表填这四个数的真实值。

### 评价协议：不做这五件事，数字不可信

1. **基线阶梯必须齐** —— 训练集平均位移 / 最近邻检索 / 线性加性 / oracle 上界
2. **分层报告** —— 未见靶点、未见细胞系、未见组合是三种难度
3. **只在 DE 基因上评** —— 全转录组相关系数被未扰动基因主导，评方向和幅度
4. **报噪声天花板百分比** —— 裸分数无法解释
5. **全记分卡打分** —— 只优化一个通道容易在合计上净为负

## 5. 三阶段与停止条件

| 阶段 | 周期 / 算力 | 交付 | 停止条件 |
|---|---|---|---|
| **Phase 0** 盘点与地基 | 2–4 周，零 GPU | 状态卡、噪声天花板表、四层基线阶梯、污染审计判定、两条检索基线 | 噪声天花板低到基线已贴顶 → 这条系这个 readout 没有可建模余量，换 readout 或换系，不硬训 |
| **Phase 1** 两条主力模块 | 1–2 月，少量 GPU | 系内扰动模型、化合物表型检索、顺式可行性闸门、实验减量对账表 | 打不赢"训练集平均位移"或"结构指纹最近邻" → 改架构，不调参硬凑，不换指标重报 |
| **Phase 2** 整合与路由 | 2–3 月 | 顺式/反式并列输出、动力学预警引擎、四值判定路由器、形态生成层 | 路由器该说不知道时在硬答 → 这层不上线 |

推荐入口：任选一条细胞系的 **CellTwin-AI**。最低承诺、最快出结论，且结论无论正负都可复用
——有余量它就是后面所有产品线的地基，没余量则省下一整个建模项目的预算。
