## Q1 — IL‑14α → 干燥症机理链(✅ 小鼠模型因果证据强)

**分阶段因果通路:**
1. **IL‑14α↑(B 细胞生长因子)** → B 细胞高活化:高丙球血症、自身抗体、腮腺淋巴浸润、SLE/SS 样表型(Shen 2006 — 转基因过表达;患者外周血 IL‑14α 亦升高 Shen 2009)。
2. **边缘区 B 细胞 MZB = 不可约效应核心**:B 细胞特异敲 **RBP‑J** 除去 MZB → **全部 SS 表型消失**(唾液分泌正常、自身抗体阴性、腺体组织学正常);敲 **Btk** 除 B1 细胞**无效**(Shen 2016)。
3. **淋巴毒素 LTα = 腺体破坏效应器**:IL14αTG 唾液腺表达 LTα、唾液中分泌可溶 LTα;与 **LTα⁻/⁻** 杂交 → 唾液正常、**无腺体淋巴浸润、无淋巴瘤**(但自身抗体仍在、B 细胞发育正常)(Shen 2010)。→ LTα 驱动**腺体淋巴浸润 / 三级淋巴组织形成 + 成瘤**。
4. **型I IFN(IFN‑α)= 后期/系统放大**:IL14αTG.IFNR⁻/⁻ 仍有早期颌下腺+泪腺损伤,但**缺后期腮腺+肺损伤+淋巴瘤**;IgG2a 被抑(Shen 2013)。
5. **分期**(Shen 2009/2013):① 高丙球+自身抗体 → ② 唾液↓+颌下腺浸润 → ③ 泪腺/腮腺浸润+间质肺/肾 → ④ 大 B 细胞淋巴瘤。

**机理解读(诚实):** IL‑14α 是**上游点火者(B 细胞生长因子)**,**未被证明直接结合腺体上皮**;真正"弄干"腺体的是**下游 LTα(淋巴浸润/腺体破坏)+ 自身反应 B/浆细胞与自身抗体(抗 SSA/Ro、SSB/La)沉积**。MZB 为不可约核心,LTα/型I IFN 为可分离下游模块。

## Q2 — 结合/受体作用机制 + 身份确证判定

**配体(HMW‑BCGF)— 生化真实:** 60 kDa 分泌型 B 细胞生长因子,从 T 细胞/淋巴瘤上清纯化,积液中检出(Ambrus/Fauci;Ford 1995)。**PNAS 1993 cDNA**:推定**分泌型 53.1 kDa、成熟 483 aa、15 aa 信号肽、3 个 N‑糖位点**,与天然 HMW‑BCGF 肽段吻合。

**受体 — 被生化表征,但从未分子克隆:**
- **Ambrus 1988**:活化 B 细胞(非静息 B/非 T)有结合位点;¹²⁵I‑HMW‑BCGF 交联 → **150 kDa 复合物**(60 kDa 配体 + **≈90 kDa 受体**);单抗 **BA5** 识别该 90 kDa 受体相关蛋白、**阻断增殖**;Scatchard 高亲和。
- **Uckun/Fauci JCI / Uckun 1989**:CLL/白血病 B 细胞**组成型表达** 90 kDa 受体;仅需占据小部分即刺激。
- **信号(JBC)**:HMW‑BCGF → ↑cAMP(PGE 依赖)、↑胞内 Ca²⁺、↑DAG/肌醇;cAMP 调控受体表达,增殖信号走 Ca²⁺/DAG。

**❗诚信判定:**

| 命题 | 判定 | 依据 |
|---|---|---|
| IL‑14 **受体**分子鉴定? | **❌ 否(仅生化)** | 有 90 kDa 蛋白 + 150 kDa 交联 + BA5 阻断抗体 + Scatchard;**受体基因从未克隆/测序**,数据库无 IL‑14R,30+ 年未分子鉴定 |
| **配体 IL‑14α = α‑taxilin(P40222)**? | **⚠️ 内在矛盾、未确证** | 1993 分泌型 cDNA(53 kDa、信号肽、N‑糖、483 aa)**≠ α‑taxilin**(546 aa、~62 kDa、无信号肽、胞质);转基因"IL‑14α"(il14 plus 链 exons 3–10)被数据库等同 TXLNA,但与最初分泌型细胞因子生化不自洽 |
| **疾病遗传学**(转基因→SS) | **✅ 稳健** | Shen 系列可重复因果实验 |

> **疾病通路很硬,分子身份很软。** 你们的抗原(α‑taxilin 210–546 = 数据库版 TXLNA)是否等于真正致病的分泌型 IL‑14,**尚未证明**。

## Q3 — 中和抗体建议表位

**"中和"靶面本应是 IL‑14α ↔ 90 kDa 受体 结合面;但该受体未克隆、IL‑14α 受体结合表位从未定位** → 无法仅凭文献理性锁定。故:

**① 主推:功能优先、机制无关。** 用重组 IL‑14α 免疫,以**"中和 IL‑14α 驱动的 B 细胞/MZB 增殖"功能读出**筛选克隆,让中和表位经验性定义。❗**现有 ELISA 只测结合(slides: 人/猴/鼠结合筛选),必须补一条功能中和 assay。**

**② 结构引导优先区(在功能框架内):**

| 表位区 | P40222 | 建议 | 理由 |
|---|---|---|---|
| ✅ 折叠 coiled‑coil 核心 | 210–484 | **优先** | 结构化、免疫原性好、跨物种高保守(利于小鼠 PoC);de‑novo Axis‑1(275–294)/Axis‑2(324–350)在此 |
| ⚠️ syntaxin 界面 | 355–443 | 谨慎 | "运输轴"界面,阻断未必中和"细胞因子轴" |
| ❌ C 端富脯氨酸无序尾 | ~485–546 | **避开** | 无序、非中和表位;**先前技术**:Peng2009 抗 IL‑14α‑C 免疫肽 `Ac‑ERRPEGPGAQAPSSPRVTEAPC` = **P40222 ~503–523**,且仅为**检测抗体、未证明中和** |

**③ 并行高价值轴:抗受体路线。** 1988 已生化证明 90 kDa 受体 + 阻断性抗受体单抗 BA5 → 克隆/鉴定该受体 + 抗受体阻断抗体可能更直接中和,但需先分子鉴定受体(大工程)。

**❗贯穿告诫:** 因身份矛盾,**抗 taxilin 抗体未必中和真正致病的分泌型 IL‑14** → **功能中和 + 转基因鼠体内 PoC 是不可省的验证闸门**,binding 阳性远不够。

## 诚信小结
- ✅ **疾病因果通路**(IL‑14α→MZB→LTα/IFN→腺体损伤+淋巴瘤)在转基因鼠中证据强、可分阶段拆解。
- ❌ **IL‑14 受体**从未分子鉴定(仅 90 kDa 生化表征 + BA5)。
- ⚠️ **IL‑14α=taxilin** 与最初分泌型 53 kDa cDNA 矛盾,未确证。
- 抗体策略据此应**功能优先**、避开 C 端无序尾/先前技术、优先保守 coiled‑coil 核心表位,并以**功能中和+体内 PoC** 为验证闸门。
