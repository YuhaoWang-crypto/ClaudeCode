增补与修订 — 结合第三份独立报告(报告C,更审慎口径)

三份独立报告在靶点身份、专利过期/FTO、C245/C373 共价锚点、siRNA 首选位点上收敛;但报告C 引入若干反向证据与一个独立阴性结果,应修订而非仅叠加。

  1. ❗胞外池证据存在冲突(最关键): HPA 显示 TXLNA 血浆未检出(免疫法+质谱均阴)、secretome=null、"predicted intracellular protein";而报告B(Sarkar 2020 RA 血浆 ELISA,AUC 0.97)与本报告(Liang 2021 pSS 血清 WB)为阳。→ "胞外可中和池"由待验证假说降级为有争议命题;Gate-1 必须用旁系特异抗体 + 质谱(而非可能交叉反应的 ELISA/WB)判定,并查外泌体组分。
  2. ❗抗体:独立 RF2 流程得阴性 → 需下调本报告乐观度。 报告C 用 RFdiffusion→ProteinMPNN→RF2 对 Axis-2 打分,17/160 中 0 个通过 interaction_pae<10(最佳 21.6)。本报告 Boltz iPTM 0.77–0.85 属不同模型/指标(Boltz iPTM ≠ RF2 i_pae,前者对 de-novo 常偏乐观)。诚实结论:抗体结合未获跨工具一致确认,延展 coiled-coil 是困难靶面,应视为高于原判的风险;需正交复评(用 RF2/AF3 复评本报告设计,用 Boltz 复评报告C 设计)。
  3. 疾病证据再加权: RA 有直接 TXLNA 蛋白证据(RA 滑液/血浆 ELISA 升高,n=106,PMID 39634288;FLS 糖酵解酶互作 PMID 32377534);pSS 关联为间接(依赖有争议的 IL-14α=taxilin 身份 + 转基因鼠)。→ 建议将 RA 列为证据更强的并行适应症,并如实标注 pSS 机制链的不确定性。
  4. 非经典分泌假说: PPI 邻居 TSG101(ESCRT) 提示——若存在胞外 TXLNA,可能经外泌体/非经典途径分泌(与无信号肽自洽)。为 Gate-1 提供可检验机制。
  5. siRNA:Evo2 已被报告C 实跑(A100),确认首选位点 = 本报告 si_1(CDS≈956/957,guide UUUGUCGAUAUGCUCCUCG,Evo2 −0.49)——三方独立收敛同一位点;可增补其 #2 位点(CDS+512,guide UGCAUCAGCAACGUGAUCU,Evo2 −0.84)。本报告"Evo2 待接入"项由此闭合(经报告C 交叉验证)。
  6. PROTAC 补充与告诫: 增加 vinylsulfonamide 弹头选项(共 3 弹头×2 E3);诚实告诫——TXLNA 无深口袋(硫醇表面暴露),C245/C373 相距 ~128 残基为两个独立锚点非共享口袋;真实连接子会把 MW 推至 700–1000 Da、降低膜渗透。
  7. 本报告反向补充报告C: 报告C 记"无 target–syntaxin 复合物结构";而本报告已用 Boltz 预测该复合物(iPTM 0.63,界面 355–443,图 B)——三方合并后,复合物界面 + 抗体对接 + PROTAC 口袋残基均已具备。

修订后共识优先级:siRNA(P1,三方收敛+Evo2 验证,最稳) ≫ 抗体(P2,跨工具未确认,风险上调,待关口实验)≈ 共价 PROTAC(P3,概念);适应症 RA(证据更强)+ pSS(机制间接) 并行。唯一 go/no-go = 胞外池 ELISA(需旁系特异+MS)。

1靶点生物学与机制

1.1 身份与结构

TXLNA(α-taxilin,UniProt P40222,546 aa) 是胞质 coiled-coil 蛋白,经 C 端卷曲螺旋结合游离 syntaxin-1A/3/4,调控 SNARE 介导的胞吐/囊泡运输。其"第二身份"为 IL-14α / 高分子量 B 细胞生长因子(HMW-BCGF)。甲方所给抗原(1014 nt)翻译为 337 aa,BLAST 100% 命中 P40222 第 210–546 位(C 端 coiled-coil + 富脯氨酸尾)。结构预测(Boltz-2.1)证实:coiled-coil 核心(210–484)pLDDT 84.9 = 置信折叠的螺旋杆;PRD 尾(485–546)pLDDT 48 = 无序;全局无深口袋(小分子难成药)。

1.2 IL-14α 与干燥综合征机制(不可约核心)

IL-14α 转基因鼠完整复现 pSS(含泪腺浸润、晚期 B 淋巴瘤);敲除边缘区 B 细胞(MZB)则表型全消——双向敲除证据将 IL-14α→MZB 定为不可约驱动边。患者血清 IL-14α(WB)升高并与抗 SSA/SSB 相关;RA 血浆 α-taxilin ELISA 升高(AUC 0.97,甲方报告 Sarkar 2020)。

9共同关键未决项与下一步

唯一的共同 make-or-break:胞外 α-taxilin 池是否足量可及。两份报告都指向同一决定性实验:

  1. Gate-1:pSS 血清 α-taxilin ELISA(n≥30 患者 vs 对照)+ IP-质谱定性分子种类 → 决定 LYTAC/抗体(需胞外池)vs siRNA/PROTAC(不需)分流。甲方 scRNA 提示应查血清+腺体基质而非免疫细胞。
  2. 湿验证 top-3 siRNA / top-3 ASO(80% 敲低,剂量依赖);建立 B 细胞/MZB 中和 assay。
  3. Axis-2 抗体 CDR 移植入人源 IgG1(效应减弱 Fc)+ Boltz 复算 + SPR 亲和 + syntaxin 竞争。
  4. C373 共价片段筛选(LC-MS 加合)→ 共价 PROTAC。
  5. 接入 Evo2(全基因组脱靶)+ AlphaGenome(剪接选择性 ASO,保留看家 taxilin 功能);跟进 TBK1/TNIP1 机制。
