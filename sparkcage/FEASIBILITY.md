# SparkCage 生物传感器项目：技术可行性分析

本文分析报价单中 Phase I（Design & Modeling）的全部条目，逐项判断能否做、缺什么软件、
用什么开源方案替代，并给出一个**已经跑通的 demo**（代码在本目录，`python3 run_demo.py`
可复现，`python3 validate.py` 有 16 项对照文献数值或解析极限的验证，全部通过）。

结论先行：**Phase I 的计算部分全部可做，没有任何一项被商业软件卡死**。COMSOL 那一项
不但可替代，而且直接求解比 COMSOL 更准（原因见第 3 节）。真正的风险不在软件，在三个
物理/生物问题上，见第 5 节。

---

## 1. 这个项目到底在做什么

报价单里的名词拆开来是这样一条链：

**SparkCage = 一个单组分、电化学读出的从头设计蛋白开关传感器。**

- **Cage（笼）+ Latch（闩）**：来自 Baker 实验室的 LOCKR / LucCage 架构。一个长螺旋束
  （cage）把一根螺旋（latch）关在自己的凹槽里。latch 上携带识别元件。分析物结合把 latch
  从笼里拽出来 —— 这就是"开关"。
- **报价单给了两个骨架选项**：
  - `7CBC` = LucCage/LOCKR 路线。经查证，它的正式身份是 **sCageHA_267–1S**，一个为结晶
    做的**缩短版**构建体（319 aa），不是完整 lucCage（359 aa）。
  - `1omp / 1anf` = 麦芽糖结合蛋白（MBP）的 apo / holo 结构，即经典的 **Type I 周质结合
    蛋白"蛤壳"折叠**，靠铰链开合产生构象变化。
- **Methylene blue（亚甲基蓝，MB）**：氧化还原报告基团，共价挂在 latch 上。它离电极的
  距离决定电子隧穿速率 `k0`。latch 被拽走 → MB 远离电极 → `k0` 暴跌 → 方波伏安（SWV）
  峰电流变化。这是 Plaxco 组 E-AB / E-DNA 传感器的机制，只是把核酸换成了蛋白。
- **Carbon electrode（碳电极）**：latch 需要在碳表面有可控的吸附取向，所以报价单里才有
  "MD 分析 latch 与碳电极的结合位点"这一条。
- **COMSOL 那一步**：模拟器件级响应 —— 分析物扩散到电极、表面反应、电流输出。

**报价单里一个术语是错的，值得先指出。** 第 1.3 条写"three thermodynamic states,
ΔGopen, ΔGLT, ΔGswitch"。查原始文献（Quijano-Rubio 2021 *Nature*；Langan 2019
*Nature*，含全部补充材料和作者公开的 `model_simulation.py` 源码）：**"ΔG_switch" 这个
术语在两篇文章里都不存在**。真实模型有**四个**自由能项：

| 项 | 含义 | 在 SparkCage 里 |
|---|---|---|
| ΔG_open | cage → latch 打开 | **保留** |
| ΔG_LT | latch/binder → 分析物结合 | **保留** |
| ΔG_CK | 打开的 cage → key 结合 | **消失**（无 key） |
| ΔG_R | SmBiT ↔ LgBiT 荧光素酶重组 | **消失**（无荧光素酶） |

这不是文字游戏。第 4.2 节会看到，丢掉 ΔG_CK 是有代价的，而且这个代价决定了 SparkCage
该怎么设计。

## 2. 逐条可行性与软件替代

报价单没有点名 Rosetta，但 LucCage 的原始设计全套是 Rosetta 做的（GraftSwitchMover、
Remodel、MergePDBMover、HBNet、BundleGridSampler）。Rosetta 学术免费、商业收费。

| 报价单条目 | 需要的能力 | 商业方案 | 开源替代 | 判断 |
|---|---|---|---|---|
| 1.1 Cage 设计（7CBC 或蛤壳） | 骨架生成、序列设计 | Rosetta | **ProteinMPNN + RFdiffusion + ESMFold/Boltz-2**；若只做移植改造，直接用现成 PDB + 定点突变 | ✅ 可做，且比 Rosetta 更强 |
| 1.2a MB 在 latch 上的结合位点（MD） | 小分子参数化 + MD + 结合自由能 | Amber / CHARMM / Schrödinger | **OpenMM + OpenFF/GAFF2 + AM1-BCC**（`openff-toolkit`, `acpype`）；对接用 **smina/GNINA**；自由能用 **openmmtools** 的 alchemical FEP 或伞形采样 | ✅ 可做，需 GPU |
| 1.2b latch 在碳电极上的结合位点（MD） | 蛋白–石墨烯界面 MD | 同上 | **GROMACS/OpenMM + 已发表的石墨烯 LJ 参数**；吸附自由能用 metadynamics / umbrella sampling | ⚠️ 可做但力场不确定性大，见 5.3 |
| 1.3 三态自由能 ΔG_open / ΔG_LT / ΔG_switch | 耦合平衡建模 + ΔΔG 计算 | Rosetta ddG / Schrödinger FEP+ | **本目录已实现**（`thermo/`）；ΔΔG 用 OpenMM alchemical FEP 或 **FoldX / ThermoMPNN** | ✅ 已跑通，见 4.1 |
| 2. 器件 FEA 仿真 | 表面限域氧化还原 + 传质 | **COMSOL 5.6** | **本目录已实现**（`echem/`）；交叉验证可用 **RedoxPySolid**（MIT）、**ElectroKitty**（BSD-3）、**MECSim**（免费二进制）；真需要 2D/3D 时用 **FEniCSx** 或 **scikit-fem** | ✅ 已跑通，见 3 |

**明确不推荐的替代品**（调研时排除的弯路）：

- **MOOSE**：官方模块列表里**没有电化学模块**，也没有 Butler–Volmer 内核。名字相近的
  Zapdos 是**低温等离子体**物理，不是电化学，是个假线索。
- **Elmer**：有 Nernst–Planck 对流扩散和 Poisson–Boltzmann，但**没找到 Butler–Volmer
  电极动力学边界条件**，未经证实。
- **OpenFOAM / PyBaMM**：领域不对。PyBaMM 唯一值得挖的是它的 Marcus–Hush–Chidsey 动力学
  实现，可以当公式参考，不要当求解器。
- **Soft Potato / pyecsim / Polarographica**：都**不支持表面吸附物种**，而 MB 恰恰是
  表面吸附的。直接出局。

## 3. 为什么 COMSOL 在这个问题上是"错的工具"，不只是"可替代"

这是本次分析最硬的一个结论。

**MB 是表面限域物种，它的伏安学没有空间维度。** 覆盖度 ODE 是：

```
dθ/dt = k_c (1−θ) − k_a θ ,   k_c = k0 exp(−α F η /RT),  k_a = k0 exp((1−α) F η /RT)
```

方波伏安每个半周期内电位恒定，所以 `k_c`、`k_a` 是常数，这个 ODE **有闭式解**：

```
θ(t) = θ_ss + (θ_0 − θ_ss) exp(−(k_c+k_a) t)
```

逐半周期精确推进即可，**零离散化误差，无需网格**。

而本项目真正要复现的那篇文章 —— Dauphin-Ducharme, Arroyo-Currás, Kurnik, Ortega, Li,
Plaxco, *Langmuir* **2017**, 33, 4407（doi:10.1021/acs.langmuir.7b00359）—— 用的是
**COMSOL 5.2 的一维模型**，而且因为 COMSOL 无法直接表示表面限域物种，他们**用一个
150 µm 的薄层池去"凑"单分子层的物理**，靠"扩散层永远到不了远壁"这个条件来近似。

也就是说：**这里的闭式解不是对 COMSOL 模型的近似，它就是 COMSOL 模型在近似的那个精确解。**
方波波形在 COMSOL 里还得用 `flsmsign` 平滑 Heaviside 加 `mod` 阶梯拼出来，在 Python 里
就是一行数组。

**2D/3D FEA 什么时候才真正必要**（这时才该考虑 FEniCSx）：
微盘/超微电极（r₀ ≲ 扩散层厚度）、凹陷电极、间距小于 2 倍扩散层的电极阵列、
带流动的微流控腔、叉指电极。**平板宏电极 + 过量支持电解质 + 静止溶液，一维足够。**

## 4. Demo：已经跑出来的东西

代码全部在本目录，纯 NumPy/SciPy/Matplotlib，4 核 CPU 无 GPU，全程不到一分钟。

### 4.1 骨架解剖（对应报价单 1.1）

直接解析 PDB，只用 numpy：

**7CBC 拓扑**（螺旋间 Cα 接触计数，< 10 Å）证实了架构：H1+H2 与 H3+H4 是被 TDP/YDP
螺旋帽劈开的螺旋发夹，用 GSGSGS 连接；加上 H5 构成五螺旋 **cage**；H6（244–269，同样
TDP 起头）是躺在凹槽里的 **latch**，只接触 H5（67 对）和 H1（45 对）；b1–b3 是移植上去的
三螺旋 HA mini-binder，它与 cage 的接触（b1–H5 = 25，b2–H1 = 26 对）就是"caging"的
结构证据 —— 与原文"除 F273 外所有 HA 结合界面残基都接触 cage"一致。

**MBP 蛤壳铰链运动**（1OMP → 1ANF，Kabsch 分域叠合）：

| 量 | 数值 |
|---|---|
| 整体 RMSD | 3.77 Å |
| N 域内部 RMSD | 0.72 Å |
| C 域内部 RMSD | 0.68 Å |
| **铰链闭合角** | **36.2°** |
| C 域平均位移 | 11.4 Å |
| C 域最大位移 | 21.3 Å |

两个瓣内部是刚性的（< 0.8 Å），确实是纯刚体铰链弯曲 —— 这是蛤壳能当变构输入的前提。
这一条**证实了报价单选 1omp/1anf 作为备选骨架是合理的**。

### 4.2 三态热力学（对应报价单 1.3）

两个模型都实现了：

1. `thermo/luccage_reference.py` —— **完整复现已发表的 LucCage 十方程耦合平衡模型**
   （9 个物种，按作者源码逐条实现，log 空间求解）。复现了 ED Fig. 1a 的 K_open 扫描：

   | K_open | 无分析物背景 | 动态范围 |
   |---|---|---|
   | 1e−7 | 0.0005% | 934933% |
   | 1e−5 | 0.0526% | 133957% |
   | 1e−3 | 4.92% | **1575%** |
   | 1e−1 | 70.5% | 17% |

   基线值 1575% 落在文章实测的 50%–1700% 区间内。文献里唯一一个 kcal/mol 数值
   （ΔG_open = 4 kcal/mol，来自 Nat Biotechnol 2022）换算得 K_open = 1.17e−3，与
   基线 1e−3 吻合到 1.17 倍。

2. `thermo/switch_model.py` —— SparkCage 用的**无 key 简化模型**，有闭式解：

   ```
   EC50 ≈ Kd_binder × exp(ΔG_open/RT)
   动态范围 ≈ exp(ΔG_open/RT)
   ```

   **每增加 1 kcal/mol 笼稳定性，动态范围乘约 5 倍，检出限也恶化同样的 5 倍。**
   这个权衡就是报价单为 1.3 单列 3–4 周的原因。

**关键发现：丢掉 key 的代价。** 把两个模型在同一 ΔG_open = 4 kcal/mol、Kd = 1 nM 下对比：

- 有 key（LucCage）：EC50 = **20.3 nM**
- 无 key（SparkCage）：EC50 = **856 nM**
- **灵敏度损失 42 倍**

注意一个容易犯的错：这个代价**不是** `exp(−ΔG_CK/RT) = 1e8`。ΔG_CK 是 1 M 标准态自由能，
而 key 实际浓度是 100 nM，真正可用的质量作用补偿只有 `1 + [key]/K_CK ≈ 11` 倍。
端到端实测 42 倍。（`validate.py` 里专门有一项检验这个区别。）

**设计含义**：SparkCage 必须自己找一个补偿相互作用来代替 key。报价单其实已经隐含了答案 ——
第 1.2 条的"latch 与碳电极的结合位点"，**那个吸附自由能就是 ΔG_CK 的结构类比物，应该
作为显式的第四个状态来建模，而不是留在模型外面。**

### 4.3 电化学读出（对应报价单 Step 2，即 COMSOL 那一项）

参数校准到真实 E-AB 器件量级（0.03 cm² 电活性面积，Γ = 2e−12 mol/cm²，α = 0.37 —— 
后者是 MB 的实测值，不是教科书的 0.5）：

- k0（贴靠，6 Å）= 110 /s，k0（释放，14 Å）= 0.037 /s
- **准可逆极大值定位在 k0/f = 1.26**（文献 Lovrić & Komorsky-Lovrić 1988 给出接近 1 ——
  这是模型的验证，不是拟合结果）
- 由此定出询问频率 **87 Hz**，落在实验常用的 20–300 Hz 带内
- 峰电流 217 nA（0% 开关）→ 6.6 nA（100% 开关）

**这里有个坑，值得单独说。** 表面限域物种的 SWV 峰电流**对 k0 不是单调的** —— 它在
k0/f ≈ 1 处取极大，两侧都下降。如果把询问频率选在贴靠态处于可逆一侧（k0/f ≫ 1），
报告基团**移远反而会让信号变大**，同一个传感器会因为频率不同表现成 signal-on 或
signal-off。这是设计不可解释传感器的最快途径。正确做法是让**贴靠态坐在极大值上**，
这样任何位移都单调降低峰值。

**最有价值的一个数字：把实测信号变化反演成位移。**

真实蛋白 E-AB 传感器（Kang, Sun, Kurnik, Morales, Dahlquist, Plaxco, *JACS* **2017**,
139, 12113）实测信号变化只有 **4%–30%**。用本模型（含 2.5 Å 宽的构象系综平均）反演：

| 信号变化 | 对应的报告基团位移 |
|---|---|
| 4% | **1.4 Å** |
| 30% | **2.6 Å** |

**而蛋白结构域本身的运动是 11–21 Å（见 4.1）。绝大部分构象变化被浪费掉了。**

所以：**MB 挂在哪里，比蛋白动多大更重要。** 这恰好就是报价单第 1.2 条要花 6–8 周做
分子动力学去决定的事 —— 这一项的预算是合理的，甚至可能是整个 Phase I 里最该投入的一项。

### 4.4 传质与边界条件（对应报价单 Step 2 的另一半）

一维扩散 + Langmuir 表面捕获，隐式方法线求解：

Damköhler 数（**与浓度无关**，是传感器和腔体的属性）：静止腔（500 µm）**250**，
搅拌腔（30 µm）**15**。**两种情况都远大于 1，即这个传感器是扩散限制的，不是反应限制的。**

| 分析物 | 平衡占据率 | t90（有储库） | t90（搅拌） | t90（半无限静止） |
|---|---|---|---|---|
| 0.01 nM | 0.15% | 593 min | 464 min | 5938 min |
| 0.1 nM | 1.50% | 593 min | 440 min | 5928 min |
| 1 nM | 14.8% | 592 min | 219 min | 5822 min |
| 10 nM | 90.9% | 387 min | 26.8 min | 2188 min |
| 100 nM | 99.0% | 25.3 min | 2.9 min | 26.0 min |

三个结论：

1. **响应时间由传质决定，搅拌或流动能买到一个数量级，改善 binder 的 k_on 买不到任何东西。**
2. 最后两列**给出了答案的上下界**：500 µm 外有均匀储库 vs 真正静止的样品，差约 10 倍。
   真实器件属于哪一种是**流体力学问题，不是化学问题**，再多蛋白设计也解决不了。
3. 半无限扩散送达时间按 **1/c²** 标度：分析物浓度降 10 倍，时间涨 100 倍。
   **限制实际检出限的是这个，不是电化学。**

**这是整个项目里 2D/3D FEA 唯一真正值当的地方** —— 真实腔体几何和流场。

## 5. 风险：真正的问题不在软件

### 5.1 无 key 架构的灵敏度损失（已量化：42 倍）

见 4.2。**必须**用 latch–电极吸附能或其他相互作用补上，否则 SparkCage 在同样 binder 下
比 LucCage 差一个半数量级。建议把它建成显式的四态模型。

### 5.2 构象变化利用率极低（已量化：11–21 Å 只用出 1–3 Å）

见 4.3。这是**最高杠杆的设计决策**，MB 挂载位点的 MD 筛选值得加码。

### 5.2b 换报告基团是可行的，但 MB 很难被取代

Kang, Ricci, White, Plaxco, *Anal. Chem.* **2016**, 88, 10452 系统测了 13 种报告基团
（全部经羧酸做酰胺偶联）。关键结论是**区分度在稳定性，不在增益**：

| 报告基团 | 缓冲液 100 次扫描 | 20% 血清 4 次循环 |
|---|---|---|
| **亚甲基蓝** | **损失 2%** | **衰减 11%** |
| 蒽醌 | ~50% | ~50% |
| 尼罗蓝 | ~50% | 20% |
| 5′-二茂铁 | ~50% | ~50% |
| 3′-二茂铁、五甲基二茂铁 | 仅 50 次扫描就 ~50% | — |
| 硫堇 | 窗口内出双峰 | 不可用 |
| Dabcyl、ROX | 无清晰氧化还原峰 | 失败 |
| 靛酚 | 偶联过程中分解 | 失败 |
| 中性红 | 衍生化后电位移到 −0.7 V，与硫醇还原重叠 | 失败 |

在 20% 血清里，MB、二茂铁、蒽醌、尼罗蓝的**信号增益基本不可区分**。

MB 之所以主流有两个经核实的原因：一是它的电位落在硫醇-金 SAM 稳定的约 1 V 窗口中段，
避开氧还原和金氧化；二是 MB/无色亚甲基蓝电对本身电化学可逆且耐复杂基质。

**值得考虑的两个替代**（都比 MB 更耐用于某些场景）：

- **Fc1a-X 二茂铁**（Kim, Park, Lee, Joo, Yang, *ACS Sensors* **2024**, 9, 6450）：
  E°′ = 0.14 V，**pH 不敏感**，血清中 12 小时表现优于 MB，有 NHS 酯形式。
- **Os(II/III) 配合物**（Aller Pellitero, Kundu, Sczepanski, Arroyo-Currás,
  *Analyst* **2023**, 148, 806）：pH 不敏感，操作稳定性比 MB 好 35%。

还有一个工程技巧值得抄：**比率法**（Zhu et al., *ACS Appl. Bio Mater.* **2023**,
6, 1586）—— MB 挂在识别元件上，二茂铁挂在 SAM 上作内参，在血清和全血里实现免标定。
如果 5.2 的漂移问题严重，这是直接的解法。

**一个修正**：我此前引用的 MB 形式电位 −0.27 V vs Ag/AgCl 这个具体数值**未能核实**。
已核实的是 DNA 修饰电极上 MB 的 E°′ = −0.25 V vs SCE（约 −0.29 V vs Ag/AgCl）。
按 −0.25 至 −0.30 V 这个区间用，引用时要找自己读过的原始文献。

### 5.3 碳电极：不是空白，而且这个选择有充分理由

我之前把碳电极当作纯粹的风险，这个判断需要修正。**选碳是有正当理由的。**

金电极的主要失效模式不是报告基团，而是**硫醇 SAM 本身会脱附**，导致传感器在数小时内
显著失信号；而且裸金暴露后电容电流升高、溶解氧还原被打开，恰好污染 MB 依赖的那个电位窗。

Aller Pellitero & Arroyo-Currás, *Anal. Bioanal. Chem.* **2022**, 414, 5627 在玻碳上
比较了三种接枝策略：阳极氧化生成羧基、重氮盐电接枝、**脂肪族伯胺电接枝**。
结论是**只有伯胺电接枝达到了可与金上烷基硫醇相比的单层有序度和堆积密度**，
并且在生物流体中连续伏安询问下**稳定性优于硫醇-金**。碳给的是共价 C–N 键而不是 Au–S 键。

而且有一个几乎正对本项目的先例：**Zeynaloo et al., *Biosens. Bioelectron.* 2022, 200,
113861** —— 葡萄糖/半乳糖结合蛋白（GGBP）通过基因编码引入非天然氨基酸 L-DOPA 作为
氧化还原标记，固定在**丝网印刷碳电极**上，结合葡萄糖引起铰链闭合，阳极峰电流下降，
LOD 0.67 µM。这是"周质结合蛋白 + 铰链运动 + 共价氧化还原标记 + 碳电极"的完整实证。
不是 MB，但架构一致，值得精读。

碳的代价（部分为推断）：

- **没有任何 MB 挂在蛋白上、在碳电极上的实测 k0**。这仍是本项目一个真实的开放参数。
- 失去 Kang 2017 用的 Ni/Cu-NTA-烷基硫醇 His-tag 锚定，固定化学要在碳上重建。
- 碳背景电容更大、表面化学重现性更差；重氮盐倾向于长成多层而非单层。
- 蛋白–石墨烯界面力场不确定性大，MD 给出的吸附自由能应当只作排序用，不作绝对值用。
- 碳表面异质性更强，建议用 RedoxPySolid 那类带 k0/E0 分布的模型，而不是单一 k0。

### 5.4 Frumkin / 双电层修正

MB 距电极 1–5 nm，**处于扩散层内部**，它感受到的局部电位不等于施加电位。这是 E-AB
非理想性的已知来源。**注意：COMSOL 也解决不了这个** —— 表面物种与扩散层的耦合在任何
软件里都不是内置接口。所以这条不能用来论证需要 COMSOL 授权。

### 5.5 设计成功率（文献实测）

LucCage 每个靶点筛 **5–13 个设计**，一轮成功，无定向进化：HA 5 个中 2 个可用；
BoNT/B 9 个；Fc 6 个；Her2 7 个；肌钙蛋白 I 11 个；HBV 8 个；RBD 13 个。
LOCKR 正交开关 5 个中 2 个可用。**按 20%–40% 成功率做实验预算是合理的。**

另外：**LucCage 的设计筛选并没有用 Rosetta ddG 或界面能过滤器**，只用了 FastRelax 后的
Rosetta 总分加人眼在 PyMOL 里看。不要在方案里声称原文用了 ddG。

### 5.6 Binder 来自 Monod Bio

报价单写明 "biomarker-binder is provided by Monod Bio"。这意味着：

- **Kd 是外生的、不可调的**。设计地图（`figures/01_...png`）显示无约束最优解总是撞在
  "亲和力越紧越好"的网格边界上 —— 亲和力不是我们的自由变量。**我们能调的只有
  ΔG_open。** 在给定 Kd 下的最优 ΔG_open：Kd = 1 nM → 1.45 kcal/mol；
  10 nM → 0.74；100 nM → 0.21。
- LucCage 与 LOCKR 有专利覆盖（WO2021242780A2、US 12,304,927）。若要商业化，
  **建议做 FTO 检索**。

### 5.7 一个诚实的空白

**没有任何已发表模型把"分析物扩散 → 结合 → 构象开关 → k_et 改变 → SWV 电流"这条完整
链路耦合起来。** Plaxco 2017 只做固定 k_et 的 SWV；传质文章只做传质。
本 demo 的 `run_demo.py` 把四段接上了 —— 这既是机会（可发表），也是风险（无先例可对照）。

同样地，**截至目前没有任何从头设计蛋白开关的电化学读出被发表**。最接近的是：
LucCage 的光电化学 + 数字微流控平台（*Biosens. Bioelectron.* 313:119156, 2026）、
Plaxco 的天然蛋白 E-AB 架构（*JACS* 2017）、以及把 LOCKR 输出换成 BRET / 分裂 β-内酰胺酶
的工作（*ACS Sensors* 2026，明确不含电化学）。**这个生态位是空的。**

## 5b. 关于 MB 怎么接、以及两条骨架路线怎么选

### MB 是共价挂上去的，不是设计口袋去"结合"的

这一点决定了难度量级。在全部 E-AB / E-DNA 传感器里，以及唯一的蛋白先例
（Kang, Sun, Kurnik, Morales, Dahlquist, Plaxco, *JACS* 2017, 139, 12113）中，
亚甲基蓝都是**共价偶联**到工程化半胱氨酸上的（马来酰亚胺化学）。

所以设计问题不是"什么序列能结合 MB"，而是"半胱氨酸点在哪个残基"。后者小得多。

报价单第 1.2 条 "identification of the binding site of MB on the Latch via molecular
dynamics" 的合理读法是：**共价拴住之后，MB 静息时贴在 latch 的哪个面、什么取向** ——
这确实需要 MD，也确实值得花 6–8 周（原因见 4.3）。如果字面理解成"设计一个非共价 MB
结合口袋"，那是个更差的设计：MB 会解离、化学计量不可控、会渗漏导致基线漂移，而且要和
样品基质竞争。**建议在方案里把这一条写清楚。**

### 已知的 MB–蛋白结构：可以参考，不能直接用

PDB 里 MB 的配体编号是 `MBT`，共 6 个条目：

| PDB | 分辨率 | 口袋残基 | 芳香族 | 酸性 | 是什么 |
|---|---|---|---|---|---|
| 2YVE | 1.40 Å | 12 | 3 | 4 | 多药结合转录调控因子 |
| 3ZYX | 2.20 Å | 14 | 4 | 0 | 人单胺氧化酶 B |
| 4XYP | 2.10 Å | — | — | — | 鱼类病毒融合蛋白 |
| 5ACM | 1.05 Å | 10 | 8 | 2 | Mcg 免疫球蛋白可变域 |
| 5DLP | 2.70 Å | 8 | 7 | 1 | 乙酰胆碱酯酶 |
| 5E4T | 2.43 Å | — | — | — | 乙酰胆碱酯酶（含 PEG） |

**没有一个是为结合 MB 而生的**：一个是本职就要结合多种配体的多药调控因子，一个是被 MB
抑制的酶，一个是出了名什么都装的抗体腔，还有结晶添加剂。亲和力最好也就微摩尔级。

但它们一致给出了识别模式：MB 是**平面芳香阳离子**，靠**芳香堆叠 + 酸性反离子**识别。
这正是识别大多数扁平药物阳离子的同一套基序 —— 也就是为什么这张表里每个蛋白都是
promiscuous 的。**想设计一个"特异"的 MB 口袋就是在跟这件事对着干，而且相对共价键没有
任何好处。** 这些结构真正的用处是两个：验证 MB 的力场参数，以及知道 MB 喜欢贴着什么。

### 两条骨架路线是互斥的，不是可以拼装的部件

报价单写的是 "Engineered Type I Clamshell **Or** LucCage (LOCKR) architecture"。

- **LOCKR 路线**：latch 是一根 26–59 aa 的**螺旋**。cage 把它关住，分析物把它拽出。
- **蛤壳路线**：MBP 是 370 残基的**双瓣**结构，它根本没有 latch。架构完全不同 ——
  把一个瓣固定在电极上，MB 挂在另一个瓣上随铰链开合改变距离。没有 cage，没有 latch。

把 1OMP/1ANF"设计成 latch"是个范畴错误。它们是两个候选架构，选一个。

### 蛤壳路线有一个决定性障碍：MBP 结合的是麦芽糖，不是生物标志物

要用蛤壳检测标志物只有三条路，前两条都有问题：

1. **重新设计 MBP 口袋的特异性。** 这就是 Hellinga 组 2003 年 *Nature* 那套计算重设计
   （把周质结合蛋白改造成结合 TNT、乳酸、血清素）。**这条路不可靠。**
   该文**未被撤稿**，但已在实践中被大幅否定：Schreier, Stumpp, Wiesner, Höcker,
   *PNAS* **2009**, 106, 18491，标题直白叫 *"Computational design of ligand binding is
   not a solved problem"* —— 他们发现多数设计蛋白不稳定、聚集，无法做结构表征；
   唯一解出的一个（阿拉伯糖结合蛋白改造成结合血清素，2.2 Å，**在过量血清素中结晶**）
   呈**开放构象且没有结合血清素**。合作者复测发现三个 TNT 设计里有两个始终不工作。

   需要区分清楚：Hellinga 组确实有**两篇撤稿**（*Science* 2004 的 NovoTIM 和
   *J. Mol. Biol.* 2007），但**都是关于设计酶，不是受体**。而且注意 JMB 那篇的撤稿
   **在 PubMed / Europe PMC 上没有标记**，文献管理软件不会警告你。
   被指控的研究者 Mary Dwyer 后来被 Duke 调查**并已澄清**。

   **关键**：铰链运动转导那部分工作（Benson 2001、Marvin 1997/2001、de Lorimier 2002）
   **完全不受牵连，依然可靠**。不可靠的只有"计算重设计配体特异性"。

2. **换一个天然就结合该分析物的周质结合蛋白。** 只对小代谢物可行（葡萄糖、磷酸、
   氨基酸），对蛋白标志物没有对应的 PBP。
3. **把 Monod Bio 的 binder 嫁接到蛤壳上**，让结合驱动铰链闭合。很难，binder 要跨接
   两个瓣才能产生构象耦合。

而 LOCKR 天生是模块化的：binder 直接放在 latch 上，原文对 11 个不同靶点都做成了。

**所以取舍取决于分析物**：蛋白标志物 → LOCKR 基本是必选；小代谢物 → 蛤壳更好起步。

### 三个可验证的差异，在小分子分析物的前提下指向蛤壳

1. **构象态数据**：MBP 有 apo（1OMP）和 holo（1ANF）两个晶体结构，所以报告基团位移**今天
   就能严格算**（见下）。LOCKR 家族全文检索只找到关闭态（7CBC 的 sCageHA、7JH5 的
   Co-LOCKR），**没找到打开态结构**，位移只能靠建模。
2. **偶联化学**：**MBP 完全没有半胱氨酸**（370 aa，0 个 Cys）。引入一个 Cys 即可做
   1:1 定点标记，无竞争位点。7CBC 在移植的 binder 区里带 2 个天然半胱氨酸（275、301），
   要先突变掉，否则错标的报告基团会落在不动的地方。
3. **先例**：LOCKR 家族**从未有过电化学读出**（见 5.7）。蛤壳类周质结合蛋白有两个：
   Benson, Conrad, de Lorimier, Trammell, Hellinga, *Science* **2001**, 293, 1641
   （MBP/GGBP/谷氨酰胺/谷氨酸/锌，Ru(II) 马来酰亚胺标记工程半胱氨酸，金电极）；
   以及上面 5.3 提到的 GGBP/L-DOPA 碳电极传感器。

   **但要注意 Benson 2001 的机制不同**：它的信号是**形式电位 E°′ 的移动**（铰链闭合
   改变了探针周围的介电/静电环境），**不是**电子传递速率或距离的改变。电化学测得的
   亲和力比溶液中弱 2–5 倍。所以"Ru 标记的 MBP 能工作"不自动推出"MB 标记的 MBP 能工作"
   —— MB 的信号模式是距离/碰撞依赖的。**周质结合蛋白 + MB + SWV 这个组合我没有找到先例。**

### 半胱氨酸该点在哪（`reporter_placement.py` 已算出）

把 MBP 的 N 瓣当作固定在电极上，按结合麦芽糖后的位移排序：

- 位移最大的位点聚在三个环区：**134–143、200–202、352–356**，都充分暴露，最大 21.3 Å
- **全部残基位移中位数只有 4.6 Å**
- **只有 14% 的残基位移超过 15 Å，而 48% 的残基位移不到 3 Å**

**随便挑一个挂载位点，接近一半的概率做出一个几乎没有信号的传感器。**
这就是为什么报价单给 MB 位点分析排 6–8 周是对的。

注意一个限制：这里排的是**总位移**，真正决定信号的是**垂直于电极表面的分量**，
它取决于蛋白固定后的取向。所以这个排序用来筛短名单，最终要靠真实表面上的 MD 定。

### 挂载位点：文献支持的机制和位移机制指向不同位置

**这一条推翻了上面按位移排序的直接结论，必须先读。**

唯一的蛋白 E-AB 研究（Kang, Sun, Kurnik, Morales, Dahlquist, Plaxco, *JACS* 2017,
139, 12113）在 CheY 上扫了 8 个单半胱氨酸位点（M17C、E37C、T71C、A80C、G89C、K91C、
K97C、E117C），实测增益 4%–30%，并且**增益最大的是 MB 靠近结合位点的那些位点**，
作者归因于**结合上去的分析物在空间上挡住了 MB 接近电极**，而不是挂载残基的刚体位移。

所以按位移排序优化的是**另一个机制**。两者的电化学描述完全相同（都通过降低有效电子
传递速率起作用），差别只在**半胱氨酸该点在哪** —— 而这正是最贵的那个决定。

**建议把两套排序当作互相竞争的假设并行验证**：位移假设指向 134–143 / 200–202 /
352–356 三个环区；空间遮挡假设指向麦芽糖口袋周边（ASN12、ASP14、LYS15、TRP62、
ASP65、ARG66、GLU111、GLU153、TYR155、PHE156、TRP230、MET330、TRP340、ARG344）。
两组位点零重叠，所以这是一个干净的对照实验。

### 4%–30% 的信号缺口有三个解释，修法各不相同

用模型反推，两种机制都能重现实测范围：

| 假设 | 参数 | 信号变化 |
|---|---|---|
| A：报告基团确实只动了一点 | 位移 2.0 Å | −14.7% |
| C：空间遮挡（**文献支持的机制**） | 见上 | 4%–30% 实测 |
| B：位移足额 8 Å，但多数探针无响应 | 死分数 75% | −24.2% |
| B | 死分数 90% | −9.7% |
| B | 死分数 95% | −4.8% |

**A 的修法是把标记移到位移更大的残基；B 的修法是换固定化学和表面密度；C 的修法是把标记
移到离结合位点更近的地方，方向和 A 相反。猜错就浪费一个设计周期。**

顺带排除一个嫌疑：**连接臂柔性不是原因**。即使距离系综宽达 9 Å，8 Å 的真实位移仍能
留下约 48% 的信号。

**一个实验就能区分**：A 会让整个单层小幅移动，伏安峰保持单峰、只是变矮；B 会把单层
劈成一个大的不响应群体和一个小的响应群体，伏安图变成**两个不同 k0 分量之和**，会**变宽**
而不只是变矮。用 k0 分布去拟合实测伏安图（RedoxPySolid 正是干这个的），峰形就告诉你
是哪种机制 —— 在动手重新设计之前。

## 6. 建议的做法

**第一阶段（1–2 周，几乎零成本）——先把该做的判断做完再花钱**

1. 用本目录的模型跑真实靶点参数，输出 ΔG_open 设计窗口和预测标定曲线。
2. 把 latch–电极吸附作为第四个状态加进热力学模型，量化它能补回多少 ΔG_CK。
3. 定 MB 挂载候选位点：优先选构象变化中位移最大的残基，这是 5.2 的直接推论。

**第二阶段（4–8 周，需要 GPU）**

4. MB 与 latch 的结合位点：对接（smina/GNINA）+ OpenMM MD + FEP 自由能。
5. latch 在石墨烯上的取向与吸附自由能：GROMACS/OpenMM + metadynamics。**只作排序用。**
6. 用 Boltz-2 / ProteinMPNN 做 cage-latch 变体的结构与稳定性预排序，替代 Rosetta。

**第三阶段（并行，2–4 周）**

7. 器件模型：本目录的一维模型已足够；若确定要微流控或电极阵列，再上 FEniCSx。
8. 用 RedoxPySolid 或 ElectroKitty 交叉验证 SWV 部分。

**必须尽早拿到的实验输入**（模型给不出来的）：

- 一条真实的 MB/碳电极 SWV 曲线，用来标定 k0 和 Γ（绝对电流量级完全依赖它）；
- Monod Bio binder 的实测 Kd；
- 目标生物标志物的临床浓度窗口 —— 没有它，ΔG_open 无从优化。
