## ⚠️ D. 结构尺度选择（`e04_linear_stability.py`）

预言 `ℓ* = 2π/k*`，`k* = argmax Re λ(k)`；测量 = S(k) 峰位（t = 6 s，4 个种子中位数）。

理论抓住了**标度**（ℓ ∝ α，跨 α = 11…38 保持同一比例），
但作为平均场闭合，**前因子只准到一个常数**：

| α | k\*_理论 | k_测量 | ℓ\*_理论 | ℓ_测量 |
|---|---|---|---|---|
| 11 | 0.1040 | 0.1714 | 60.4 | 36.7 |
| 14 | 0.0819 | 0.1318 | 76.7 | 47.7 |
| 17 | 0.0676 | 0.1132 | 92.9 | 55.5 |
| 20 | 0.0557 | 0.1001 | 112.8 | 62.7 |
| 24 | 0.0466 | 0.0736 | 134.9 | 85.3 |
| 28 | 0.0401 | 0.0687 | 156.8 | 91.4 |
| 33 | 0.0341 | 0.0547 | 184.1 | 114.8 |
| 38 | 0.0298 | 0.0486 | 211.1 | 129.4 |

过原点最小二乘：**ℓ_测量 = 0.607 · ℓ\***，**R² = 0.9906**（α 跨 3.5 倍范围）。

这一项标 ⚠️：**"尺寸正比于 minRadius" 是被验证的；"尺寸等于 2π/k\*" 不是。**

顺带确定的两件事：

* 单物种在 282 组随机参数（Û(0)<0）中，Û(k) 的极小值**每次**都在 k = 0
  ⇒ 单物种无法选出有限尺度，只能无限粗化。
* 多物种通过中介有效相互作用 `Û^eff_aa = Û_aa − Û_ab Û_ba/Û_bb` 得到有限 k 极小
  （示例：k = 0.244，ℓ ≈ 26，而 `Û_aa` 自身极小在 k = 0）。

## ✅ E. 非互易行波转变（`e05_nonreciprocal_transition.py`）

固定 `A = [[−0.1, 0.9], [−0.9, −0.1]]`，α = 15、β = 45、N = 6000、L = 1200，只调摩擦：

脚本从色散关系解出的阈值是 **λ_c ≈ 0.157**（Re λ_osc 变号处）。
实测运动性在 λ ≥ 0.15 塌到 ~0.003 的**残余平台**——那不是零，而是非线性的

**一个有价值的副产品：平台默认的 λ = 0.3 恰在阈值的静态一侧。**
所以默认参数下"先成团、后运动"——运动来自已形成团簇的净内力（第 4 节），
而不是均匀态的线性行波不稳定性。

## ✅ G-bis. 非互易指标必须包含半径矩阵

第一版 E06 用 `ν_A = ‖A−Aᵀ‖/(…)` 作横轴，结果出现明显矛盾：
`Chains 1`（A 严格对称，ν_A = 0）测得 motility = 0.92。

原因不是定理错，而是**指标选错**：站点的随机化器对 min/max 半径按 ordered pair
独立采样，α 与 β 本身不对称，于是 f_ab ≠ f_ba 即使 A = Aᵀ。
改用作用在真实力函数上的

    ν_f = ‖f_ab − f_ba‖₂ / (‖f_ab + f_ba‖₂ + ‖f_ab − f_ba‖₂)

后：`chains1` + 默认随机半径 → **ν_f = 0.196**（确实非互易）；
`chains1` + 对称半径 → **ν_f = 0.000**（确实互易）。
E06 现在用对称半径 + ν_f，两者一致。

**对平台用户的直接含义：只把 Forces 矩阵对称化不足以让系统停下，
Min. Radius 和 Max. Radius 也必须对称。**

## ✅ H. 图谱与形态发生图（`e06`, `e07`）

**E06（21 个预设，同条件、对称半径、ρ = 0.0020 < ρ_max）**

* 10 个 ν_f = 0 的宇宙，运动性全部落在 **0.002–0.011** 的窄带（残余弛豫地板）；
* 运动性排前四的（Concentric Shells 0.099、Patchwork 0.067、Random 0.038、
  Rotating Conveyor 0.028）ν_f 分别是 0.19 / 0.29 / 0.32 / 0.27；
* **线性理论的 regime 判定与 ν_f 在 21/21 上完全一致**：
  ν_f = 0 → `static`，ν_f > 0 → `condense+move` 或 `travelling`。

保留：Wavefield / RPS / Hub 这几个 ν_f > 0 的预设运动性也低（0.002–0.004），
原因是它们没有凝聚（D₂ ≈ 2，气体状），"团簇质心速度"这个观测量对它们无意义。

**E07（(w, b) 平面 9×9 扫描）**

形态相图上"静态链/网络"的带子**逐格贴着 w = b 这条互易线**，两侧全是"爬行细丝"。
互易线上 motility = 0.004–0.009；离开它可达 **20.2**（w=0, b=1）—— 跨越三个数量级。

⚠️ 仍需保留的一点：把序参量切成形态标签用的阈值（D₂ 1.55 / ψ₆ 0.42 /
motility 0.02 / 团簇 6）是**经验拟合**，不是从理论导出的。
分界的存在是被验证的，分界的具体数值不是。
