02 为什么会动

互易 ⇒ 必然静止

把力拆成互易与非互易两半：f_S = ½(f_ab + f_ba)，f_A = ½(f_ab − f_ba)。

定理. 若 A、α、β 全部对称，则 E = ½Σ|vi|² + Σi<j U(rij) 满足
    Ė = −γ Σi |vi|² ≤ 0 E 有下界 ⇒ 由 LaSalle 不变原理，轨道收敛到 {v = 0}。 不可能有持续的爬行、追逐、旋转或振荡。

更锐利的形式是功率。Ė 里唯一的非变分项是

Pinj = 60κ Σi<j fA(rij) r̂ij · (vi + vj) 互易时逐项恒等于 0。稳态下必有 ⟨Pinj⟩ = γΣ|vi|² ——打破的第三定律，就是为这套"生命"付电费的那台发电机。
一个实测中发现的陷阱。 定理的前提是 fab ≡ fba， 而不是 A = AT。α 和 β 同样是有序对矩阵。 站点的随机化器对 min/max 半径按 ordered pair 独立采样，产生的半径矩阵不对称。 实测：Chains 1（A 严格对称）配默认随机半径给出 νf = 0.196， 配对称半径给出 0.000。 所以只把 Forces 页签对称化，系统不会停——Min. Radius 和 Max. Radius 也要对称。 这条是第一版实验自相矛盾（A 对称却测到 motility 0.92）之后才挖出来的。

04 尺度

结构多大，由色散关系说了算

把密度场粗粒化并线性化。设 Ûab(k) 是 U 的二维 Hankel 变换， σn(k) 是 diag(ρ̄)Û(k) 的本征值（一般是复数），则每支满足

λ² + γλ + 60κ k² σn(k) = 0   ⇒   λ± = ½( −γ ± √(γ² − 240κk²σn) ) 即使 Uab ≠ Uba（没有自由能），这个线性算子依然良定义——这正是关键。

Re λ(k) 在有限 k* 取极大：长波端被粒子数守恒的 k² 前因子压住， 短波端被核心排斥（σ > 0）压住。于是 ℓ* = 2π/k* 就是第一批结构的尺寸。

一个必须诚实说明的结果：单一物种做不到有限尺度。 在 282 组随机单物种参数中，Û(k) 的极小值每一次都落在 k = 0——单物种只能无限粗化。 有限的、重复出现的细胞总是来自多物种竞争：短程自吸引 + 长程互斥， 就是在物种空间里实现的 SALR 核。
