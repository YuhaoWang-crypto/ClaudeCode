# 从 pattern 到功能：真实蛋白群的机制信息链

> 前一份 `PATHWAY_ATLAS.md` 回答「会长成什么形态」。这一份回答下一个问题：
> **这个形态让细胞获得了什么能力？** 每一条链的每一个箭头都配一个算出来的数，而不是叙述。
>
> 代码：`theory/plife/bio/function.py`　验证：`theory/test_function.py`（35 项全过）
> 图：`theory/figures/e11_mechanism_chains.png`　数据：`theory/results/e11_mechanism_chains.json`
>
> 交叉检验：[`CHAIN_CROSSCHECK.md`](CHAIN_CROSSCHECK.md) —— 拿九条独立整理的真实信息链逐条检验这套框架，
> 含一处**符号错误**及由此补上的别构层。

信息链的统一格式：

```
分子参数（价数 / Kd / 浓度）
   ↓  模型量（可算）
形态（pattern）
   ↓  涌现的能力（可算）
生物学功能
   ↓
可证伪的预测
```

---

## 0. 为什么值得做这一层

价数、Kd、浓度是**测量**；形态是**观察**。两者之间的桥前一份已经搭好了。
但真正解释机制需要的是第三段：**形态凭什么产生功能**。

这一段常常被当成定性叙述（「凝聚体富集了酶所以反应快」），而它其实是可以算的，
而且一算就会发现好几个反直觉的地方——本文档第 3 节全是这类。

## 1. 五条能力链

### 链 A｜超敏开关：不需要任何协同结合

```
价数 n ≥ 3，普通的非协同单键（Kd 10 µM）
   ↓  凝胶分数 g = 1 − Π t_k^{n_k}（多型分支过程的灭绝概率）
渗流转变：阈值以下 g 恒等于 0，阈值以上近乎垂直上升
   ↓  有效 Hill 系数 n_H = dln[g/(1−g)]/dln c
数字化开关
```

| 价数 | 有效 Hill 系数 |
|---|---|
| 3 | **3.7** |
| 4 | **3.8** |
| 6 | **4.0** |
| 8 | **4.0** |
| — 参照：双曲结合曲线 | 1.0 |
| — 参照：血红蛋白（真有协同） | 2.8 |

**模型里只有一个 Kd，没有任何协同项、没有别构、没有 Hill 参数。**
陡峭度完全来自连通性转变本身。

> **启发**：教科书默认「超敏 = 需要协同结合 / 多位点磷酸化 / 零级超敏」。
> 渗流白送一个 $n_H \approx 4$。所以当你看到一个陡峭的剂量反应曲线时，
> **「有协同结合」并不是唯一解释**，而且往往不是最省事的那个——
> 先查这些蛋白是不是多价的、是不是在阈值附近。

### 链 B｜浓度缓冲：让表达噪音停止传播

```
体系跨过渗流阈值
   ↓  自由（全部位点未成键）浓度 c_free = c·Π X_k^{n_k}
网络吸收掉新加进来的蛋白
   ↓  dln c_free / dln c_total
下游看到的浓度被钳住
```

| 区间 | dln c_free / dln c_total |
|---|---|
| 稀释极限 | **+0.96**（自由浓度跟着总量走） |
| 阈值以上 | **−0.72**（总量涨，自由浓度反而降） |

数值上：总量 ×3，自由蛋白只到 **×0.57**。

> **启发**：mRNA→蛋白的散布大约 3 倍（这就是 `protein_from_mrna` 里那个 log10_sd=0.5）。
> 如果下游读的是**自由浓度**，那么跨过阈值以后这 3 倍噪音基本被吃掉。
> **多价网络可以当成一个浓度缓冲器用**——这可能是「为什么很多支架蛋白的表达量看起来
> 管得并不严，通路输出却很稳」的一个机制性答案。
>
> **实验含义**：测总蛋白量和测自由蛋白量，在阈值附近会给出完全不同的结论。
> 想验证就得测自由的那一份（FCS、热泳、或者拉下未结合组分），不是 western。

### 链 C｜排阻 → 双稳态 → 记忆（最值得注意的一条）

```
磷酸化「造出」价数（n = n_max·p）
   ↓  g(p)：磷酸化程度决定成网程度
网络形成
   ↓  尺寸排阻：大的磷酸酶进不去，access α(p) = 1 − g(p)(1−a)
磷酸酶被排除
   ↓  正反馈：磷酸化 → 成网 → 磷酸酶进不去 → 更磷酸化
双稳态 + 滞回
```

稳态条件 $R \equiv k_{\rm kin}/k_{\rm ppt} = p\,\alpha(p)/(1-p)$。
没有反馈时右边单调，只有一个根；有反馈时它会翻折，出现**三个根**（两稳一不稳）。

以 LAT 样的参数（scaffold 10 个磷酸位点、四价接头、局部各 10 µM、Kd 10 µM、
磷酸酶残余进入 5%）：

| 量 | 值 |
|---|---|
| 出现双稳的 $R$ 范围 | **0.06 – 0.27**（滞回宽度 **4.7×**） |
| 两个稳态的磷酸化程度 | **p = 0.06 vs 0.81** |
| 对照：把 g 强行设为 0（无排阻） | **双稳态完全消失** |

**这个双稳态不是设计出来的。** 模型里没有任何一处写了「产生双稳态」；
它是「渗流曲线」+「尺寸排阻」这两个各自独立测定的东西相乘的结果。
所需的排阻强度也不夸张：图 4 显示 access ≲ 0.3 就够，而实测的尺寸排阻是
**3 nm 探针 0.059、8 nm 探针 0.0025**——CD45 这种大的跨膜磷酸酶远在要求之内。

> **启发**：T 细胞的全或无激活、突触的长时程增强、细胞命运的锁定，
> 通常都要引入一个显式的正反馈回路（转录、别构、双磷酸化）。
> 这条链说：**只要「修饰产生价数」且「网络按尺寸排阻反向酶」，
> 正反馈是免费的，双稳态是自动的。**
> 这可能是很多「找不到明确正反馈却观察到双稳」的体系的答案。

### 链 D｜配体长度就是价数：自我/非我识别

```
一方的价数 = 聚合物长度（dsDNA 每 ~20 bp 一个 cGAS 结合圈）
   ↓  分支门槛 (n_A−1)(n_B−1) ≥ 1 → 需要 n_DNA ≳ 长度阈值
短配体点不着，长配体点得着
   ↓  最小长度 L_min
长度依赖的免疫激活
```

| [cGAS] | 最小激活 dsDNA 长度 |
|---|---|
| 0.5 µM | **160 bp** |
| 0.2 µM | **249 bp** |
| 0.05 µM | **687 bp** |
| 0.02 µM | **1592 bp** |

> **启发**：cGAS 的「长 DNA 才激活」通常被描述成一种识别特性。
> 这条链说它**根本不是识别问题，是算术**：短 DNA 提供的价数不够越过渗流门槛。
> 而且它给出一个强预测：**长度阈值随 cGAS 丰度反比移动**——
> 干扰素预处理上调 cGAS 之后，激活所需的最小 DNA 长度应当显著变短。
> 同样的逻辑直接适用于 **p62 读泛素链长度**、**应激颗粒读裸露 mRNA 长度**：
> 链长/裸露长度就是价数，阈值就是门槛。

### 链 E｜共富集加速反应——以及为什么头条数字是错的

```
客体被网络富集（分配系数 K）
   ↓  双分子速率 ∝ [E][S] → 局部加速 K_E·K_S
凝聚体内反应加快
   ↓  但只有 φ 的体积是凝聚体，且内部黏度高
全细胞通量的真实增益
```

| 情形 | 增益 |
|---|---|
| 局部（凝聚体内部），K_E = K_S = 100 | **10⁴ ×** |
| 全细胞，φ = 1% | **101 ×** |
| 全细胞，φ = 1%，内部扩散慢 100 倍 | **2.0 ×** |

> **启发**：文献里常见的「凝聚体使反应加速上万倍」是**局部**数字。
> 换算到全细胞通量要乘体积分数、再除以黏度惩罚，常常只剩个位数。
> **所以「加速反应」多半不是凝聚体的主要功能**——
> 真正大的效应是上面那三条：开关陡度、缓冲、双稳态，以及下面的排阻选择性。
> 想验证到底是哪一种，就去测**体积分数**和**内部扩散系数**，不要只报分配系数。

## 3. 四个反直觉的、可以直接拿去做实验的预测

这一节是这份文档最有用的部分——模型给出的、和直觉相反的判断。

### 3.1 给 LAT 体系补 Grb2，会**破坏**凝聚体

在膜浓度下，把三个组分分别单独加 6 倍：

| 操作 | pLAT 进网络的比例 |
|---|---|
| 都不动 | 0.144 |
| **SOS1 ×6** | **0.807** ↑ |
| **Grb2 ×6** | **0.000** ↓ 完全散架 |

原因是化学计量窗口（条件三）：Grb2 只有一个 SH2，过量的 Grb2 会把 pLAT 的每个磷酸酪氨酸
**单价封顶**，变成死端，网络失去交联。SOS1 则是四价的，加它是加交联。

> **可测**：在重组体系或细胞里做 Grb2 的剂量曲线，应当看到**钟形**——
> 而不是单调上升。这一条如果做出来是单调的，模型这部分就错了。

### 3.2 「过表达却看不到凝聚体」不代表这个蛋白不参与

同样是化学计量窗口。数值上：$n=4\times4$、Kd 10 µM 的体系，伙伴加到 40 倍，
分支因子从 2.45 掉到 **0.47**——网络彻底消失。

> **可测**：任何用过表达来判断「X 是不是凝聚体组分」的实验都必须做**剂量曲线**。
> 单点过表达阴性是没有信息的。

### 3.3 LAT 凝聚体是**化学计量受限**的，不是亲和力受限的

即使把三个组分一起放大 2000 倍，**pLAT 的入网比例**也只到 **0.163** 就饱和了——
因为 SOS1 只提供 0.63 µM 位点，是三者里最少的（pLAT 6.32、Grb2 SH3 4.47）。

> **可测**：SOS1 的表达水平应当比 Grb2 或 LAT 的表达水平更强地控制簇的大小。
> 这给出一个具体的敲低优先级。

### 3.4 提高亲和力可能**破坏**通路绝缘

pool 分析说：跨通路 Kd 只要跌破约 **2 µM**（组内 Kd 的调和平均），
本该分开的凝聚体就会融合，5 个体先并成 3 个、再并成 1 个。

> **可测的病理机制**：任何增加结构域杂交结合的突变、融合蛋白、或大幅过表达，
> 都可能通过「体融合」而不是通过「激酶活性改变」来致病。
> 融合蛋白癌症（EWS-FLI1、FUS-CHOP 之类）值得从这个角度重看一遍。

## 4. 怎么用这些链去想机制：一张诊断表

**观察到什么 → 模型说去查什么。**

| 你观察到 | 模型的第一嫌疑 | 去测什么 |
|---|---|---|
| 剂量反应特别陡（$n_H$ > 2） | 未必是协同结合，可能是渗流 | 组分的**价数**；是否在阈值附近 |
| 表达量波动大但输出稳定 | 网络在做浓度缓冲 | **自由**浓度 vs 总浓度 |
| 全或无、有记忆、有滞回 | 修饰造价数 + 反向酶被排阻 | 反向酶的**尺寸**和分配系数 |
| 配体长度决定激活 | 长度就是价数 | 阈值长度是否随受体丰度反比移动 |
| 过表达反而没有凝聚体 | 化学计量窗口的再进入 | **剂量曲线**，找钟形峰 |
| 两个本该分开的体融合了 | 跨通路亲和力跌破调和平均 | 杂交结合的 Kd |
| 凝聚体在**持续定向运动**或周期振荡 | **平衡态解释不了**，一定有 ATP 循环 | 找那个激酶/GTPase/解折叠酶循环；测 $k_{\rm cat}[E]$ vs $k_{\rm off}$ |
| 看到的是丝不是液滴 | 每类位点只有一个（一头一尾） | 结构域拓扑，不是亲和力 |
| 亲和力很强却没有凝聚体 | 价数门槛关着 | 按**结构域分类**数价数，不要数总数 |

最后一行值得重复：**报价数必须按结构域分类报**。
「Grb2 是三价的」这句话在预测相行为时会给出错误答案（把开启阈值从 18× 错报成 1×）。

## 5. 局限（哪些数能信，哪些不能）

| 量 | 性质 |
|---|---|
| 凝胶分数 `gel_fraction`、自由浓度 `free_monomer` | ✅ 在 Wertheim TPT1 已经假设的树形拓扑下**精确**，与自由能同等可靠 |
| Hill 系数、长度阈值、化学计量效应 | ✅ 上面两者的导出量，同样可靠（在参数给定的前提下） |
| `rate_enhancement` | ✅ 给定分配系数后是精确记账；但 φ 和黏度惩罚要你自己测 |
| `phospho_bistability` | ⚠️ **最小反馈模型**。双稳态本身是算出来的凝胶曲线 + 实测排阻的真实后果；但速率常数是示意性的，没有空间和动力学细节 |
| 绝对 $c_{\rm sat}$ | ⚠️ TPT1 不含分子内成环，偏低 1–2 个数量级。比较比值和趋势，不要引用绝对值 |
| 表里的 Kd / 价数 / 浓度 | ⚠️ 数量级的文献典型值，不是测量值 |
| 几何、动力学、主动过程 | ❌ 完全没有。纤维的螺旋对称、成核时间、凝胶老化、ATP 驱动全部不在模型里 |

还有一条原则性的：**平衡态热力学做不出会动的图案**。
$K_d^{AB}=K_d^{BA}$ 是细致平衡，互易系统有 Lyapunov 函数、必然静止。
所以诊断表最后那一行不是经验规则，是定理的直接推论。
