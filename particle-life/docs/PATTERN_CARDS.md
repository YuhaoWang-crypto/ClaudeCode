# 形态参数卡 · 每种结构的核心参数、对应模型与分析

这份报告把 `THEORY.md` 里的理论落到**可直接照抄的参数**上。
十种形态，每种给出：参数卡（抄进模拟器就能复现）、背后的模型项、
理论预言与实测的逐项对照、以及**哪个旋钮一动它就没了**的敏感性扫描。

全部数据由 `theory/experiments/e08_pattern_cards.py` 产出
（原始数值 `theory/results/e08_cards.json`，每张卡一幅图 `theory/figures/e08_card_*.png`）。
除非特别标注，主运行统一为 **N = 3000，L = 1200（ρ = 2.08×10⁻³），κ = 1，Δt = 1/60，环面边界，t = 43 s**。

## 0. 三个判别量

读卡之前先记住这三个数——形态基本由它们决定：

| 量 | 定义 | 读法 |
|---|---|---|
| **ν_f** | ‖f_ab − f_ba‖₂ / (‖f_ab+f_ba‖₂ + ‖f_ab−f_ba‖₂) | 0 ⇒ 定理保证冻结；> 0 ⇒ 可以动。**注意它看的是三个矩阵，不只是 A** |
| **coherence** | 最不稳定本征向量的 \|Σv_a\| / Σ\|v_a\| | 1 ⇒ 各物种一起聚成一团（液滴）；0 ⇒ 反相分离（核壳、膜、条纹） |
| **D₂** | [α, 3.5α] 尺度上的关联维数 | ~1 ⇒ 细丝/链；~2 ⇒ 团块/片；> 2 ⇒ 稀疏气体 |

再加两个"会不会动"的量：团簇**净内力** F_int（⇒ 平移）和**净内力矩** τ_int（⇒ 自旋），
二者在 ν_f = 0 时恒等于零。

## 2. 均匀气体 / 排斥液体

**参数卡**

```
S = 3     A[i][j] = −0.6  (全部)
α = 15    β = 45    R = 1    λ = 0.30    N = 3000, L = 1200
```

**模型.** 全排斥 ⇒ 没有凝聚，但**并非没有结构**：有限密度下的纯排斥体系会自发排成
一个优先间距的"维格纳液体"。这是 k ≠ 0 处的一个弱不稳定性，
`Û(k)` 在 k* = 0.170 处取负最小值。

**理论 → 实测**

| 量 | 理论 | 实测 | 误差 |
|---|---|---|---|
| 优先间距 ℓ* = 2π/k* | **37** | **38** | **3 %** |
| 团簇净内力 F_int | 0（互易） | 0.0000 | 恒等式 |
| motility | 0 | 0.0074 | 残余弛豫地板 |

> **这是十张卡里 ℓ 预言最准的一张，而且不是巧合。**
> 线性理论是围绕**均匀态**展开的；排斥体系始终贴着均匀态，所以平均场闭合几乎精确。
> 强凝聚的卡（团块 0.62、链 0.72、蛇 0.65）落在 E04 测到的 0.607 那条平均场折扣上；
> 而弱凝聚/行波的卡（气体 1.03、追逐者 0.96、行波 1.09、旋涡 1.13）几乎不打折。
> **平均场的误差不是常数，它随密度反差增大而增大。**

**敏感性**（扫 A_ij，全部对）

| A_ij | −0.6 | −0.2 | +0.1 | +0.4 |
|---|---|---|---|---|
| motility | 0.0070 | 0.0049 | 0.0026 | 0.0011 |
| D₂ | 1.62 | 1.89 | 1.29 | **0.46** |

A_ij 越正越聚团：D₂ 从 1.9（近二维散布）掉到 0.46（紧凑小团）。ν_f 全程为 0，所以**怎么调都不会动**。

## 4. 晶体团簇

**参数卡**

```
S = 3     A[i][j] = 0.9  (全部)
α = 16    β = 26        ← 窄吸引带 β/α = 1.63
R = 4     λ = 0.30
```

**模型.** 吸引带窄 + 核心硬（R = 4）⇒ 每条键被锁死在 r = α，
体系没有别的自由度，只能六角密堆。局域六角序 **ψ₆ = 0.62**（随机气体是 0.44，完美三角格是 1.0）。

> **一个要说清的细节：** 这张卡的 ℓ_实测 = 15 不是畴尺寸，而是**布拉格峰**——
> 即晶格常数本身（理论键长 α = 16，实测 15，差 6 %）。

R 小 ⇒ 核心软 ⇒ 塌成致密小团（D₂ 低）；R 大 ⇒ 撑开成二维片（D₂ → 1.8）。
**R 控制的是"硬度/密度"，不是"动不动"。**

## 5. 核-壳细胞

**参数卡**

```
S = 2     A = [[0.90, 0.45],
               [0.45, −0.50]]              （对称 ⇒ 互易）
α = [[12, 22],   β = [[42, 60],
     [22, 16]]        [60, 48]]            ← α₀₁ = 22 > α₀₀ = 12：把膜推到外圈
R = 1     λ = 0.30
```

**模型.** 0 号是核（自吸引 0.9），1 号是膜（**自斥 −0.5**，但被核吸住 0.45）。
自斥使膜无法聚成实心团，只能摊成一层；交叉键长 α₀₁ = 22 大于核内键长 α₀₀ = 12，
于是膜必然待在核外面。最不稳定模 **coherence = 0.10** —— 分量反号的分相模，
正是"核与膜互相排开又互相束缚"的数学形式。

**理论 → 实测**

| 量 | 理论 | 实测 |
|---|---|---|
| coherence | 0.10（分相） | 快照：绿色核 + 品红膜，规则排布 ✓ |
| F_int / τ_int | 0 / 0 | **0.0000 / −0.0000** |
| ℓ* | 51 | 92 |
| 团簇数 / 大小 | — | 85 个 / 平均 36 |

ℓ 差 1.8 倍是这十张卡里最大的偏差。原因不难理解：这张卡的**半径按对不同**
（α 从 12 到 22，β 从 42 到 60），"一个"长度尺度本来就不唯一，
线性理论挑的是最短程那条通道。

**敏感性**（扫膜的自耦合 A₁₁）

| A₁₁ | −0.9 | −0.5 | −0.1 | +0.3 |
|---|---|---|---|---|
| D₂ | **1.13** | 0.99 | 0.78 | **0.47** |
| motility | 0.0057 | 0.0037 | 0.0037 | 0.0009 |

A₁₁ 由负转正，膜就不再是膜——它开始自聚，细胞塌成实心团，D₂ 从 1.13 掉到 0.47。
**膜的存在完全依赖膜物种的自斥。**

## 6. 链 / 网络

**参数卡**

```
S = 5     A[i][i] = 1.0,  A[i][i±1] = 0.35,  其余 = −0.9      （对称）
α = 15    β = 45    R = 1    λ = 0.30
```

**模型.** 类型空间上的**环图**：i 只和 i±1 成键，其余互斥。
一维的成键拓扑映射成实空间的一维流形 ⇒ 细丝、链、网络。
**链的粗细就是键长 α。** A 对称 ⇒ ν_f = 0 ⇒ 静止。

**理论 → 实测**

| 量 | 理论 | 实测 |
|---|---|---|
| D₂ | ≈1（一维流形） | **1.09** ✓ |
| ℓ* | 82 | 59（比值 0.72） |
| F_int | 0 | **0.0000** |
| coherence | 0.00（分相） | 相邻物种交替排列 ✓ |

**敏感性**（扫环耦合 w = b）

| w = b | 0.0 | 0.2 | 0.35 | 0.8 |
|---|---|---|---|---|
| D₂ | 1.17 | 1.00 | 1.06 | 1.19 |

只要**保持 w = b**，链再结实也不会动（motility 始终 ≈ 0.01）。

## 7. 爬行的蛇 ★

**参数卡**

```
S = 5     A[i][i] = 1.0,  A[i][i+1] = 0.8,  A[i][i−1] = −0.1,  其余 = −0.9
                                            ↑ 正向 ≠ 反向：这一处不对称就是全部
α = 15    β = 45    R = 1    λ = 0.25
```

**模型.** 和上一张卡**同一个环图**，唯一区别是正向耦合 0.8 ≠ 反向耦合 −0.1。
于是每一条键都是一次追逐，团簇净内力沿链方向不再抵消：

> F_int = Σ_{i<j} 2 f_A(r_ij) r̂_ij ≠ 0  ⇒  整条蛇自己往前爬

**理论 → 实测**

| 量 | 理论 | 实测 | 误差 |
|---|---|---|---|
| 团簇漂移 V = μ_disc·\|F_int\|/N_C | **14.2988** | **14.3179** | **0.13 %** |
| 团簇自旋 ω = μ_disc·τ_int/I | −0.0348 | −0.0315 | 9.5 % |
| D₂ | ≈1 | 1.15 ✓ | |
| 线性判定 | travelling | motility 0.727 ✓ | |

> 一个 280 粒子的团簇，它的漂移速度由**内部力的矢量和**预言到 **0.13 %**。
> 这就是"结构不是被推着走，而是自己内部的力不再抵消"的直接测量。

**敏感性**（扫非互易度 θ，θ=0 时正向=反向=0.35，即上一张卡）

| θ | 0.0 | 0.35 | 0.7 | 1.0 |
|---|---|---|---|---|
| ν_f | 0.00 | 0.08 | 0.15 | 0.20 |
| motility | **0.0098** | 0.121 | 0.370 | **0.690** |
| D₂ | 1.09 | 1.11 | 1.11 | 1.11 |

**D₂ 全程不变 1.09–1.11**：形状始终是链。变的只有它动不动——
motility 从 0.0098 涨到 0.690，**70 倍**，而 θ = 0 那一格正是互易点。

## 8. 追逐者 / 迁移细胞

**参数卡**

```
S = 2     A = [[0.80,  0.90],
               [−0.90, 0.80]]
          ↑ A_S = diag(0.8) 精确对角，A_N = ±0.9 纯反对称
α = 14    β = 42    R = 1    λ = 0.10   （γ = 6.3 s⁻¹）
```

**模型.** 分解得干干净净：对称部分只有对角自吸引（负责各自成团），
反对称部分只有交叉项（负责追逐）。**交叉的对称部分为零 ⇒ 两个物种不共处一团**——
绿团追着品红团跑，驱动力是**团簇之间**的，不是团簇内部的。
（因此这张卡用较大的聚类半径 2.8α 才能把"追逐对"当成一个单元。）

**理论 → 实测**

| 量 | 理论 | 实测 | 误差 |
|---|---|---|---|
| ℓ* | 80 | **77** | **4 %** |
| 行波相速 c = Im λ/k | 9.1 px/s | — | |
| 追逐对漂移 V | 0.638 | 0.509 | 25 % |
| 线性判定 | travelling | motility 0.108 ✓ | |

漂移预言只准到 25 %，比蛇（0.13 %）差得多，原因已在模型里：
这里的驱动是**团簇间**的，把两团当成一个刚体来算内力本来就是近似。

**敏感性**（扫摩擦 λ，单种子）

| λ | 0.04 | 0.10 | 0.15 | 0.30 |
|---|---|---|---|---|
| motility | 0.510 | 0.053 | 0.216 | 0.156 |

⚠️ 这一行**不单调**。追逐态是间歇性的（追上—散开—再追），单种子单快照涨落很大。
摩擦的真实趋势由 E05 给出（2 种子、9 个 λ、配合理论阈值 λ_c ≈ 0.157）：
**λ ≥ 0.15 时运动性塌到 ~0.003 的残余平台，λ < 0.15 一侧陡升 5–60 倍。**
这张卡的敏感性以 E05 为准。

## 9. 自旋细胞 / 旋涡 ★

**参数卡**

```
S = 3     A[i][i] = 0.9,  A[i][i+1] = 0.6,  A[i][i−1] = −0.2
α = 14    β = 42    R = 1    λ = 0.20   （γ = 13.4 s⁻¹）
```

**模型.** 三个物种**互相吸引**（自 0.9、正向 0.6）所以待在同一团里 —— coherence = **1.00**，
是凝聚模；但正向 0.6 ≠ 反向 −0.2，团簇获得**净内力矩**：

> τ_int = Σ_{i<j} [(x_i−X) f_ij − (x_j−X) f_ji] × r̂_ij ≠ 0  ⇒  自旋

**理论 → 实测**

| 量 | 理论 | 实测 | 误差 |
|---|---|---|---|
| 团簇自旋 ω = μ_disc·τ_int/I | **+0.4396** | **+0.4421** | **0.57 %** |
| 团簇漂移 V | **3.4538** | **3.4550** | **0.03 %** |
| ℓ* | 80 | **90** | 12 % |
| \|spin\| 序参量 | — | **0.132**（十张卡最高） | |

> 一个 79 粒子的细胞，**转速被内力矩预言到 0.57 %，漂移被内力预言到 0.03 %**。

**敏感性**（扫反向耦合 b，正向固定 0.6）

| b | −0.6 | −0.2 | +0.2 | **+0.6** |
|---|---|---|---|---|
| ν_f | 0.31 | 0.23 | 0.12 | **0.00** |
| motility | 0.846 | 0.100 | 0.029 | **0.0015** |

b → +0.6 时正向 = 反向，矩阵变回互易，**ν_f 精确归零，τ_int 归零，转动消失**。
这是把"旋涡"一路调回"静态细胞"的完整路径。

## 11. 自驱动二聚体气体 ★

**参数卡**

```
S = 2     A = [[−0.90,  0.90],
               [−0.40, −0.90]]           ← 强自斥：不许同类聚团
α = [[15, 15],   β = 45 (全部)           ← α₁₀ = 26 ≠ α₀₁ = 15：半径不对称是马达
     [26, 15]]
R = 1     λ = 0.10     N = 250, L = 1800（ρβ² = 0.16，稀薄）
```

**模型.** 这张卡的物理**不在集体层面**，而在两体层面。强自斥使同类无法聚团，
剩下的是一群孤立的异类束缚对，每一对严格服从两体精确解：

> 键长 r\* 解 f_S(r\*) = 0  →  **r\* = 19.297**
> 漂移 V = μ_disc · f_A(r\*)  →  **V = 2.3203**

**理论 → 实测：一条密度交叉**

| ρβ² | 配对数 | r\*_理论 | r\*_实测 | V_理论 | V_实测 | V/V_th |
|---|---|---|---|---|---|---|
| 2.250 | 69 | 19.297 | 20.756 | 2.3203 | 0.654 | 0.28 |
| 0.844 | 86 | 19.297 | 20.004 | 2.3203 | 1.368 | 0.59 |
| 0.360 | 45 | 19.297 | 19.303 | 2.3203 | 1.849 | 0.80 |
| 0.156 | 22 | 19.297 | 19.221 | 2.3203 | 2.224 | 0.96 |
| **0.063** | 5 | **19.297** | **19.297** | **2.3203** | **2.3203** | **1.000** |

> **两体公式在稀薄极限下精确成立**：ρβ² = 0.063 时键长与速度都对到小数点后四位。
> 密度升高时，二聚体被邻居不断散射，达不到自由末速度——ρβ² = 2.25 时只剩 28 %。
> **这就是"两体理论"的适用边界，用一条曲线量出来了。**

**敏感性**：见上表。控制量是密度 ρβ²，不是矩阵。

## 12. 横向分析：哪个旋钮管什么

把十张卡的敏感性扫描并排看，旋钮的分工非常干净：

| 旋钮 | 改变什么 | 不改变什么 | 证据 |
|---|---|---|---|
| **α**（min radius） | 尺寸（ℓ ∝ α） | 形状（D₂ 恒为 0.67） | §3 |
| **β/α**（带宽） | 键能、配位数、硬度 | 拓扑 | §4 |
| **R**（repel） | 密度/硬度（D₂ 0.58→1.76） | 动不动（motility 恒 ≈ 0） | §4 |
| **A 的图结构** | **形态**（环图→链，二部→核壳，星形→辐射） | — | §5–7 |
| **A 的对称性** | **动不动**（motility ×70） | 形状（D₂ 恒 1.09–1.11） | §7 |
| **正向 vs 反向耦合差** | 平移 vs 自旋的比例 | — | §7 vs §9 |
| **λ**（friction） | 非互易性**能否兑现成运动** | 非互易性本身（ν_f 恒定） | §10 |
| **ρ**（密度） | 两体理论的适用性 | 相互作用 | §11 |

一句话：**A 的图结构决定"长什么样"，A 的不对称性决定"动不动"，
α 决定"多大"，λ 决定"能不能动起来"，ρ 决定"两体公式还准不准"。**

## 14. 保留

* 追逐者的摩擦敏感性单种子不单调（§8），以 E05 的多种子扫描为准。
* 晶体卡的 ℓ_实测 是布拉格峰而非畴尺寸（§4），两者在总表里被并列只是格式所限。
* 形态标签（"crawling filaments" 等）由经验阈值给出（D₂ 1.55 / ψ₆ 0.62 / motility 0.02），
  分界的**存在**被验证，分界的**数值**是拟合的。
* 每张卡只跑一个种子。定量结论（内力预言、密度交叉）对种子不敏感；
  形态标签在临界附近会跳。
