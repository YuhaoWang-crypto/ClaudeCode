## 1. 微观模型（精确，非近似）

状态：N 个粒子，位置 xᵢ ∈ ℝ²，速度 vᵢ，物种 sᵢ ∈ {0,…,S−1}，质量恒为 1。

三个**有序对**矩阵：力系数 A ∈ [−1,1]^{S×S}、最小半径 α、最大半径 β；一个全局标量 R（`repel`）。

### 1.1 力

记 m = (α+β)/2，w = (β−α)/2。粒子 a 受粒子 b 的**径向力**（正号 = 吸引）：

```
              ⎧ R (r/α − 1)                 0 ≤ r < α      核心排斥（与 A 无关）
   f_ab(r) =  ⎨ A_ab (1 − |r − m|/w)        α ≤ r < β      帐篷形，符号 = sign(A_ab)
              ⎩ 0                           r ≥ β          截断
```

粒子 i 的合力 **Fᵢ = κ Σⱼ f_{sᵢsⱼ}(rᵢⱼ) r̂ᵢⱼ**，r̂ᵢⱼ 由 i 指向 j。

> **这里就是全部的"规则"。** 没有隐藏的生命逻辑、没有代理、没有神经网络。
> 之后所有复杂性都是这一条分段线性函数 + 一个非对称矩阵的推论。

### 1.2 积分器（站点的确切更新顺序）

```
v ← ( v + 60κΔt · Σⱼ f r̂ ) · (1−λ)^{60Δt}
x ← x + v Δt
```

### 1.3 连续时间形式

令 Δt → 0，(1−λ)^{60Δt} = e^{−γΔt}，定义

> **γ ≡ −60 ln(1 − λ)**   （平台默认 λ = 0.3 ⇒ γ = 21.4 s⁻¹）

于是

> **ẍᵢ = 60κ Σⱼ f_{sᵢsⱼ}(rᵢⱼ) r̂ᵢⱼ − γ ẋᵢ**  … (1)

**这就是 Particle Life 的运动方程。** 它是一个耗散的、非保守的、非互易的多体系统。

### 1.4 离散迁移率（把理论和模拟对齐的关键细节）

在恒力 a 下，离散映射的不动点是

> μ_disc = 60κΔt · d/(1−d)，  d = (1−λ)^{60Δt}

Δt → 0 时 μ_disc → μ = 60κ/γ。但在默认 Δt = 1/60、λ = 0.3 下：
μ_disc = 2.3333 而 μ = 2.8037，**相差 16.8 %**。
所有与模拟对比的定量预言都必须用 μ_disc，否则会系统性偏高 —— 这正是 E02 中
预言误差从 17 % 降到 0.05 % 的原因。

### 1.5 无量纲化

取长度单位 α₀（典型键长）、时间单位 1/γ，得到两个无量纲群：

| 群 | 含义 | 默认值 |
|---|---|---|
| **Γ = 60κ / (γ²α₀)** | 力 / 惯性 · 阻尼 = "驱动强度" | ≈ 0.009（强过阻尼） |
| **ρα₀²** | 每个键长面积内的粒子数 = 填充率 | O(0.1–1) |
| β/α | 相互作用程 / 键长 = "配位数" | 2–5 |
| ν | 非互易度（下节定义） | 0–1 |

Γ ≪ 1 说明系统**接近但不等于过阻尼**：速度记忆时间 1/γ = 47 ms，
而结构演化时间是秒级。残余惯性正是追逐者会"冲过头"并绕圈的原因。
`Params(inertialess=True)` 可以积分严格过阻尼极限 ẋ = μ Σ f r̂ 来做对照。

## 2. 两体问题：势、键长、阱深 —— 系统的"化学"

因为 f 只依赖距离，可以定义 U(r) 使 U′(r) = f(r)、U(∞) = 0。积分得到**分段二次**的闭式：

```
          ⎧ R(r−α)²/(2α) − A(β−α)/2          0 ≤ r ≤ α
  U(r) =  ⎨ −A[2w² − (r−α)²]/(2w)            α ≤ r ≤ m
          ⎨ −A(β−r)²/(2w)                    m ≤ r ≤ β
          ⎩ 0                                r ≥ β
```

由此立刻得到两条**结构性事实**：

> **(a) 键长 = minRadius。** f(α) = 0，且 A > 0 时 α 是稳定平衡点
> （内侧核心排斥、外侧帐篷吸引）。所以 α 矩阵字面上就是这套"化学"的键长表。
>
> **(b) 键能 = −A(β−α)/2。** 势阱深度只由力系数和相互作用**带宽**决定，与 R 无关。

这解释了平台教程里那句经验规则"最小半径决定蛇有多粗"：
蛇的粗细就是相邻键长，即 α；细胞膜的厚度、晶格常数同理。

键的刚度是**单侧**的：内侧 k₋ = R/α，外侧 k₊ = A/w = 2A/(β−α)。
R 大、A 小时是"硬球+弱胶"，形成脆的晶体；反之是软而黏的液滴。

数值核对（`e01_force_law.py`）：

```

f(α)             = 0              Û_core(0) = 883.573   πRα³/12 = 883.573
```

## 3. 互易性定理：为什么"生命"必须打破牛顿第三定律

把力分解为互易部分和非互易部分：

> f_S(r) = ½[f_ab(r) + f_ba(r)]   （互易 / 变分）
> f_A(r) = ½[f_ab(r) − f_ba(r)]   （非互易 / 非变分）

非互易度指标：**ν = ‖A − Aᵀ‖_F / (‖A + Aᵀ‖_F + ‖A − Aᵀ‖_F) ∈ [0,1]**。

### 定理

**若 A、α、β 全部对称**（即 f_ab ≡ f_ba），令

  E = ½ Σᵢ |vᵢ|² + Σ_{i<j} U_{sᵢsⱼ}(rᵢⱼ)

则沿 (1) 的轨道

  **Ė = −γ Σᵢ |vᵢ|² ≤ 0**

*证明.* 力 Fᵢ = −∂V/∂xᵢ（因为对称时 U 良定义为势），故
dE/dt = Σᵢ vᵢ·(Fᵢ − γvᵢ) + Σᵢ (∂V/∂xᵢ)·vᵢ = −γΣ|vᵢ|²。∎

E 有下界（U 有界、N 有限）。由 LaSalle 不变原理，轨道收敛到 {Ė = 0} = {v = 0}
中的最大不变集，即 V 的力学平衡点。

> **推论：互易的 Particle Life 一定会停下来。**
> 不可能有持续爬行、追逐、旋转、振荡。所有"活着"的现象都必须归因于 A（或 α、β）的反对称部分。

### 更锐利的形式：功率注入

把 (1) 的力写成 f = f_S ± f_A。f_S 部分恰是 −∇V，所以 Ė 中唯一的非变分项是

> **P_inj = 60κ Σ_{i<j} f_A(rᵢⱼ) r̂ᵢⱼ · (vᵢ + vⱼ)**   … (2)

它在互易时**逐项恒等于零**。稳态下必有 ⟨P_inj⟩ = γΣ|vᵢ|²：
**打破的第三定律，就是为这套"生命"付电费的那台发电机。**

### 验证（`e03_reciprocity_theorem.py`）

固定一个随机宇宙，作 A(θ) = A_S + θ·A_N 的插值（半径矩阵取对称），θ=0 严格互易：

| θ | ν | 团簇运动性 | P_inj/N | γΣ\|v\|²/N |
|---|---|---|---|---|
| 0.00 | 0.000 | 0.00134 | **0.000000** | 4.22 |
| 0.25 | 0.211 | 0.00738 | 2.57 | 9.20 |
| 0.50 | 0.349 | 0.01572 | 15.13 | 26.96 |
| 0.75 | 0.446 | 0.10506 | 159.92 | 185.40 |
| 1.00 | 0.518 | **0.50008** | 1688.12 | 1669.99 |

（λ = 0.10；定理对任意摩擦成立，这里用较低摩擦把效应放大，见 §6。）

θ = 0 时注入功率**精确为 0**（不是"很小"，是恒等式），全部动能只能耗散掉——
150 s 的长程跟踪显示 ⟨|v|⟩ 一路衰减到 0.06 且没有停止的迹象；
θ = 1 时注入功率 1688 与耗散 1670 在噪声内相等（**功率平衡**），运动性比互易情形高 **373 倍**。

## 4. 运动的显微起源：自驱动二聚体与团簇内力

### 4.1 二体精确解

取 a、b 各一个，r⃗ = x_b − x_a。分解为质心 X 和相对坐标：

> r̈⃗ = −120κ f_S(r) r̂ − γ ṙ⃗        （只含**互易**部分）
> Ẍ  = 60κ f_A(r) r̂ − γ Ẋ           （只含**非互易**部分）

于是：

> **键长 r\* 由 f_S(r\*) = 0 且 f_S′(r\*) > 0 决定（互易部分定"形状"）**
> **末速度 V = μ_disc · f_A(r\*) 沿 r̂（非互易部分定"运动"）**  … (3)

一个非互易的束缚对，就是一个**自驱动粒子**。它自发选择一个方向并沿之匀速漂移——
连续旋转对称性被自发破缺。

**一个必须说清的退化情形：** 若两个方向的半径相同（α_ab = α_ba，β_ab = β_ba），
则 f_ab 与 f_ba 有**共同零点** r = α，于是 f_A(r\*) = 0，V = 0：
**二体追逐总会停下来。** 持续自驱动需要
(i) 半径矩阵不对称，或 (ii) ≥3 个粒子的**几何阻挫**（不可能让所有键同时落在各自的零点上）。

### 4.2 团簇的净内力与净内力矩

对任意一团粒子 C：

> **F_int = Σ_{i<j∈C} 2 f_A(rᵢⱼ) r̂ᵢⱼ**              → 平移（爬行、追逐）
> **τ_int = Σ_{i<j∈C} [(xᵢ−X) f_ij − (xⱼ−X) f_ji] × r̂ᵢⱼ**  → 旋转（自旋细胞、旋涡）

互易时两者**恒等于零**（这正是牛顿第三定律的内容）；非互易时一般不为零。
团簇末速度 ≈ μ_disc · |F_int| / N_C。

**这就是"结构会动"的完整机理：结构不是被外力推动，而是它自己内部的力不再抵消。**

## 5. 连续介质理论：结构的**尺度**从哪来

### 5.1 粗粒化

对每个物种定义密度场 ρ_a(x,t)。由质量守恒 + (1) 的动量方程线性化：

> ∂ₜρ_a + ∇·(ρ_a u_a) = 0,  ∂ₜu_a = −60κ ∇Φ_a − γ u_a,  Φ_a = Σ_b U_ab ⋆ ρ_b

注意：即使 U_ab ≠ U_ba（没有自由能），**线性算子依然良定义**——这正是关键。

### 5.2 色散关系

令 δρ_a ∝ e^{ik·x+λt}，Û_ab(k) = 2π∫₀^β r J₀(kr) U_ab(r) dr 为二维 Hankel 变换，
σₙ(k) 为矩阵 **ℳ(k) = diag(ρ̄) Û(k)** 的本征值（一般是复数），则每支满足

> **λ² + γλ + 60κ k² σₙ(k) = 0**
> **λ± = ½( −γ ± √(γ² − 240κk²σₙ) )**   … (4)

（过阻尼极限 λ ≈ −μk²σₙ，即 Cahn–Hilliard 形式。）

### 5.3 尺度选择

Re λ(k) 在**有限 k\*** 取极大，原因是两端各被压制一次：

* **长波端**：粒子数守恒给出的 k² 前因子 ⇒ k→0 时增长率 → 0；
* **短波端**：核心排斥使 σ(k) > 0 ⇒ 稳定。

于是 **ℓ\* = 2π/k\*** 就是第一批结构的特征尺寸。

> **一个必须诚实说明的结果：单一物种做不到有限尺度。**
> 在 282 组随机单物种参数（Û(0) < 0）中，Û(k) 的极小值**每一次**都落在 k = 0
> —— 单物种只能无限粗化（Ostwald 熟化）。
> 有限的、重复出现的结构**总是来自多物种竞争**：短程自吸引 + 长程互斥
> 就是在**物种空间**中实现的 SALR 核。消去"快"物种给出中介有效相互作用
>
> **Û^eff_aa(k) = Û_aa − Û_ab Û_ba / Û_bb**
>
> 它的内部极小值才是细胞大小的来源（数值：上式在 k = 0.244 处取极小，
> 对应 ℓ ≈ 26，而 Û_aa 本身极小在 k = 0）。

### 5.4 验证（`e04_linear_stability.py`）

固定 β = 3α，扫描 α，比较预言 ℓ\* 与模拟中 S(k) 峰位（t = 6 s，4 个种子取中位数）。
线性理论把**标度**抓得很准，前因子作为平均场闭合只准到一个常数：

> **ℓ_测量 = 0.607 · ℓ\***，跨越 α = 11…38（3.5 倍范围），**R² = 0.9906**。

这是平均场理论应有的表现：它预言"尺寸正比于 minRadius"以及不同宇宙之间的排序，
而不预言绝对数值。**平台教程里"最小半径控制结构大小"这句经验规则，
在这里被化成了一条可计算的标度律。**

## 6. 非互易相变：结构什么时候开始"动"

### 6.1 判据

设 σ = σᵣ + iσᵢ。由 (4)，Re λ₊ > 0 当且仅当

> **σᵢ² > (γ² / (60κk²)) · σᵣ**   … (5)

（σᵣ < 0 时自动成立——这就是普通的吸引致凝聚。）

* 若 **σᵣ > 0**（互易部分本身是稳定的），不稳定性**只可能来自非互易性**，
  且此时 Im λ ≠ 0：增长模是**行波**，相速度 c = |Im λ|/k。
  这就是"追逐者/爬行的蛇/旋转细胞"在线性理论中的指纹。
* σ 为复数要求 **Û ≠ Ûᵀ**，即矩阵非互易。

### 6.2 例外点（两物种可解）

两物种时

> σ± = ½(ρ₁û₁₁ + ρ₂û₂₂) ± √D,  **D = [½(ρ₁û₁₁ − ρ₂û₂₂)]² + ρ₁ρ₂ û₁₂û₂₁**

σ± 成为共轭复数对 ⟺ **D < 0** ⟺ **û₁₂û₂₁ < 0**，即
**一个追、一个逃**，且强度足够大。D = 0 的轨迹是**例外点**（两个本征向量并合）：
跨过它，两个静态的分相模合并成一个行波模。
这正是 Fruchart 等人（*Nature* **592**, 363, 2021）非互易相变在 Particle Life 中的实例。

### 6.3 摩擦是开关

判据 (5) 里显含 γ²：**摩擦压制行波不稳定性**。这给出一条可证伪的预言：
矩阵不变、只调 `frictionFactor`，结构必须在某个可计算阈值处从"站着"切换到"走着"。

固定纯追逐矩阵 A = [[−0.1, 0.9], [−0.9, −0.1]]，α = 15、β = 45、N = 6000、L = 1200：

| λ | γ [1/s] | Re λ_osc | k_osc | c [px/s] | 判定 |
|---|---|---|---|---|---|
| 0.30 | 21.40 | −0.0000 | — | — | 静态 |
| 0.15 | 9.75 | +0.0105 | 0.167 | 6.4 | 行波 |
| 0.08 | 5.00 | +0.4128 | 0.074 | 27.4 | 行波 |
| 0.04 | 2.45 | +1.1683 | 0.074 | 33.4 | 行波 |
| 0.02 | 1.21 | +1.6755 | 0.074 | 35.1 | 行波 |

阈值落在 λ ≈ 0.15–0.30 之间。**平台默认的 λ = 0.3 恰好在阈值的静态一侧**，
这解释了一个常见观察：默认参数下先出现团块，运动是随后由非线性效应（团簇净内力，
第 4 节）驱动的，而不是由均匀态的线性不稳定性直接产生的。

## 7. 形态学字典：矩阵的图结构 → 结构

把 A 看成 S 个物种上的**有向加权图**。形态由三件事决定：

1. **图的拓扑**（谁和谁成键）→ 结构的维度与连通方式
2. **边的对称性**（A_ab vs A_ba）→ 动不动、怎么动
3. **α、β**（键长与作用程）→ 尺寸与粗细

| 图 motif | 典型矩阵 | 涌现结构 | 机理 |
|---|---|---|---|
| 对角为正、非对角为负 | `condensate` | 静态团块 / 液滴 | 单一凝聚模；ν=0 ⇒ 定理 3 ⇒ 冻结 |

### 形态发生图（`e07_morphogenesis_map.py`）

单一双参数族就能重现整个动物园。在物种环上取

> A_ij = a·δ_ij + **w**·δ_{j,i+1} + **b**·δ_{j,i−1} + c·(其余)

两个坐标有直接的物理含义：

* **w + b** → 互易成键强度（链有多结实）
* **w − b** → 非互易度（每条键追得多凶）

对角线 **w = b** 正是互易线，定理 3 在这条线上禁止一切运动 ——
它就是"活相"的边界。

## 10. 局限与开放问题

1. **平均场**。§5 的线性理论忽略关联和涨落，所以尺度前因子只准到常数。
   要做得更好需要把核心排斥的关联（如 RPA/HNC 闭合）放进去。
2. **只做了线性稳定性**。团簇的运动本质上是非线性的（§4 的团簇内力）。
   完整的弱非线性分析（振幅方程 / 非互易 Cahn–Hilliard）没有做。
3. **粗化的终态未处理**。Û(0) < 0 时长时间行为是 Ostwald 熟化；
   模拟里看到的"有限大小的细胞"部分来自**动力学冻结**（致密团簇内部弛豫极慢），
   这一条只做了观察，没有做理论。
4. **形态分类的阈值是经验的**。序参量的物理含义是明确的，
   但 1.55 / 0.42 / 0.02 这些切分是拟合出来的，不是从理论导出的。
5. **3D 未涉及**。原站有 3D 引擎；本文所有结论写在 2D，
   Hankel 变换换成三维傅里叶变换后大部分论证可以照搬，但没有验证。
6. **8 bit 量化**。原站把力系数量化到 8 bit；本复现用浮点。
   这在遍历"矩阵空间"时会有细微差别，对单个宇宙没有影响。
