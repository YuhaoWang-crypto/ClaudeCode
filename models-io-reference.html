模型 / 工具 I/O 参考 + 新适应症迁移手册

每个采用的模型：用途 · 输入 · 输出；末尾是把整套流程搬到任意新适应症的通用操作步骤。

1 · 基础模型层（生成候选）

模型用途输入输出
Geneformer 核心 单细胞上下文嵌入；de novo 细胞态发现、疾病/应答分型、in-silico 扰动定位驱动基因、网络中心性 scRNA 计数矩阵（细胞×基因，Ensembl ID + n_counts），rank-value 编码（表达/中位数 降序取 token，截断 2048）；可选细胞标签 每细胞嵌入（V1-10M=256维）；聚类/细胞态标签；扰动"状态位移分"；（微调后）分类预测
ESM-2 / AMPLIFY 变异效应预测（VEP，零样本）、蛋白功能/家族嵌入、抗原性辅助 蛋白氨基酸序列（野生型 + 变异型），或仅序列 每残基/序列嵌入；变异有害性分（wt vs mut 掩码 LM 伪对数似然差 Δpll）
Geneformer 落地要点：词表须与模型匹配（V1↔gc30M，V2↔gc104M）；按供体/中心分层防批次效应；需真实 scRNA 才有真实信号——合成随机基因无共表达结构，预训练嵌入不会分离（见 geneformer-gpu-run-results.md）。

2 · PROTO（核酸/调控层平台）

PROTO = 生物学"高级编程语言"，把多个核酸模型编排成"设计+打分"流程。biomarker 挖掘里角色 = 候选基因的调控/剪接变异功能验证（判断"基因型层通路激活度"）。文档：proto.evodesign.org

子模型用途输入输出
Evo2基因组 DNA FM；非编码/调控变异效应、序列打分/生成DNA 序列窗口（ref/alt，变异居中）序列似然 / 调控影响分
AlphaGenome / Enformer / Borzoi序列→功能：表达、染色质可及性预测DNA 窗口（以变异/位点居中）调控轨迹预测；ref−alt 差 = 变异效应
SpliceAI / Pangolin剪接改变预测DNA 序列 + 变异位置剪接改变概率（供/受体位点增益/丢失 Δ）
ViennaRNARNA 二级结构RNA 序列最小自由能结构、碱基配对概率
PROTO 整体设计/打分核酸序列（启动子、调控元件）序列(DNA/RNA)、变异、约束每变异功能影响分（表达/染色质/剪接）；优化序列

7 · 迁移到新适应症：通用手册

整套流程与代码与适应症无关，六步不变，只换 6 样东西。

六步流程

  1. 定义问题：选适应症 + 1–2 个 BEST 类别 + 明确对比组（responder vs NR / progressor vs stable / disease vs healthy）
  2. 证据接地：PubMed/bioRxiv/Trials/ChEMBL → 已知 biomarker、竞争基线、新颖性缺口
  3. 候选生成：Geneformer（scRNA 细胞态）+ ESM-2 VEP（编码变异）+ PROTO（调控变异）
  4. 机制过滤：Boltz / EDEN / ChEMBL
  5. 临床筛：新颖性 / 可及性 / 临床对齐 三门槛
  6. 组合评分卡 + 前瞻验证
