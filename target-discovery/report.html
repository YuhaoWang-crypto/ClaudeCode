Foundation-model target discovery · methods & results

Mining novel drug targets for idiopathic pulmonary fibrosis

A counterfactual pipeline that pairs biomolecular foundation models with an evidence layer of curated databases — nominating targets by asking what a gene's knockout does to a diseased cell, then testing novelty, druggability, and tractability before committing.

How a target gets nominated

Five stages. The engine generates hypotheses; the surrounding layer keeps only what is novel, druggable, and structurally tractable.

04 · Result — druggability

From target to attackable target

PTGES / mPGES-1

Small-molecule route. ChEMBL: best IC50 1 nM, LE 0.40–0.46, 17 co-crystal PDBs. Boltz homotrimer confirmed the inhibitor in a defined inter-subunit pocket (protein-iPTM 0.987, interface error 3.1→1.35 Å). A 7-compound screen cleanly split actives (opt-score 0.28–0.42) from decoys (0.00–0.01).

MDK / midkine

Biologic route. ChEMBL nM binders exist only as sulfated-glycan mimetics; Boltz apo structure is flexible with no deep pocket — a secreted factor to neutralize, not a small-molecule target.

SFRP2 — model nomination meets human biology

The pretrained engine's #1 pick is, per PubMed, a causal driver of the aberrant-basaloid transition in IPF: a TGF-β1 fibroblast target that switches on the KRT5+ basal program via Frizzled-5 (Cohen et al., J Clin Invest 2024), and marks myofibroblast progenitors (Tabib et al., Nat Commun 2021). Secreted, zero ChEMBL ligands → biologic. Boltz designed 10 anti-SFRP2 nanobodies; the top scored interface iPTM 0.83 (interaction PAE 3.1 Å) — a credible starting binder for lab validation.

Novelty gate

IPF has 55 in-clinic Phase 2/3 programs. Crowded mechanisms — PDE4B, LPA1, integrin αvβ6, ROCK2, CSF1R, TG2 — are down-weighted so the pipeline spends its attention on first-in-class whitespace.

05 · Reuse

Running this on a new indication

The pipeline is indication-agnostic. Four things change; everything else — tokenizer, model, Boltz calls, scoring — is reused as-is.

  1. Landscape — ClinicalTrials search_trials(condition) → crowded-targets list; PubMed/bioRxiv → mechanism map & candidate genes; ChEMBL drug_search(indication) → known targets.
  2. Data — run inspect_census to find the exact Census disease label, dataset_id, and cell-type lineage (they differ per disease). Edit PF_DATASET, LINEAGE, STATES; run fetch_ipf_data.
  3. Engine — tokenize → finetune the disease classifier → perturb_targeted (or genome-wide) → read_shifts.
  4. Druggability & dossier — top hits through ChEMBL, Boltz structure / screen / design, PubMed; assemble the ranked dossier.

changes per indication: ClinicalTrials/PubMed queries · Census disease label + dataset_id + lineage · STATES start label · candidate gene list

06 · Notes

Compute, cost, and honest limits

Compute

Modal — T4 (model smoke), A100 (perturbation, fine-tune). Image + 418 MB checkpoint cached in a Volume.

Boltz spend

Under ~$1 total: structure predictions, the inhibitor screen, and 10 nanobody designs.

What to trust, and what not to

  • The fine-tuned ranking is verifiable-grade for direction: effectors top, controls bottom. Absolute magnitudes are small and not calibrated affinities.
  • Targeted perturbation covers a candidate set, not the whole genome — a genome-wide classifier sweep is the next scale-up (needs more GPU budget).
  • SFRP2 is a hypothesis with strong independent support, not a validated drug target; the nanobodies are computational designs for wet-lab triage.
  • Every GPU stage needed real debugging (checkpoint download, transformers pin, CUDA-fork, tensor placement) — all captured in the committed code so a rerun is clean.
