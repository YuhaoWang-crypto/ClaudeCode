The sequence

Seven stages, one representation budget

Each stage is a place coverage can be lost. The numbers below are the same ones the calculator (scripts/coverage_calculator.py) reproduces for any library size.

01

Target set — the kinome

Pull the 518 protein kinases from HGNC, map to Ensembl transcripts for constitutive-exon targeting. Don't hand-curate.

518 kinasesHGNC 1258Manning classification
02

Guide selection

6 sgRNA/gene targeting early constitutive exons, ranked by Rule Set 3 + DeepSpCas9; hard filters on poly-T, GC, cloning sites, SNPs.

6 guides/geneRule Set 3DeepSpCas9Brunello subset + top-up
03

Off-target prediction

Enumerate with Cas-OFFinder, score CFD/MIT via GuideScan2; reject perfect or exonic 1-mismatch off-targets; CFD specificity ≥ 0.2.

CFD ≥ 0.2GuideScan2Cas-OFFinder
04

Library construction

Array-synthesized oligo pool → BsmBI Golden Gate into lentiGuide-Puro → Endura at ≥50–100× colonies/guide → NGS QC.

Gini < 0.1skew < 10×≥95% represented
05

Screen scale

Transduce ~13.5M cells at MOI 0.3 → 3.5M integrants; hold ≥3.5M cells/sample through selection, passaging and each timepoint to ~day 21.

≥1000× coverageMOI 0.3T0 + ~day 21
06

Sequencing readout

~23 µg gDNA/sample (all of it, split across ~3 PCRs) → 2-step indexed PCR → ~4.4M reads/sample, 1×75 bp + PhiX.

~23 µg gDNA~4.4M reads1×75 bp SE
07

Analysis

MAGeCK count → BAGEL2 for essentiality, drugZ for chemogenomic; Chronos copy-number correction; benchmark against CEGv2/NEGv2.

BAGEL2drugZMAGeCKChronos
One experiment · two readouts

Vehicle and drug arms, split from a shared T0

The vehicle arm does double duty — it is the essentiality experiment and the control for the drug arm.

Line A · essentiality

Kinase dependencies

Which kinases this cell line needs — depletion from T0 in the untreated arm.

compare  T_end(DMSO)  vs  T0
  • Primary: BAGEL2 Bayes Factor (CEGv2/NEGv2 priors)
  • Positive controls: PLK1, CDK1, AURKB deplete
Line B · synthetic lethal

Drug-modifier kinases

Which knockouts change drug sensitivity — sensitizers and resistance nodes.

compare  T_end(Drug)  vs  T_end(DMSO)
  • Primary: drugZ — normZ < 0 sensitizer, > 0 resistance
  • Dose = IC20–IC30 of proliferation, measured in-house
≠
Synthetic lethality is drug vs. vehicle, never drug vs. T0 — the vehicle arm subtracts baseline essentiality so only the drug-specific increment remains.
