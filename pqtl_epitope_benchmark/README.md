# pQTL 驱动的蛋白标志物"表位假象"排雷:公开数据原型

这不是矩阵里的既有行,是一个独立的"排雷"工具原型。
背景:亲和力蛋白质组学(SomaScan 适配体 / Olink 抗体)靠结合表位测蛋白。靶蛋白自身基因附近的 cis-pQTL
可能不是真的改变丰度,而是**改变了表位序列让试剂结合变差**(表位假象 / 结合假象)。
"排雷"=把这类假象信号从真·丰度信号里挑出来,避免把它当成真实的蛋白标志物去下游分析。

经典红旗:cis-pQTL 的主效变异是该基因里的**蛋白改变变异(PAV:错义/终止/移码/剪接)**。
本原型用公开 UKB-PPP(Olink)数据 + Ensembl VEP 实现并演示这个检测器。

结论先行:**流程端到端跑通,并在真实数据上复现了已知的 ~10% cis-PAV 率;被标记的表位假象候选(如 TNFSF14 终止获得、IL15RA 错义、HGF 终止获得)效应量明显偏大,与"结合失败"的假象特征一致**。但本次只覆盖了一个 UKB-PPP 编号区块(56 个蛋白),样本小,是概念验证而非全图谱排雷。

## 数据与方法(全部公开)

| 步骤 | 来源 |
|---|---|
| cis-pQTL | UKB-PPP(Sun 2023,Olink)summary stats,EBI GWAS Catalog,GRCh38 harmonised,远程 tabix 取 cis 区段(基因 TSS ±500kb) |
| 蛋白→基因 | HGNC complete set(全称/别名)→ 符号;UCSC refGene(GRCh38)→ 基因坐标 |
| 变异后果 | Ensembl VEP REST(GRCh38),判定主效变异是否为该基因的 PAV |

覆盖:一个 UKB-PPP 编号区块 GCST90274758–848 的 91 个蛋白,成功映射并取到 cis 主效的 56 个,其中 28 个达全基因组显著(p<5e-8)。

## 结果

### 1. 流程跑通,PAV 率与文献一致

28 个全基因组显著 cis-pQTL 的主效变异后果分布:内含子 22、上游 2、**终止获得 2、错义 1**、5′UTR 1。
→ **3/28 ≈ 11% 的 cis-pQTL 主效是该基因的蛋白改变变异**,属表位假象候选。这个比例与 UKB-PPP 原文报告的 cis-PAV 占比(~12–16%)一致,说明检测器工作正常。

### 2. 被标记的假象候选效应量偏大(方向符合,样本小)

| | 标记为 PAV(表位假象候选) | 非 PAV |
|---|---|---|
| 主效 \|β\| 中位 | 0.37 | 0.17 |
| n | 3 | 25 |

表位假象因为"试剂干脆结合不上"往往表现为异常大的表观效应。被标记的 3 个确实偏大,方向符合,但 n=3 不足以做统计结论。

具体标记出的候选:**TNFSF14**(终止获得,\|β\|0.49)、**IL15RA**(错义,0.37)、**HGF**(终止获得,0.19)——都是"主效落在编码区、会改蛋白序列"的典型表位假象嫌疑,下游用这些蛋白做标志物/MR 前应先核实是不是检测假象。

## 这个"排雷"思路可以这样用

1. 任何用亲和力蛋白质组(SomaScan/Olink)做标志物面板或 pQTL-MR 的流程,先对每个蛋白的 cis-pQTL 主效跑 VEP;主效(或与主效高度连锁的变异)是该基因 PAV 的,打上"表位假象候选"标签,人工复核或降权。
2. 更强的版本(本次未做,见下)应叠加:① 跨平台核对(同一蛋白 SomaScan vs Olink 的 cis-pQTL 不一致 = 强烈假象信号);② cis-eQTL 正交核对(真·丰度 cis-pQTL 常有同向 cis-eQTL,表位假象缺少);③ LD 代理(表位假象的 PAV 可能不是主效本身而是与它连锁的变异)。

## 限制(重要)

- **样本小**:只覆盖一个 UKB-PPP 编号区块(56 蛋白,28 显著)。UKB-PPP 的 ~2,900 个蛋白在 GWAS Catalog 的编号不连续、分散在多处,本会话未能定位全部区块;因此这是**原型/概念验证**,不是全蛋白组排雷。
- **只标了主效本身**:没做 LD 代理,会漏掉"假象由与主效连锁的 PAV 驱动"的情况(可能低估假象比例)。
- **缺正交验证**:计划中的 cis-eQTL 核对,本会话用的 eQTL Catalogue 端点(QTD000356)远程 tabix 返回空,未完成;跨平台(SomaScan/deCODE)数据在门户后面,未取到。因此"假象"目前是基于机制红旗(编码区 PAV)的候选判定,未经第二种证据确认。
- 效应量差异 n=3,仅为方向性提示。
- 蛋白名→基因用 HGNC 名称匹配,复杂名/复合体可能漏映射(本区块 91→56)。

## 复现

```bash
pip install requests  # + tabix (htslib)
# gene38.json: UCSC hg38 refGene -> 符号:TSS; hgnc.tsv: HGNC complete set
export QB_DATA=...
python 01_harvest.py 90274758 900   # 远程 tabix 采 cis 主效(UKB-PPP 区块)
python 02_annotate.py               # Ensembl VEP 注释主效后果 -> PAV 标记
python 03_analyze.py                # 效应量/后果分布 + 图
```
数字在 `results/analysis.json`,图在 `results/fig1_pqtl_epitope.png`,采集到的主效在 `results/cis_leads_annotated.tsv`。
