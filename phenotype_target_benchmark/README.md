# 表型命中反推与实验模型匹配:公开数据实测

检验矩阵这一行的承诺与边界。
这一行里 L1000CDS2/SigCom(转录指纹)、CellProfiler(形态指纹)、DepMap/PRISM 对齐 负责
"反推候选直接靶点/分子胶机制"与"推荐最匹配验证模型"。
第 05 栏承诺"通过指纹相似度 反推候选直接靶点,或推荐最匹配验证模型";
第 06 栏边界:**"表型指纹相似不等于直接物理结合靶点真值;模型推荐不保证跨模型迁移后的药效一致"**。

本次用 DepMap/PRISM(这一行列出的组件之一,全公开、CPU 可算)做严格的已知答案检验。

结论先行:**反推"机制类"有效(最近邻药物共享 MoA 65.7%,随机仅 3.8%),但反推"物理靶点"基本失败(真实靶点全基因组中位排名 10,636/18,443,比随机还差)**。矩阵标注的边界被数据强力坐实。

## 数据(全部公开)

| 项目 | 数据 | 规模 |
|---|---|---|
| 药物敏感性 | PRISM Repurposing 二次筛(DepMap/figshare),每(药,细胞系)的 AUC + 靶点/MoA 注释 | 531 个单靶点药 |
| 基因依赖 | DepMap 24Q2 CRISPRGeneEffect(Chronos) | 18,443 基因 |
| 细胞系/谱系 | DepMap Model.csv | 403 个 PRISM∩CRISPR 共享细胞系 |

## 结果

### 1. 反推物理靶点:失败(证实核心边界)

对每个药,把它在 403 个细胞系上的敏感性谱与全部 18,443 个基因的 CRISPR 依赖谱做相关,看它**真实注释的靶点**排在第几:

| 指标 | 值 |
|---|---|
| 真实靶点全基因组中位排名 | **10,636 / 18,443**(随机期望 ≈9,221,比随机更差) |
| 真实靶点进前 10 的药占比 | 0.2% |
| 真实靶点进前 100 的药占比 | **0.9%** |
| 敏感性-依赖呈正相关(方向对)的药占比 | 39.5% |

绝大多数药的"杀细胞表型"并不追随其物理靶点的遗传依赖——因为多数药通过汇聚的/泛毒性机制杀细胞,活力表型携带的物理靶点信息极弱。
少数真·在靶药是例外:2,3-DCPE→BCL2L1(排第 6)、INH1→NDC80(24)、PQ-401→IGF1R(58)、enzalutamide→AR(229)。这些药的活力效应确实依赖靶点。

### 2. 反推机制类(MoA):有效

| 指标 | 值 |
|---|---|
| 最近邻药物(按敏感性谱)共享 MoA | **65.7%** |
| 随机配对共享 MoA | 3.8% |
| MoA 类别数 | 45 |

表型指纹相似能把机制相同的药聚到一起(富集 17 倍)。这正是 connectivity/指纹检索真正擅长的——**反推机制类,不是指认物理靶点**。

### 3. 模型匹配与跨模型一致性

- 在"物理靶点排名较好"的在靶药子集(仅 8 个)里,"最依赖该靶点的细胞系"并不更对该药敏感(敏感-依赖 Spearman −0.15);样本太小,只作提示。
- 药物总体效力排序在谱系间高度保留(谱系中位 AUC 跨谱系 Spearman 0.96)——但这主要是泛毒性主导(毒的药在哪都毒),**不能据此说"靶向药在正确模型里的选择性响应会迁移"**;选择性迁移是另一个问题,本数据不能干净回答。

## 对矩阵这一行的修改建议

1. 第 05 栏"反推候选直接靶点"应改为"反推候选机制类(MoA)";指认物理结合靶点不可交付(中位排名比随机还差)。分子胶/直接靶点必须另有结合实验。
2. 交付物定位为"机制相似的已知药/扰动清单",并标注这是 MoA 级相似,不是靶点级真值。
3. 第 06 栏两条边界完全正确,建议作为硬性免责声明并给量化锚点(真实靶点中位排名 10,636/18,443;MoA 最近邻命中 66% vs 随机 4%)。

## 限制

- **只用了 DepMap/PRISM 一个组件**:L1000 转录指纹(L1000CDS2/SigCom)、CellProfiler 形态指纹未测——这两类用的是转录/形态指纹,可能比 PRISM 活力表型更能反推靶点;本结论针对"活力表型→靶点"这一路。转录指纹路可能更好,但未直接复测。
- PRISM 是活力(viability)读出,本就偏向泛毒性;这是活力表型做靶点反卷积的已知弱点,本次复现了它。
- 靶点/MoA 注释来自 PRISM 的 Repurposing Hub,有不完整和多靶点情况;这里只取单靶点注释的药。
- 模型匹配子集只有 8 个药,跨谱系只用了谱系中位,结论偏提示性。
- 没有做分子胶/降解剂的专门检验(需要蛋白降解读出)。
